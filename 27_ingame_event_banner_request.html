PST 인게임 이벤트 신청을 위한 배너 제작 요청

Tripeaks Solitaire · 인게임 이벤트 6종 배너 제작/심사 요청 · 2026-07-16 · 기준 데이터 PST_event_schedule.json

신청 개요

  • 대상 — 인게임 이벤트 신청에 쓸 배너 6종 제작 요청(이벤트 4종 + 주간 리더보드 + 콜렉션 앨범 퍼즐 모으기). City Race는 이벤트 4종에 포함
  • 배너 규격 — 각 이벤트당 2종 · 가로 1920×1080 / 세로 1080×1920
  • 페이로드 — 샘플 규칙 ingame_event_gold_tile 계승 → 전 이벤트 ingame_event_* 스네이크 표기로 통일
  • ※ 첨부 배너는 전부 GPT 생성 예시 — 톤·구성 참고용이며 실제 제작본 아님(최종은 아트팀 기준). 예시에 들어간 CTA 버튼(Play 등)은 실제 배너에 불필요

payload(social value)는 배너/딥링크/트래킹 공용 키. 스케줄 type과 1:1 정렬.

배너 노출 예시

노출 지면 — FB Instant Games "Happening now"

신청 통과 시 배너가 뜨는 실제 지면. 게임 허브 상단 "Happening now" 인게임 이벤트 캐러셀에 카드형(썸네일 + 제목 + 남은 기간 + 한 줄 설명)으로 노출됨. 아래 이벤트 4종이 이 슬롯을 로테이션.
실제 지면 예시 (타 게임 이벤트 노출 화면 · 우리 배너도 이 형태로 카드 노출)

1. Midnight Collection 3일

보드에서 검은 카드(스페이드/클럽)를 목표 수만큼 수집 → 15스텝 마일스톤 보상. 야간(자정) 무드.
payload ingame_event_black_card type black_card_milestone 목표 collect_color: black 스텝 15
가로형 1920×1080

하단 보드 — 트라이픽스 보드에서 검은 카드 부각(주변 일반 카드는 디밍)
세로형 1080×1920
