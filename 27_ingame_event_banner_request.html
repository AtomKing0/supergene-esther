Tripeaks Solitaire · 인게임 이벤트 7종 배너 제작 요청 · 2026-07-16 · 기준 데이터 PST_event_schedule.json

신청 개요

  • 대상 — 인게임 이벤트 신청에 쓸 배너 7종 제작 요청(이벤트 4종 + 주간 리더보드 + 콜렉션 앨범 퍼즐 + 7일 출석 보상). City Race는 이벤트 4종에 포함
  • 신청 문구 — 각 이벤트마다 FB Event Info 폼용 Event name(≤30) · Short(≤50) · Long(≤120) 영문 문구 포함(글자수 검증 완료)
  • 배너 규격 — 각 이벤트당 2종 · 가로 1920×1080 / 세로 1080×1920
  • 페이로드 — 샘플 규칙 ingame_event_gold_tile 계승 → 전 이벤트 ingame_event_* 스네이크 표기로 통일
  • ※ 첨부 배너는 전부 GPT 생성 예시 — 톤·구성 참고용이며 실제 제작본 아님(최종은 아트팀 기준). 예시에 들어간 CTA 버튼(Play 등)은 실제 배너에 불필요

배너 노출 예시

노출 지면 — FB Instant Games "Happening now"

신청 통과 시 배너가 뜨는 실제 지면. 게임 허브 상단 "Happening now" 인게임 이벤트 캐러셀에 카드형(썸네일 + 제목 + 남은 기간 + 한 줄 설명)으로 노출됨. 아래 이벤트 4종이 이 슬롯을 로테이션.
