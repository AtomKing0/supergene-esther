⑤ 스트릭 미터 골드

v1 v1

streak_meter_gold = entry_cost × 5%

entry_cost_base 1,000G → streak_meter_gold 최저 50G, max (entry_cost_max_cap 5,000G 기준) 250G. 11개 티어 적용 중. 상세: 02_streak_meter_gold_balance.html

와카 회수율 7.7% (A1안 적용, 2026-04-29 라이브). 스트릭 보상이 입장료 실패 손실의 완충 역할.

v2 v2

entry_cost = 0 → streak_meter_gold = 0

입장료 폐지로 streak_meter_gold 계산식 분모 소멸. 스트릭 미터 골드 보상 채널 전면 비활성화.

스트릭 보상은 별도 재설계 필요 (예: 연승 횟수 기반 플랫 보상·RV 교환 등). 현재 설계엔 대체 채널 미포함.

스트릭 미터 골드 V1 vs V2 비교: v1은 기존 A1안(entry_cost×5%) 유지로 와카 회수율 7.7% 운용 가능. v2는 entry_cost=0이므로 streak_meter_gold 자체가 무효화됨 → 스트릭 연승 보상 경험 설계 재검토 필요.
