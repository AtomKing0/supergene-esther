## 섹션 4: PM 권고

### 권고: **조정안 B** 채택

**이유:**

1. **패턴 일관성 완벽 준수**
   해머 ×1.170, 골드 ×1.200 모두 G2→G6 정상 범위(×1.111~×1.333, ×1.103~×1.343) 중앙값에 위치. 기존 도시 진행을 경험한 유저에게 위화감 없는 자연스러운 스텝.

2. **골드 수치의 명료성**
   골드 합계 40,800g. Sort별 값 [3,000 / 4,800 / 7,200 / 10,800 / 15,000]은 G6 Rio [2,500 / 4,000 / 6,000 / 9,000 / 12,500]의 정확히 ×1.20 배수 — 설계 의도가 명확하고 검증이 쉬움.

3. **경제 Sink 적정성**
   7.2일/도시는 G6(Rio 기준 약 6.1일)보다 18% 증가. 신규 콘텐츠 체감 난이도가 완만하게 상승하여 이탈 위험 최소화.

4. **현재값 대비 절감 효과**
   해머 190→110 (-42%), 골드 65,500→40,800 (-38%). 누적 인플레이션 완화에 기여.

**조정안 A 비채택 이유:** 해머 ×1.106이 정상 범위 하한(×1.111) 미달. 신규 도시 2개 동시 출시 시 콘텐츠 소비 속도가 너무 빨라 잔존 기간 단축 우려.

**조정안 C 비채택 이유:** 상한에 도달하나, G7 2개 도시를 동시 출시하는 특성상 총 소요일이 16.5일로 누적 골드 sink는 충분함. 단, 유저 진행 속도 측면에서 A보다 감소 폭이 적어 별도 이점 없음.
