# 인게임 골드 부족 대응 구조 개선 (상세 기획)

---

## 1. 문제 정의 (Trigger Condition)

- 유저가 인게임 부스터 사용 시도
- 보유 골드 < 부스터 가격

→ 즉시 소비 불가 상태 발생

### 문제 본질
- 광고를 통한 소비 우회 구조로 인해
  - 재화 경제 흐름 단절
  - 유저의 보상 체감 저하

---

## 2. 기존 구조 (As-Is)

- 광고 시청 → 즉시 부스터 사용

### 한계점
- 재화 획득 없이 소비 발생
- 경제 시스템과 분리된 구조
- 광고의 “보상 가치” 체감 부족

---

## 3. 개선 구조 (To-Be)

### 3.1 UX 플로우

1. 골드 부족 상황 발생
2. 보유 골드 → 빨간 숫자 강조 표시
3. 유저 터치
4. 광고 기반 골드 충전 팝업 노출
5. 광고 시청 → 골드 지급 → 부스터 사용

---

### 3.2 광고 보상 구조

- 지급 기준:
  - `level_entry_tier` 시트의 `rv_gold_ratio` 값 사용

### 설계 의도
- 플레이 구간별 경제 밸런스 유지
- 초반 과도한 지급 방지
- 후반 인플레이션 대응

---

### 3.3 노출 제한 정책

- `const` 시트의 `popup_free_gold_limit` 값 사용
- UTC 0시 기준 리셋

### 설계 의도
- 광고 과노출 방지
- 경제 붕괴 방지
- 일일 플레이 루틴 형성

---

## 4. 기대 효과

### 4.1 경제 구조 정합성 확보
- 광고 → 재화 → 소비 구조 정립
- 모든 소비가 골드 기반으로 통합

---

### 4.2 유저 인지 개선
- 기존: 광고 = 소비 우회
- 개선: 광고 = 보상 획득

→ 보상 체감 상승 및 RV 가치 증가

---

### 4.3 확장성 확보
- 이벤트 / 패키지 / 프로모션을 동일 재화 구조로 통합 가능

---

## 5. 향후 확장 전략

### 5.1 누적 보상 시스템

- 광고 시청 횟수 누적 시 지급 골드 증가
- 예:
  - 1회: 기본 지급
  - 3회: +20%
  - 5회: +50%

- 일일 리셋 유지

---

### 5.2 런칭 스펙 제외 이유

- 초기 설계:
  - 낮은 보상 → 점진적 증가 구조 채택

### 이유
- 보상 감소 구조:
  - 박탈감 발생
  - 이탈 리스크 증가

- 보상 증가 구조:
  - 긍정적 강화 효과
  - 세션 지속 유도

---

## 6. 결론

광고 기반 즉시 소비 구조를 제거하고  
재화 충전 → 소비 구조로 전환하여  

- 경제 일관성 확보
- 광고 보상 인식 강화
- 장기 확장성 확보

을 동시에 달성하는 설계
