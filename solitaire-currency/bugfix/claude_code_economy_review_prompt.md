# Economy Review Prompt (Claude Code)

당신은 모바일 퍼즐 게임의 **게임 경제 시스템을 검토하는 AI 분석가**다.  
다음 규칙과 전제를 기반으로 현재 경제 구조의 타당성을 검토하고 필요한 경우 의견을 제시하라.

중요:  
- 새로운 설계를 만드는 것이 아니라 **제시된 정책이 경제적으로 타당한지 검토하는 역할**이다.
- 경제 붕괴 가능성, 인플레이션 가능성, 소모 구조 등을 중심으로 분석하라.

---

# 1. Hammer 재화 구조

망치는 **아웃게임 메타인 꾸미기 시스템에 사용되는 재화**다.

획득 구조  
- 맵 난이도에 따라 획득량이 달라짐  
- 기준 데이터: `difficulty_tier` 시트

소모 구조  
- 꾸미기 도시 및 장식 요소에 따라 소모량이 달라짐  
- 기준 데이터: `meta_decoration_list` 시트

검토 시 고려사항

- 망치 획득 속도 vs 꾸미기 진행 속도
- 메타 진행 속도가 과도하게 빠르거나 느리지 않은지
- 망치가 과잉 축적되거나 부족해지는 구간이 존재하는지

---

# 2. 개선안 정책

## 개선안 1
개선안 1은 **진행한다.**  
경제적으로 문제가 되는지 검토하라.

---

## 개선안 2

부스터 구조

- 언두 (Undo)
- 추가 덱 (Extra Deck)

특징

- 해당 판 안에서 **사용할수록 가격이 계속 상승**
- **배수 시스템의 영향을 받는 금액**

따라서 플레이 중 다음 흐름이 발생한다.

- 부스터 사용 증가
- 사용 횟수 증가
- 가격 상승
- 배수 적용
- 골드 소모 급증

이 구조는 **Solitaire Grand Harvest 등 레퍼런스 게임에서도 동일하게 사용된다.**

검토 포인트

- 이 구조가 충분한 **골드 소모 장치로 작동하는지**
- 특정 상황에서 골드 소모가 부족해지는 구간이 있는지

---

## 개선안 3

개선안 3을 진행할 경우 **골드 인플레이션이 확정적으로 발생한다.**

정책

- 개선안 3은 **진행하지 않는다.**
- 해당 방향 설계는 **반려한다.**

검토 포인트

- 실제로 인플레이션 위험이 높은 구조인지
- 다른 조건에서 인플레이션이 발생할 가능성은 없는지

---

# 3. 광고 보상 골드 정책

정책

- 광고 보상 **수령 상한(cap)은 도입하지 않는다**

이유

- 수령 횟수 제한은 **리텐션에 악영향**
- 유저에게 **계속 받을 수 있다는 기대감**을 유지해야 함

따라서 해결 방법

- 횟수 제한 ❌
- **1회 지급 골드량 조정**

즉

- 소량이라도 **지속적으로 지급되는 구조 유지**

검토 포인트

- 이 방식이 경제적으로 안정적인지
- 광고 보상이 경제를 무너뜨릴 가능성이 있는지

---

# 4. 레벨 클리어 경제 구조

게임 설계 전제

- 대부분 맵은 **클리어 확률 85% 이상**
- 레벨 클리어 시

```
입장료 + 알파 보상
```

따라서 평균적으로 플레이어는

- 입장료 이상의 보상을 회수
- 플레이 자체는 경제적으로 손해 구조가 아님

검토 포인트

- 이 구조가 실제로 **경제적으로 중립 또는 약한 보상 구조인지**
- 장기 플레이에서 골드 축적이 발생하는지
- 골드 소모 구조가 이를 충분히 상쇄하는지

---

다음 구조로 분석 결과를 작성하라.

3. 광고 보상 구조 평가

5. 골드 인플레이션 가능성

7. 현재 설계의 강점
8. 잠재적 리스크
9. 추가로 확인해야 할 데이터
