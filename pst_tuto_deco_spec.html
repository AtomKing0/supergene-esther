🔁 왜 첫 데코가 판수·리텐션 레버인가 — 플라이휠 증거

신규를 데코 참여 여부로 갈라 비교 (정식 7/10~). "판수 낮은데 꾸미기로 액션을 빼는 게 맞나?"의 답.
신규 유저인원인당 판수D1 리텐션
데코 안 찍음2,7513.2판 (중앙값 0)6.0%
데코 1개+ 찍음1,11842.0판 (중앙값 18)44.8%
데코는 판수를 뺏는 게 아니라 판수의 "이유"다 — 데코 찍은 유저가 판수 13배·D1 7.5배. 인당 판수 평균이 벤치보다 낮은 건 데코 때문이 아니라, "3.2판 찍고 나가는 대다수(입구 이탈)"가 평균을 끌어내려서다. 코지·퍼블마가 판수도 높고 데코도 강한 게 증거 — 둘은 공존한다. 첫 데코 유도 = 이 대다수를 플라이휠(플레이→골드→데코→더 플레이)에 태워 판수·리텐션을 동시에 올리는 것.
단서: 선택 편향 있음(많이 논 유저가 골드 있어 데코함) → 게임 루프를 끊지 말고 클리어 후 자연 지점에서 유도. 그리고 입구(로딩/튜토) 수정이 선행 — 골드를 벌어야 데코를 찍으니, 입구에서 튕기면 데코 유도도 못 닿는다.
⚠ 실측 정정 (2026-07-16) — 에스더가 코지식 데코 방식을 판수 증대 목적으로 실제 적용했으나 판수가 유의미하게 안 늘었음. 즉 위 "42판 vs 3.2판"은 선택 편향이었고, 유도로 판수를 밀어 올리는 인과는 약하다. → 데코는 판수 레버가 아니라 리텐션·메타 관여 레버로 봐야 함. 이 트랙의 목적을 "판수↑"에서 "메타 진입·리텐션"으로 재설정.

기획 요청 사항

  • 첫 데코는 강제 튜토로 기획 클라 — 첫 세션에 데코 1개는 스킵 불가 튜토로 손 잡고 찍게. (연출은 짧게 — 트랙1과 같은 원칙.)
  • 첫 데코 해머 무료 지급 / 비용 면제 이코노미 정정 — 앞서 "골드 할인"이라 했으나 실제 게이트는 해머(첫 데코 3해머·신규 중앙 0). 골드가 아니라 스타터 해머를 주거나 첫 데코 해머비용 면제. 골드는 이미 남아돎(뺏기는 느낌 없음).
  • "한번에 꾸미기"(bulk) 도입 기획 클라 — 슬롯별 개별 탭 대신 한번에 여러 데코. 골드 단계는 안전(골드 남아도니 왕창 써도 "쌓인 걸 쓴다" 느낌). 단 해머 단계는 해머 공급이 전제 — 해머 없으면 bulk도 못 함.
  • 해머 획득처 강화 이코노미 — 해머가 진짜 병목이자 유일한 뺏기는 느낌의 원천. 게임 클리어·미션 보상으로 해머를 더 풀어 데코 루프를 돌게. (골드는 오히려 sink 필요 — 데코가 그 sink.)
  • 배치 즉시 보상 연출 아트 기획 — 도시가 눈에 띄게 변하고 별·골드가 튀는 피드백. "내가 바꿨다"를 강하게.
  • 클리어 골드 → 데코 동선 직결 기획 — 게임 클리어 보상 화면에서 도시·데코로 자연스럽게 흘리기(코지 패턴).
  • 도시 개방 가속은 보류 — 유저가 도시1도 안 채우는데 2·3 열어도 무의미. 첫 데코 유도로 진척 엔진부터 점화.

✅ 확정 — 첫 데코 무료 처리 방식 + 튜토 상태/재진입 (2026-07-16)

트랙2 "강제 튜토 + 무료" 메커니즘 미결분 확정. 별도 재화 지급 코드 없이 밸런스 시트 + UI만으로 첫 데코 튜토 완결.
  • ① 밸런스 시트 — 지정 스타터 데코 = 영구 0해머 이코노미 — 튜토 대상 오브젝트 1개만 해머 비용 0(영구). 조건부 비용 로직 불필요, 나머지 데코는 정상 비용 유지.
  • ② UI — 해당 오브젝트만 터치 가능 강제 + Free 버튼 클라 — 튜토 중 지정 오브젝트만 활성(나머지 잠금·가이드 하이라이트), 구매 버튼은 Free 노출. 기존 구매 플로우 그대로 재사용(cost=0).
  • ③ 재진입 예외 — 기존 튜토 체크포인트로 처리 (신규 플래그 X) 클라 — 배치 전 이탈 시 다음 세션 튜토 체크포인트에서 재개. 0해머 영구라 언제 돌아와도 Free. 데코 배치는 "상태"(반복 보상 아님) → 서버 권위·idempotent, 이중지급·어뷰징 벡터 없음.
  • ④ UX — 1탭 가볍게 기획 — 강제하되 무거운 연출 금지(튜토 인트로 2110 이탈 1위). 지정 오브젝트 하이라이트 → 1탭 → 즉시 배치 + 소액 보상.
핸드오프 — 이코노미: 시트에서 스타터 데코 0해머(영구) / 클라: 튜토 중 해당 오브젝트만 터치 강제 + Free 버튼 + 기존 튜토 체크포인트 재개. 신규 플래그·재화 지급 코드 불필요.

⏸ 보류 결정 (2026-07-16)

아래 상세 기획은 검토했으나 보류. 이유 3가지.
  • 레퍼런스에 없음 — 코지는 데코를 철저히 하나씩(2,101회 중 동시 2개+ 0건), 퍼블마는 데코 메타 자체가 없음. 벤치 두 게임 다 bulk 미보유.
  • 장르 페이싱과 상충 — 데코를 아껴 재방문 이유를 만드는 게 관행. 한 번에 다 꾸미면 콘텐츠 소진↑ → 이탈 위험.
  • 판수 효과 미검증(실측) — 코지식 데코 방식을 판수 증대 목적으로 실제 적용했으나 판수가 유의미하게 늘지 않음(에스더 실측). 데코의 "42판 vs 3.2판"은 선택 편향(많이 논 유저가 데코함)이었고, 유도로 판수를 밀어 올리는 인과는 약함.
결론 — 데코는 판수 레버가 아니라 리텐션·메타 관여 레버로 봐야 함. bulk는 필요 시 나중에 재검토. 아래 상세는 기록용(고민 이력 보존).

✨ 개요 — "한번에 꾸미기" = claim-all 편의성 버튼

무료 기능이 아니다. 첫 꾸미기(단일 1개)는 무료 강제 튜토(트랙2)가 담당하고, "한번에 꾸미기"는 그 이후 유저가 재화(해머·골드)를 모아 여러 데코를 살 수 있게 됐을 때, 하나씩 탭하지 않고 모인 재화로 살 수 있는 만큼 한 번에 적용해주는 편의 버튼. 여러 게임의 "claim all"과 같은 QoL.
  • 편의성(반복 제거) — 데코 여러 개를 하나씩 탭 대신 버튼 1개로. 특히 오래 안 하다 돌아와 재화가 쌓인 유저에게 유용.
  • 큰 시각 보상 — 여러 데코가 한 번에 올라가 도시가 확 변신 = 개별 1칸보다 강한 성취감.
  • 남아도는 골드 소비 — 약한 골드 sink 강화. 유저는 "뺏긴다"가 아니라 "쌓인 걸 드디어 쓴다" 만족.
정의 정정 — bulk = "가진 재화로 살 수 있는 걸 한 번에" 하는 편의(claim all). 실제 재화를 쓴다(무료 X). 무료 온보딩은 첫 단일 꾸미기가 담당.

💬 비용 확인 UX — "뺏기는 느낌" 방지

bulk의 리스크 = 확 쓰고 후회. 확정 전 미리보기로 통제감을 준다.
  • 확정 팝업 클라 기획 — "🔨 15  +  🪙 0  →  데코 5개 1단계" 처럼 총비용·결과를 보여주고 [확인]. 누르면 바로 빠지는 게 아니라 한 번 확인.
  • 범위 선택 — 어디까지 꾸밀지(1단계 / 2단계 / 완성) 토글·슬라이더로 유저가 선택. 강제 X.
  • 골드는 여유 강조 — "골드 5,250 (보유 8,967)"처럼 남는 걸 보여줘 부담 제거. 골드 부담 경고문 금지.
  • 해머 부족 시 — "해머 12 부족 → 가능한 3개만 꾸미기 / 해머 더 얻기(플레이)"로 부분 적용 + 획득 유도. 골드는 부족 케이스 사실상 없음.
