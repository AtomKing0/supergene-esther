메타 Play 이벤트 정리

2026-07-28 개최 · 현장 촬영 슬라이드 77장 판독 기준 · 통화 표기 SGD/USD 혼용(싱가포르 세션 추정)
발표: 페이스북 인스턴트 게임 플랫폼팀 · Hilda Zhang(Strategic Partnership Manager) · Sam Yang(Instant Games)
먼저 볼 것 다섯 가지
  1. 심사가 사람 판단에서 데이터 판단으로 완전히 바뀜. 주관 품질 점수 폐지, 객관 Pass/Fail 7개 기준만 남음. 심사 최대 10영업일, 반려 시 3일 쿨다운.
  2. CDR 가동 조건이 공식 확인됨 — 권역 DAU 300. 티어는 Promoted 상위 20% / Standard 상위 50% / Limited 나머지. 신호는 유저 평점·D14 리텐션·WAU@14 세 가지뿐.
  3. NEZP 마이그레이션 데드라인 2026-09-30. 이후 미이전 게임은 플랫폼에서 내려감. 남은 기간 두 달.
  4. Project Launchpad — 2026년 광고 크레딧 $2.5M+ 배정. NEZP 이전·품질 개선·C2P 개선 건당 2.5만~10만 달러 직접 지급. 신청은 SPM 경유. 우리가 지금 당장 노려볼 수 있는 실탄임.
  5. 수익화 세션 벤치마크 게임이 Solitaire Story - Tripeaks였음. 메타가 솔리테어 트라이픽스를 우수 사례로 스크린샷까지 떠서 설명함. 우리 장르가 플랫폼 레퍼런스라는 뜻이자, 비교 기준선이 이미 공개돼 있다는 뜻.

1. 플랫폼 방향성

메타가 스스로 밝힌 올해 우선순위 4가지

Canvas / NEZP 마이그레이션

수익 보호, 프라이버시·보안 리스크와 부담 축소

더 나은 배포

객관성·투명성 확보, 개발사 입장에서 흐름 단순화

개발자 도구

"도구가 부족하다는 피드백 듣고 있고 개선 중"이라고 직접 인정

새로운 기회

Reels 우선 및 그 너머 — 다수의 변화가 신규 트래픽/성장을 만들 수 있음

Reels 우선 전환

페이스북 유저가 Reels에 먼저 착지하는 구조로 앱이 재편되는 중이고, 게임도 그 흐름에 붙이겠다는 방향. 하위에 Reels-First Content 프로그램이 따로 붙어 있음(5장 참조).

미니 플레이어 테스트

게이밍 탭과 아케이드에서 인라인 Playable(피드 안에서 바로 플레이) 첫 실험 진행 중. 아직 테스트 단계라 별도 신청 안내는 없었음.

플랫폼 역사와 현재 위치

2007 Canvas → 2018 FB.gg/Live → 2023 통합(클라우드 레거시 종료) → 오늘 FB PLAY. 마무리 슬라이드에서는 PLAY / Horizon Mobile / VR / Wearables 4개 축으로 개발사를 지원한다고 정리함.

2. 심사 개편 — 인스턴트 게임 품질 심사(IGQR)

바뀐 지점 세 가지

구분과거현재
평가주관적 품질 루브릭(0~4점)객관 Pass/Fail — 명확한 7개 기준
판정 주체리뷰어가 판단플레이어가 판단 — engagement 신호
배치고정·영구 랩 배치연속적·유동적 유기 배포

심사 통과 기준 7개

Compliance

01 커뮤니티 표준 — 메타 플랫폼 가이드라인 완전 준수

02 현지화 — 타깃 시장 무관하게 영어는 완전 지원 필수

Performance

03 코어 게임플레이 — 심각한 버그·크래시·진행 블로커 없음, 로딩 30초 초과 금지

04 개발 완성도 — 플레이스홀더·미완성 기능·디버그 도구 잔존 금지

Integrity

05 투명성 — 기만적 설계·불명확한 수익화·강제 공유 금지

06 프로모션 — 크로스프로모는 'More Games' 메뉴로 한정, 화면 하이재킹 금지

07 일관성 — 스토어 이미지/아이콘이 실제 플레이를 정확히 표현

운영 규칙

  • 엄격한 Pass/Fail — 주관 점수 없음, 사실 기준 판정
  • 명확한 피드백 — 반려 시 무엇을 바꿔야 하는지 구체 피드백 제공
  • 심사 기간 최대 10영업일
  • 재제출 쿨다운 3일
  • 결과 확인은 DFC(Developer Feedback Center)에서. 정책 심사·품질 심사·인앱결제 심사 상태가 실시간 표시되고, 반려 시 근거 미디어까지 첨부됨

3. 배포 구조 — Play Tab과 CDR

01
게임 제출
기존 DFC 흐름, 필수 정책 심사 포함
02
품질 심사
객관 Pass/Fail 게이팅
03
Play Tab
초기 플레이어 신호·engagement 수집
04
CDR 유기 배포
자동 랭킹·성과 기반 연속 스케일링

Play Tab 진입과 CDR 가동 임계

  • EQRv4 통과 즉시 Play Tab 노출 — 대기 없음
  • CDR 알고리즘 가동 임계 = 권역 DAU 300 이상. 이 신호가 모여야 유기 배포 스케일링이 시작됨
  • 슬라이드에 "Pre distribution Boost (Upcoming)" 항목이 회색으로 잡혀 있었음 — 사전 배포 부스트가 준비 중이라는 뜻. 세부는 미공개

CDR 판정 신호 3개

유저 평점

썸업/썸다운 직접 피드백, 60일 롤링 윈도우로 산출

D14 리텐션

신규 유저 기준, 유저-앱 페어로 엄격 평가

WAU@14

주간 활성 유저를 롤링 리텐션으로 봄 — 지속 인게이지먼트 포착

권역 공정성과 데이터 신뢰성

  • 권역별로 따로 채점 — 북미 / 남미 / 유럽 / 아시아 / 아프리카·중동. 특정 권역에서 인기 있는 게임이 다른 권역 지표 때문에 불이익 받지 않음. 글로벌 폴백으로 커버리지 보장
  • 플랫폼 전반 신뢰성 확보 위해 권역 DAU 300 최소치를 강제

배포 티어

티어범위노출 지면
PROMOTED상위 20%탭 Top Picks, 아케이드 피처드, 피드 단일 게임 추천
STANDARD상위 50%전 플랫폼 Games Grid — 베이스라인 발견·성장
LIMITED그 외품질·인게이지먼트 개선이 필요하다는 신호
핵심 개념 — 티어는 고정이 아니라 유동. 배포는 연속적으로 돌아가고, 지표가 좋아지면 티어가 자동으로 올라감. 한 번 매겨지고 끝나는 등급이 아님.

DFC 신규 Curation 탭

  • 신규 배포 상태 표시 — EQRv4 통과 여부를 "PLAY_TAB" 상태로 확인
  • Curation 탭 — 게임 배포와 지표를 관리하는 전용 공간 신설
  • Pre-distribution 진행률(%) 표시 있음

컴플라이언스 부담 축소

롤아웃 컨트롤

  • 경로: DFC > Instant Games > Launch Status
  • 롤아웃 방식 선택 가능 — 단순 롤아웃 / 기존 유저 대 신규 유저 / 과금 유저 대 비과금 유저
  • 테스트 토글 — 어드민·개발자·테스터·리뷰어 롤에 한정 적용하거나 특정 유저 ID 허용·차단
  • 플레이어 리다이렉션 확인 및 특정 유저가 어느 마이그레이션 그룹인지 조회 가능
  • 롤아웃 비율이 0%를 넘어야 실제 마이그레이션이 시작됨, 그리고 한 번 켜면 되돌릴 수 없음

5. Project Launchpad — 광고 크레딧 지원 프로그램

인스턴트 게임 광고 크레딧 인센티브 프로그램. 2026년 $2.5M 이상의 광고 크레딧을 편성해 플랫폼 제품 채택을 유도하고, 개발사가 수익성 있게 성장하도록 리텐션과 C2P 광고 ROAS를 끌어올리는 것이 목적.

Partners Pillar — 직접 광고 크레딧 지급

플랫폼 커밋(마이그레이션, 품질 개선, C2P 연동) 대가로 개발사 계정에 광고 크레딧을 직접 입금하는 방식.

6. C2P 광고 운영 가이드

C2P가 왜 중요한가

마찰 제로

탭하면 바로 플레이 — 앱스토어·다운로드·설치 없음. 퍼널이 6단계에서 2단계로

전환율 약 30%

다운로드 장벽 제거로 클릭→설치 ~30%. NEZP 연동 이후 기존 앱 설치 광고 대비 훨씬 높음

ROAS 내장

메타 생태계 내 자연 어트리뷰션, 180일 수익 추적 윈도우

메타가 인정한 남은 과제: Monetisation Manager와 ROAS 툴 간 데이터 불일치, IAA 수익의 Ads Manager 통합은 아직 미완.

캠페인 세팅

  • 목표: App Promotion → Instant Games
  • 설치 최적화로 시작 → AEO(주당 이벤트 50건 이상 확보 후)와 CEO로 단계 상승
  • IAP ROAS 노릴 땐 Value Optimization 활성화
  • 데스크톱이 IAP 최우수 유저층

지역·오디언스 타기팅과 확장

  • 유사 오디언스는 구매자 또는 D7 잔존 유저 기준 1~3%로 시작
  • 시드 최소 1,000명, 5,000명 이상이 이상적
  • T1(미국·유럽)에서 먼저 검증, T2/T3는 CPI가 낮아 IAA용으로 활용
  • D30 ROAS 45% 초과를 확인한 뒤 확장
  • 확장 국면에서 유사 오디언스를 3~5%로 넓힘

7. 수익화 벤치마크 — IAA와 IAP

플랫폼 오디언스 실태

지역

아시아가 압도적 1위, 이후 남미 · 북미 · 아프리카 · 중미 · 유럽 순

플랫폼 OS

안드로이드가 압도적, iOS 소수, 웹/데스크톱은 극소수

설치 소스

광고 > 공유 > 오가닉 > 메신저 순

설치 소스 3종 실제 예시도 제시됨 — 공유(피드로, 토너먼트로), 오가닉(게임 탭, 게임 아케이드), 메신저(커스텀 업데이트, Play in Messenger).

오디언스 어필은 장르 경계를 넘음. 러너 게임(Elastic Car)과 퍼즐 게임(Arrows Escape)의 CTR과 D1 리텐션이 유사하게 나왔음. 페이스북에는 두 장르를 모두 즐기는 오디언스가 있다는 것이 메타의 결론.

9. 솔리테어 관점 시사점

1. 벤치마크 게임이 우리 장르였음

수익화 세션 전체의 레퍼런스 게임이 Solitaire Story - Tripeaks(App ID 755626824646698)였음. 에너지+소프트 재화 경제, 프리레벨·인게임 부스터, 럭키휠+유료휠, 돼지저금통, 보상형 광고 오퍼+스타터 번들, 배틀패스, 마일스톤 공유 화면까지 스크린샷 단위로 해부됨.

즉, 메타가 우리 게임에 기대하는 표준 구성이 그 슬라이드에 그대로 있음. 우리 현재 구성과 대조해 빠진 항목을 찾는 작업이 바로 가능.

2. CDR 임계 300 DAU가 공식 확인됨

기존에 파악하던 권역 DAU 300 기준이 메타 공식 슬라이드로 확인됨. 권역별 별도 채점, 글로벌 폴백도 명시됨. 크로스프로모로 300을 채우는 현재 전략이 구조적으로 맞다는 것이 재확인됨.

다만 CDR 신호가 평점·D14·WAU@14 세 가지뿐이라는 점이 중요. 판수·세션시간·매출은 티어 판정에 안 들어감. 트래커 지표 우선순위를 이 셋 중심으로 재정렬할 필요 있음.

3. Launchpad 신청 자격을 우리가 충족할 가능성 있음

Product Pillar Initiative 1(New Titles Sprint)은 출시 1년 미만 + 품질심사 통과 + 배너 광고 없음 + D1 리텐션 신호 강함 + NEZP 조건. 타이틀당 $40~50K 규모.

Partners Pillar는 NEZP 마이그레이션만으로 $25~50K. 어차피 9월 30일까지 해야 하는 작업이므로 크레딧을 받으면서 하는 것이 맞음. SPM 경유 신청이 유일한 경로이므로 Andre 쪽 확인이 선행돼야 함.

4. 배너 광고 폐지 로드맵 확인

배너는 2027년 1분기 폐지, 신규 게임에는 이미 비권장. Launchpad Initiative 1 선발 기준에도 "배너 광고 없음"이 명시돼 있음. 배너를 쓰고 있다면 선발에서 탈락 요인이 됨.

5. 전면 광고 빈도 곡선이 구체 수치로 제시됨

레벨 1~5 0% / 6~10 20% / 11~20 50% / 21+ 75%, 최소 60초 간격, 2세션 이상 유저부터. 우리 현재 노출 정책과 대조 가능한 명확한 기준선임.

6. 심사 기준 중 즉시 점검할 항목

로딩 30초 초과 금지가 Pass/Fail 항목에 들어 있음. 권역별 로딩 편차가 큰 상황에서 심사 리스크가 될 수 있음.

크로스프로모는 'More Games' 메뉴로 한정, 화면 하이재킹 금지. 현재 크로스프로모 배치가 이 규정에 저촉되는지 확인 필요.
