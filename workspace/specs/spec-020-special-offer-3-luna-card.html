배경 — 숨겨진 해금 조건의 문제

덱에는 루나의 뒷모습이 그려진 특별 카드백이 존재하며, 해금 조건은 Special Offer 3 구매 1회입니다. 그러나 현재 Special Offer 3 팝업 화면에는 이 카드백 해금에 대한 안내가 전혀 없습니다.

  • 현황: Special Offer 3을 구매해도 루나 카드백이 해금된다는 사실을 유저가 인지하지 못함 — 구매 후 우연히 덱 컬렉션에서 발견하는 구조
  • 기회: 희귀 전용 카드백은 수집 욕구를 자극하는 강력한 동기 — 구매 화면에 노출만 해도 전환율 향상 기대
  • 목적: Special Offer 3 팝업에 "루나 카드백 해금 포함" 섹션을 추가하여 유저가 구매 전 해금 혜택을 인지하게 만든다
  • 범위: 기존 팝업 레이아웃 하단에 루나 카드 안내 영역 1개 추가. 기존 보상 구성·가격·트리거 조건은 변경 없음
핵심 논리: 루나 카드백은 이미 게임에 존재하고, 해금 조건도 이미 special_offer_3에 연결되어 있다. 이 기획은 새로운 콘텐츠를 만드는 것이 아니라, 이미 있는 해금 조건을 구매 시점에 유저에게 알려주는 것이 전부다. 추가 비용 없이 전환율을 올릴 수 있는 가장 간단한 개선이다.

1-1 플레이어 경험 흐름

도시 완성 — Special Offer 3 팝업 트리거
유저가 도시 건설을 완성하면 special_offer_3 팝업이 노출된다 (limit_type: city, 도시당 최초 1회). 기존 흐름과 동일.
팝업 내용 확인 — 루나 카드 해금 섹션 발견
보상 목록(골드·부스터 등) 아래에 구분선과 함께 "보너스 해금" 섹션이 보인다. 루나 카드백 미리보기 썸네일 + "이 상품 구매 시 루나 카드백이 영구 해금됩니다" 문구.
이미 보유한 경우 — "이미 보유 중" 상태 표시
과거 special_offer_3을 이미 구매해 루나 카드백을 보유 중인 유저는 같은 섹션에 "이미 보유 중 ✓" 표시가 나타난다. 중복 구매 유도 오해 방지.
구매 완료 — 루나 카드백 해금 + 안내 토스트
구매 성공 시 기존 보상 지급과 함께 루나 카드백이 덱 컬렉션에 해금된다. 화면에 "루나 카드백이 해금되었습니다! 덱 컬렉션에서 확인하세요" 토스트가 표시된다.
덱 컬렉션에서 확인
유저가 덱 컬렉션 화면으로 이동하면 루나 카드백이 잠금 해제된 상태로 표시된다. 신규 해금 배지가 붙어 눈에 띄게 강조.

전체 방향성

  • 기존 Special Offer 3 팝업 레이아웃을 최대한 유지 — 기존 보상 영역에 영향을 주지 않는 하단 추가 섹션 형태
  • 루나 카드백은 게임 내 이미 존재하는 에셋이므로 별도 신규 아트 제작 필요 없음 (기존 카드백 썸네일 재사용)
  • 섹션은 가볍고 우아하게 — 팝업의 주 보상 영역보다 시각적으로 한 단계 낮은 강도로, 보조 정보처럼 보여야 함
  • 고급스러운 느낌을 위해 별·달 등 루나 테마 색상(딥 퍼플, 골드 강조)을 은은하게 적용

루나 카드 해금 섹션 방향성 메모

  • 카드 썸네일은 실제 루나 카드백 에셋을 그대로 사용 (별도 신규 제작 불필요)
  • 섹션 배경은 딥 퍼플~다크 계열 그래디언트 — 카드의 신비로운 느낌과 어울리는 조용하고 깊은 톤
  • 별 장식은 과하지 않게 소량만 — 메인 보상 영역보다 절제된 느낌
  • 이미 보유 중인 경우: 카드 썸네일 위에 반투명 오버레이 + "이미 보유 중 ✓" 텍스트, 색조는 흐릿하게 처리
  • 구매 완료 후 토스트 아이콘은 루나 카드백 썸네일 작게 포함

UI 표시 로직

루나 카드 해금 섹션 노출 조건

  • special_offer_3 팝업이 열릴 때 항상 루나 카드 해금 섹션을 표시한다
  • 해당 유저가 루나 카드백을 이미 보유 중인 경우 → 섹션을 그대로 표시하되, 카드 썸네일에 오버레이를 씌우고 "이미 보유 중 ✓" 문구로 대체
  • 해금 여부 판단 기준: 유저 인벤토리(덱 컬렉션) 내 루나 카드백 보유 플래그

구매 완료 후 처리

  • 기존 보상 지급 로직과 동일한 흐름에서 루나 카드백 해금 처리
  • 구매 성공 콜백에서 "루나 카드백이 해금되었습니다! 덱 컬렉션에서 확인하세요" 토스트 노출
  • 토스트 탭 시 덱 컬렉션 화면으로 이동 (딥링크)
  • 덱 컬렉션 화면에서 루나 카드백 항목에 "NEW" 배지 표시 (기존 신규 해금 배지 정책 그대로 적용)

엣지 케이스

케이스처리 방법
구매 완료 후 루나 카드백 해금 API 실패 보상 지급은 정상 완료로 처리. 해금 실패는 별도 재시도 큐에 등록. 토스트는 표시하지 않고 다음 접속 시 자동 복구
이미 보유 중인 유저가 (미래에 재구매 가능해질 경우) 구매 시 루나 카드백 해금 이벤트를 중복 발생시키지 않음. 이미 해금 상태면 스킵
덱 컬렉션 미오픈 상태 (is_deck_collection_open = 0) 루나 카드 해금 섹션은 팝업에 그대로 노출하되, 토스트의 덱 컬렉션 딥링크 버튼은 숨김 처리. 덱 컬렉션 오픈 시 자동으로 해금 상태 반영
팝업 노출 중 루나 카드 해금 상태 조회 실패 (네트워크) "해금 예정" 상태로 기본 표시 (미보유 가정). 보수적으로 노출하는 것이 UX에 유리
