왜 만드는가 — AS-IS / TO-BE

내용
AS-IS데일리 3종(기프트·태스크·룰렛) 전부 당일 리셋 → 다주차 목표·복귀 앵커 없음. 오늘 안 오면 잃는 건 있어도, "이어서 쌓는 것"이 없음.
TO-BE14일 트랙 → 데일리/위클리 퀘가 데코·도시·토너·앨범·이벤트로 유도 → 티어 보상 누적 → 완주 목표로 매일 복귀 → 완주 후엔 보너스 상자로 시즌 끝까지 유지. D7·D14를 직접 겨냥.

패스는 새 콘텐츠가 아니라 디렉터형 레버다 — 기존 시스템(레벨·해머·데코·토너·앨범)으로 유저를 라우팅하는 진척 트랙. 진척은 플레이와 직결(승리 1판 = XP)이라 별도 그라인드가 없고, 보상은 해머 중심으로 데코 플라이휠(리텐션 로드맵 P1 진행 체스트와 동일 sink)에 연료를 공급한다.

플레이어 경험 흐름

1
시즌 시작 — 로비 위젯 + 인트로 팝업

"루나 시즌 패스 · 뉴욕 시즌 ⏳14일" 노출. 30티어 보상 미리보기(잠금 포함)로 목표 심기. 프리미엄 줄은 자물쇠(🔒 8/12)로 보이기만.

2
플레이 = 진척

레벨 승리 1판마다 XP +1. 결과 화면에 패스 게이지 인라인 노출("다음 레벨까지 3판") — 진행 체스트(P1) 게이지와 나란히.

3
퀘스트 = 라우팅

데일리 퀘 3종 + 위클리 퀘 2종이 데코 배치·도시 진척·토너·앨범·스트릭으로 유저를 보낸다. 완료 시 보너스 XP.

4
티어 도달 → 클레임

도달 칸에 글로우 + [받기] 배지. 미수령 누적 시 로비 위젯에 빨간 배지 N → 패스 진입 → "받을 보상 N" 일괄 수령.

5
티어 30 완주 → 시즌 한정 카드덱 + 보너스 상자 루프

완주 트로피(카드덱) 수령 연출 후, 사다리 끝이 보너스 상자 게이지로 전환. 이후 15XP마다 상자 1개 → 랜덤 보상. 시즌 종료까지 반복 — 완주해도 매판이 상자를 채운다.

6
종료 임박 — 복귀 노티

D-3·D-1 "시즌 N일 남음 — 받을 보상 M개" 노티(로드맵 P3 노티 윈백과 문구 공유). 로비 위젯 타이머 빨간 강조.

7
시즌 종료 → 정산 팝업 → 리스킨 재시작

도달분 미수령 보상 자동 지급, 종료 후 첫 진입 시 정산 팝업(받은 내역 + 다음 시즌 예고). 다음 시즌 = 다음 도시 테마. 8/12 후에는 이 시점이 프리미엄 소급 구매의 마지막 압박 지점.

  • 교체 범위 = 테마 레이어만. 사다리 UI·게이지·칸 프레임은 공통 프리팹 고정, 배경 일러스트·헤더 로고·시즌명·위젯 아이콘만 도시별 교체(CCS 리스킨 운영 방식). 시즌 1 = 루나 · 뉴욕(자유의 여신·타임스퀘어 모티프), 이후 도시 순서 = 메타 도시 순서(meta_city_list) 따름.
  • 시즌 한정 카드덱 (시즌당 1종 · 핵심 신규 에셋): 도시 테마 카드백. 기존 collection_deck 포맷(카드백 1장 소재) 그대로 — 뉴욕 시즌 = 루나+뉴욕 스카이라인 카드백. 완주 전에는 T30 칸에서 실루엣+"?"로 노출(목표 견인), 다음 시즌 예고에도 실루엣 재사용.
  • 재활용: Collections 나무 프레임 · 기존 보상 아이콘(해머·골드·부스터) · 진행바 컴포넌트 · 보너스 상자는 P1 진행 체스트 소재 색변형.
  • 트랙 컬러: 무료 = 파란 라벨(참여감·깔끔), 프리미엄 = 주황/골드 라벨(프리미엄감·자물쇠 반투명 45%). 무료 트랙이 초라해 보이면 안 됨 — 완주 동기의 주인공은 무료 줄.
  • 연출: 티어 클레임 = 짧은 개봉 연출(1초 내, Royal Pass flow GIF 참조). 레벨업 = 게이지 오버플로우 → 마커 숫자 +1 팝. 완주 = 카드덱 회전 공개 연출(1회성, 가장 화려하게). 보너스 상자 개봉 = 흔들림→터짐 숏 연출. (타이밍 수치는 개발 변수로 관리 — 아트 가이드에 수치 고정 금지)
  • 신규 에셋 리스트: ① 시즌 헤더 로고(도시별) ② 프리미엄 자물쇠 오버레이 ③ 시즌 한정 카드덱(도시별 1종) ④ 보너스 상자(체스트 색변형) ⑤ 로비 위젯 아이콘(도시별) ⑥ 정산 팝업 프레임. CCS 에셋 규모 참고: 패스 전체 ~120개(Base 60 + 시즌 리스킨 55) — 우리는 재활용 중심으로 그 이하 목표.

완주 가능성 검증 (240XP / 14일):
· 캐주얼 (승리 4판/일 · 데일리 퀘 2/3 완료 · 위클리 4개 중 2개): (4 + 10)×14 + 40 = 236 + α ≈ 완주선 — 딱 맞게 설계. 데일리 퀘 3개를 다 하면 여유 완주(276XP).
· 코어 (승리 10판/일 · 퀘 전부): (10 + 15)×14 + 80 = 430XP → 약 9일차 완주 → 잔여 5일은 보너스 상자 루프(잉여 190XP ≈ 상자 12개).
· 라이트 (승리 2판/일 · 퀘 1개): (2+5)×14 + 40 = 138XP → 티어 17 부근. 중후반 보상(해머 밀집 구간)이 남아 다음 시즌 재도전 동기.
승리 판수 XP만으로는 완주 불가(승리만 17판/일 필요) — 퀘 참여가 필수 경로가 되도록 의도한 설계다. 판수 벤치 변동 시 req_xp 계단만 조정.

티어 보상표 (30티어 전체 · 전면 유동화)

무료 = 즉시 오픈. 프리미엄 = 노출 + 잠금(🔒 8/12), premium_enabled=1 전까지 클레임 불가. 아이템 키는 PST_item_list(40001~) 실키 사용.

본 트랙도 전면 유동화 (Rev.5): 보상 수량이 유저 레벨에 따라 자동 스케일된다.
· 골드 = tier_scaled — 시트에는 계수만 기재, 지급량 = 현재 level_entry_tier 입장비 × 계수 (기존 tier_combo_reward 루틴 재사용). 초반 유저(입장비 1,000)는 아래 계수 그대로 ×1,000, 후반(입장비 5,000 cap)은 5배.
· 해머 = band_scaled — 시트의 base 수량 × 레벨 밴드 배율 hammer_band_multiplier (A 1.0 / B 1.5 / C 2.0, 올림). 도시 해머 수요 곡선(뉴욕 54 → 파리~방콕 124~164 → 카이로~리우 205~235)을 따라간다.
· 부스터·티켓·인피닛 = 개수 고정 — 부스터는 소모 비용 자체가 입장비 비례(entry_cost_ratio: fireworks 60%·golden_ticket 80%·wild 50%)라 개수 고정이 이미 가치 유동. UI는 항상 "내 레벨 기준 실제 지급량"으로 표시(계수 노출 금지).

완주 후 보너스 상자 — 레벨 밴드별 가중 가챠 풀

티어 30 완주 후에도 XP는 동일 규칙(승리+퀘)으로 계속 적립. bonus_box_xp_cost(=15XP)마다 상자 1개 개봉 가능. 미개봉 bonus_box_stack_max(=3개)까지 적립, 시즌 종료 시 개봉 가능분 자동 개봉 후 정산 팝업에 내역 표시.

보상은 고정 풀이 아니라 유저 레벨 밴드에 따라 가중치·수량이 유동적으로 바뀐다. 근거: ① 도시 해머 수요가 후반으로 갈수록 급증(뉴욕 54 → 리우 235) — 후반 유저일수록 해머 가중↑ ② 골드 가치는 입장비와 함께 변동 — 고정액 대신 레벨 티어 비례 스케일. 구현은 기존 streak_reward의 reward_type: tier_combo_reward(티어 비례 동적 수량) 패턴을 그대로 준용 — 신규 로직 없음.

엣지 케이스

  • 시즌 중 신규 유저 합류: 합류 시점부터 XP 0 시작. 남은 기간으로 완주 불가할 수 있음 — 정상(다음 시즌 완주 동기). 초반 5XP 계단 덕에 며칠만 해도 티어 5~10 보상(해머)은 도달 → 첫 데코 연료는 확보됨.
  • 데코 미해금 유저: place_deco·city_progress 퀘 미발급, 다른 타입으로 대체 추첨.
  • 완주 직전~직후 XP 경계: 240XP 도달 판에서 잉여 XP는 상자 게이지로 이월(버리지 않음).
  • 상자 스택 초과: 미개봉 3개 상태에선 게이지 충전 정지·XP 대기 표시("상자를 열어주세요"). 개봉하면 대기 XP부터 이어서 충전 — 개봉 강제가 아니라 손실 없는 대기.
  • 시즌 종료 직전 승리: 종료 판정은 서버 타임스탬프. 종료 시각 이전 승리는 XP 인정 → 자동 정산에 포함.
  • 시간 조작: 퀘 갱신·시즌 종료 전부 서버 UTC 기준. 클라 로컬 시간 신뢰 금지.
  • 일괄 수령 중 중단(앱 킬): 티어별 claimed 비트를 지급 성공 단위로 커밋 — 부분 지급 후 재실행 시 남은 것만 지급.
  • 카드덱 중복: 같은 시즌 덱은 1회만 지급(소유 플래그). 재수령 시도는 무시.
