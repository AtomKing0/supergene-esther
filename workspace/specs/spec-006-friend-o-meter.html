Friend-O-Meter — 친구 초대 누적 보상

친구를 더 많이 초대할수록 더 큰 보상을 받는 소셜 루프 시스템. 전체 공동 달성(안 A)과 개인 누적 달성(안 B) 두 가지 안을 함께 검토합니다.

왜 만드는가

캐주얼 카드 게임에서 오가닉 신규 유입은 마케팅 비용 대비 효율이 낮고 지속성이 떨어집니다. 소셜 초대는 CPI 없이 유저를 데려오는 몇 안 되는 수단이지만, 보상 없는 초대 버튼은 사실상 방치됩니다. 초대 행동에 명확한 보상 루프를 붙여 기존 유저의 초대 동기를 만드는 것이 이 기능의 목적입니다.

레퍼런스: Candy Crush Solitaire — Friend-O-Meter 참고.

플레이어 경험 흐름 — 안 A (전체 공동 미터)

1
미터 노출

메인 화면 또는 소셜 탭에서 현재 전체 초대 진행 게이지와 "목표까지 N명 남음"을 상시 표시. 긴박감을 주는 숫자가 핵심.

2
초대 행동

유저가 초대 링크를 공유. 링크를 통해 가입한 친구가 자격 조건(일정 판 수 플레이)을 충족하면 전체 카운터에 +1 합산.

3
목표 달성 알림

전체 목표 수 달성 시 참여한 유저(최소 1명 이상 초대)에게 보상 지급 알림 발송. 보상은 자동 지급 또는 수동 수령 방식 선택.

4
다음 라운드 자동 시작

목표 달성 후 미터 리셋, 새 라운드 즉시 시작. 유저는 다시 초대 행동을 이어갈 동기를 얻음.

플레이어 경험 흐름 — 안 B (개인 누적 미터)

1
개인 미터 노출

내 초대 현황 카드: "친구 N명 초대 완료 / 다음 단계까지 M명". 단계별 보상 미리보기로 다음 목표를 명확히 인식.

2
초대 행동

링크 공유 → 친구 가입 + 자격 조건 충족 시 개인 카운터 +1.

3
단계 달성 → 즉시 보상

임계값 돌파 시 단계 보상 즉시 지급. 게이지 채워지는 시각 피드백과 함께 보상 팝업 표시.

4
다음 단계 동기 부여

다음 단계 보상 미리보기로 연속 초대 행동을 유도. 최고 단계 달성 후에는 영구 기록 뱃지 또는 월별 리셋 구조 검토.

비주얼 방향성

안 A — 전체 공동 미터

전체 유저가 함께 만들어가는 느낌을 강조합니다. 게이지는 두껍고 따뜻한 색감으로, 채워질수록 밝아지는 인상을 줍니다. 남은 수 텍스트가 시각적 중심이 되어야 합니다 — 이것이 긴박감의 핵심입니다. 달성 임박 시 게이지 끝부분에 은은한 글로우 효과를 추가하면 흥분감이 올라갑니다.

  • 게이지: 진행 방향이 명확한 수평 바. 달성 마커가 중간중간 표시되어 진행감을 줍니다.
  • 내 기여 표시: 작게, 하지만 눈에 띄게. "나도 참여하고 있다"는 소속감 강조.
  • 카운트다운: 남은 일수가 항상 보여야 합니다. 조용하지만 놓치지 않게.
안 B — 개인 누적 미터

내 성취를 중심에 두는 개인화된 느낌입니다. 현재 단계가 시각적으로 두드러지고, 다음 단계의 보상이 명확하게 보여야 합니다. 단계 달성 시에는 보상 획득 애니메이션이 즉각적이고 만족스럽게 재생되어야 합니다.

  • 단계 표시: 원형 노드 스타일. 달성 단계는 색상 채워짐, 현재 단계는 테두리 강조(펄스 효과), 미달성은 회색.
  • 숫자 강조: 내가 초대한 수를 대형 숫자로 중앙에 표시. 성취감의 핵심.
  • 다음 목표 유도: 남은 초대 수와 보상을 명시한 배너가 항상 노출.

애니메이션 방향성

  • 게이지 채워짐: 새 초대 집계 시 게이지가 스르르 늘어나는 느낌. 급격하지 않고 부드럽게.
  • 단계 달성 (안 B): 노드가 터지듯 채워지고 보상 아이템이 위에서 쏟아지는 파티클 효과. 짧고 화려하게.
  • 달성 임박 (안 A): 남은 수가 일정 이하로 줄어들면 게이지 끝단에 부드러운 글로우가 켜짐.
  • 수치 하드코딩 금지 — 애니메이션 타이밍은 개발 스펙 변수로 관리.

필요 에셋

  • 친구 아이콘 (공통): 2~3명의 실루엣이 함께 있는 따뜻한 느낌의 아이콘. 게임 캐릭터 스타일과 통일.
  • 게이지 바 텍스처 (선택): 단순 컬러 블록이 아닌 약간의 텍스처나 패턴으로 생동감 추가 가능. 없어도 무방.
  • 단계 달성 이펙트 (안 B): 기존 보상 획득 파티클 재사용 가능 여부 개발팀 확인 필요.
  • 초대 버튼: 기존 공유 버튼 스타일 재활용 가능. accent 컬러 적용.

진입점: 메인 화면 하단 탭 또는 소셜 탭 내 고정 카드로 진입. 새 초대 달성 시 메인 화면에 소형 배지 알림 표시 검토.

트리거 조건 — 유효 초대 처리

  • 초대 링크를 통해 신규 유저가 가입 완료
  • 가입 후 friend_meter_qualify_day_limit일 이내에
  • friend_meter_qualify_play_count판 이상 플레이 완료 시
  • → 초대자 카운터 +1 (안 A: 전체 서버 카운터, 안 B: 개인 카운터)

상황처리 방식
동일 기기 다계정같은 기기에서 friend_meter_abuse_block_same_device_count 초과 시 어뷰징 플래그, 카운터 미집계

안 A 전용 — 서버 집계 처리

  • 전체 카운터는 서버 단일 진실 소스 (Single Source of Truth). 클라이언트 로컬 캐시 금지.
  • 클라이언트는 friend_meter_global_refresh_count_sec 주기로 서버 폴링 또는 실시간 푸시 수신.
  • 목표 달성 시 서버에서 참여 유저 목록 추출 → 보상 배치 지급 → 미터 자동 리셋.
  • 기간 만료 시 목표 미달성이면 미터 리셋 (보상 없음), 다음 라운드 즉시 시작.

안 B 전용 — 개인 단계 처리

  • 단계 달성은 서버에서 판정 후 클라이언트에 이벤트 전달.
  • 보상은 달성 즉시 자동 지급. 미수령 팝업 별도 불필요 (단, 오프라인 달성 시 다음 접속 때 알림).
  • 최고 단계(5단계) 달성 후 추가 보상 없음 — 미터 UI는 유지하되 "최고 단계 달성" 상태 표시.
  • 월별 리셋 여부는 PM 결정 필요 (기본: 리셋 없음, 영구 누적).
