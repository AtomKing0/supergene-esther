데일리 태스크 토큰 누적량 표시

Daily Tasks 팝업 상단 진행 바에서 현재 누적 보유 토큰 수를 숫자로 표시한다. 플레이어가 다음 마일스톤까지 얼마나 남았는지 직관적으로 파악할 수 있게 한다.

문제

현재 Daily Tasks 팝업 상단의 진행 바는 토큰 진행도를 막대 길이로만 표현한다. 플레이어는 지금 토큰이 몇 개인지, 다음 마일스톤(30·60·100)까지 얼마나 남았는지 직접 계산해야 한다.

예시: 진행 바가 30%쯤 차 있을 때 "내가 지금 몇 개야? 30개 중에 몇 개 받은 거지?"라는 의문이 생김. 숫자 없이는 목표까지의 거리를 체감하기 어려움.

제안

진행 바 좌측 토큰 아이콘 우측에 현재 누적 토큰 수 / 다음 마일스톤 목표 형태로 숫자를 표시한다.

표시 형식 (안)

형식예시비고
현재량만♣ 35단순, 공간 효율적
현재 / 다음마일스톤♣ 35 / 60목표 인지 명확, 권장안
잔여량♣ 25 남음긴박감 강조, 텍스트 길이 가변

권장: ♣ 35 / 60 형식. 현재 위치와 목표를 동시에 전달하여 "앞으로 25개만 더"라는 목표감 생성.

데이터 소스

참조 변수
daily_task_token_count int 플레이어의 현재 누적 데일리 태스크 토큰 보유량. 기존에 진행 바 계산에 사용 중인 값 그대로 활용.
next_milestone_threshold int 다음 미달성 마일스톤 값 (30 / 60 / 100 순). 현재 토큰량 기준으로 동적 계산.

표시 로직

  • 마일스톤 배열 [30, 60, 100]에서 daily_task_token_count보다 큰 첫 번째 값 = next_milestone
  • 모든 마일스톤 달성 시: next_milestone = null → 숫자만 표시
  • 표시 문자열: next_milestone이 있으면 "{count} / {next_milestone}", 없으면 "{count}"

신규 서버 작업 없음. 이미 진행 바 렌더링에 사용 중인 토큰 카운트 값을 UI 텍스트로 추가 출력하는 것이므로 클라이언트 UI 수정만 필요.
