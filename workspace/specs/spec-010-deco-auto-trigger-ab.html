기획 의도 & 흐름
개발 + 아트 공통
왜 테스트하는가
  • 꾸미기 시스템은 메타 핵심 콘텐츠이나, 자발적 진입률이 낮은 유저군 존재
  • 재화가 충분히 쌓였는데도 꾸미기를 안 하는 유저 → 인식 부족 or 진입 마찰
  • 자동 진입으로 꾸미기 경험을 강제 노출 → 진행률 상승 + 재화 sink 활성화 기대
  • 단, 강제 전환이 불편함으로 느껴질 경우 리텐션 하락 리스크 → 실측 필요
A안 (현재)
  • 꾸미기는 유저가 원할 때 언제든 자유 진입
  • 로비에 꾸미기 버튼 상시 노출
  • 재화 충족 여부와 무관하게 알림 없음
B안 (테스트)
  • 꾸미기 재화가 다음 데코 아이템 구매 가능 수준에 도달하면
  • 게임 결과 화면 → 로비 복귀 시 자동으로 꾸미기 화면 전환
  • 꾸미기 완료(또는 스킵) → 로비 자동 복귀
B안 플레이어 경험 흐름
1
레벨 클리어 — 결과 화면 표시
2
재화 충족 감지 — 서버에서 다음 구매 가능 아이템 체크. 충족 시 플래그 세팅
3
자동 전환 — 로비로 복귀하는 대신 꾸미기 화면으로 전환. 짧고 부드러운 전환 연출
4
꾸미기 진행 — 구매 가능한 아이템 하이라이트 표시. 유저가 자유롭게 구매 또는 스킵
5
로비 복귀 — 꾸미기 완료 또는 "나중에" 버튼 → 로비로 돌아옴
성공 지표 & 전제
  • 주요: B안 유저의 데코 진행률(완성 아이템 수)이 A안 대비 유의미하게 높음
  • 부수: 재화 소비량 증가 (골드 sink 활성화)
  • 허용 범위: D1/D7 리텐션 하락 없거나 미미한 수준
  • 실패 기준: 리텐션 유의미한 하락 (강제 전환이 불쾌감으로 작용)
  • 타깃 우선: 재화 보유 중이나 꾸미기 미진행 유저군에 먼저 적용 고려
2
아트 가이드
아트팀 전용
방향성
  • 자동 전환 연출: 갑작스럽지 않게 — 살짝 페이드 또는 슬라이드로 꾸미기 화면 등장. 놀라거나 끊기는 느낌 없도록
  • 꾸미기 화면 진입 배너: "지금 꾸밀 수 있어요!" 같은 가이드 텍스트를 화면 상단에 가볍게 — 강제가 아니라 초대받는 느낌
  • 구매 가능 아이템 하이라이트: 구매 가능한 데코 아이템을 은은하게 강조 (빛나거나 테두리 강조). 과하지 않게
  • "나중에" 버튼: 명확하지만 주인공이 되지 않도록 — 보조적 위치, 차분한 컬러
B안 — 자동 꾸미기 진입 흐름 와이어프레임
필요 에셋
  • 자동 진입 배너 텍스트 — "지금 꾸밀 수 있어요!" 혹은 그에 상응하는 카피 (로컬라이징 필요)
  • 구매 가능 아이템 하이라이트 이펙트 — 기존 잠금/해제 UI 확장으로 처리 가능한지 개발 확인 필요
  • 화면 전환 애니메이션 — 기존 씬 전환 에셋 재활용 우선 검토

개발 스펙
개발팀 전용
밸런스 시트 변수
TAB: const
ab_deco_auto_trigger_variant 0 0=A안(자유 진입), 1=B안(자동 진입). 서버 플래그로 그룹 분기
ab_deco_auto_cooldown_count — 자동 진입 후 다음 자동 진입까지 최소 플레이 판수 (연속 강제 방지)
트리거 & 분기 조건
  • A/B 그룹 배정: 유저 ID 기반 해시로 50:50 분기 (서버 결정)
  • B안 발동 조건: ab_deco_auto_trigger_variant == 1 AND 현재 보유 골드 ≥ 다음 데코 아이템 가격
  • 발동 시점: 레벨 클리어 결과 화면에서 로비 복귀 직전
  • 쿨다운: 자동 진입 후 ab_deco_auto_cooldown_count 판 동안 재발동 억제 (도배 방지)
  • 억제 조건: 이미 모든 데코 아이템 구매 완료 유저 / 튜토리얼 미완료 유저
측정 이벤트
  • ab_deco_auto_triggered — 자동 진입 발동 횟수
  • ab_deco_purchased — variant(a/b), source(auto/manual), item_id
  • ab_deco_skipped — "나중에" 선택 횟수 (B안에서 강제 스킵 비율 모니터링)
  • 데코 진행률: 유저별 구매 완료 아이템 수 스냅샷 비교
엣지 케이스
  • 재화가 딱 맞게 있어 구매 후 0원이 되는 경우 → 정상 허용 (유저 선택으로 구매하는 것)
  • 자동 진입 중 앱 백그라운드 전환 → 복귀 시 로비로 자연 복귀, 자동 진입 재발동 없음
  • 테스트 종료 후: 채택안으로 ab_deco_auto_trigger_variant 고정, 쿨다운 값 조정
