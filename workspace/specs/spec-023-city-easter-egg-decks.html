시티 이스터에그 덱 스킨

완성된 도시 속 특정 오브젝트를 터치하면 전용 덱 스킨을 획득하는 숨겨진 보상 시스템.
힌트 없이 직접 발견하는 재미 · 소셜 바이럴 · 메타 재방문 동기 부여.

왜 만드는가

현재 도시 완성 후 메타 화면은 보상 팝업 → 로비 복귀 흐름으로 완성된 도시를 다시 열어볼 이유가 없다. 이스터에그 덱 스킨은 "혹시 뭔가 더 있지 않을까?"라는 탐색 욕구를 자극해 완성 도시 재방문율을 높이고, 소셜 공유("이거 알았어?") 바이럴 포인트를 만든다.

  • 덱 스킨은 상점·이벤트·보상으로 얻을 수 없는 이스터에그 전용 아이템
  • 발견 여부를 힌트 없이 운영 — 아는 유저가 알려주는 입소문 구조
  • 도시 수 확장 시 자연스럽게 이스터에그도 추가 → 콘텐츠 업데이트 포인트

아트 가이드
아트팀 전용

이스터에그 오브젝트 배치 원칙

  • 오브젝트는 도시 장식물 사이에 자연스럽게 녹아들어야 함 — 일부러 띄우거나 빛나게 하지 않는다
  • 탭 히트박스는 충분히 크게 (손가락 터치 여유 확보), 시각적으로는 작게
  • 발견 시 리액션은 작고 귀여운 이모션 — 놀람·반짝임·살짝 움직임 정도, 폭발적인 연출 금지
  • 오브젝트 자체는 기존 도시 아트 에셋과 동일 아트 스타일로 제작

오브젝트 → 팝업 연출 흐름 (와이어프레임)

탭 → 작은 리액션 → 보상 팝업. 팝업은 덱 미리보기 + 받기 + 공유 3요소.

보상 팝업 디자인 방향

  • 배경: 반투명 딤 처리 (도시 씬이 살짝 비침)
  • 팝업 헤더: "이스터에그 발견!" + 달걀 이모션 — 깜짝 발견의 기쁨
  • 덱 미리보기: 실제 카드 앞면·뒷면 애니메이션 (느리게 회전)
  • 전체 톤: 도시별 컬러와 연동 (NY=노란, Venice=핑크·보라 등)
  • "이미 보유 중" 상태일 때는 팝업 대신 짧은 토스트 메시지

트리거 & 억제 조건

항목조건
트리거도시 완성 상태(is_completed=true) + easter_egg_deck_in_use=1 + 해당 이스터에그 in_use=TRUE + 유저가 해당 도시 씬에서 prop_id 오브젝트 탭
억제: 미완성 도시도시 미완성 상태에서는 오브젝트 탭해도 반응 없음 (이스터에그 이벤트 바인딩 안 함)
억제: 이미 수령동일 계정에 deck_item_key 이미 보유 시 팝업 대신 토스트 메시지 ("이미 보유한 덱입니다")
억제: 전체 기능 OFFeaster_egg_deck_in_use=0이면 모든 오브젝트 반응 비활성화

상태 처리 & 서버 저장

  • 이스터에그 수령 여부: 서버 유저 데이터에 easter_egg_collected: [key_number_list] 형태로 저장
  • 덱 스킨 지급: 기존 아이템 지급 API 재사용 (item_list의 deck_skin 타입 처리 필요 여부 확인)
  • 보상 팝업 → [받기] 탭 시 서버에 수령 기록 후 아이템 지급 → 클라 인벤토리 반영
  • 오프라인 중 탭: 수령 처리 온라인 복귀 시 동기화 (또는 온라인 필수 처리 — 정책 결정 필요)

z-index & 엣지 케이스

  • 이스터에그 팝업 z-index: 도시 씬 UI보다 위, 시스템 팝업(네트워크 오류 등)보다 아래
  • 도시 씬 진입 직후 탭: 씬 로딩 완료 이벤트 이후에 이스터에그 바인딩 활성화
  • 같은 세션 내 다른 도시 이스터에그 연속 발견: 팝업 큐 처리 (동시 2개 표시 금지)
  • 덱 스킨 타입이 item_list에 없을 경우 폴백: 보상 없음 + 로그 기록 (지급 실패 사일런트)
  • 도시가 이후 순서 재배치될 경우: easter_egg_deck은 city_id 기준이므로 영향 없음
⚠️ 덱 스킨 타입 확인 필요: 현재 item_list에 deck_skin type이 정의되어 있지 않음. 신규 타입 추가 또는 기존 타입 재사용 여부를 개발팀과 선확인.
