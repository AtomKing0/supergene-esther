SPEC-008 📌 기타 🔴 높은 우선순위 ✅ 완료 2026. 4. 6.

share_reward_in_use 런칭 후 ON

공유 보상 기능 활성화 — App Store 리뷰 통과 후 즉시 처리 필요

[결론] 완료 — share_reward_in_use 런칭 후 ON 적용. 공유보상은 2종으로 구성:

  • 도시 완성 공유 — 도시(꾸미기) 완성 지점에서 발동 (경로 3500).
  • 친구 추월 공유 — 친구를 앞지른(p2p_win) 지점에서 발동 (경로 3600 p2p_win).
⚠️

트리거: App Store 리뷰 통과 확인 → 즉시 처리. 잊으면 공유 보상 기능 미동작 상태로 라이브 됨.

①
배경 & 사유
개발 + 아트 공통
배경 & 사유
  • 왜 껐는가 — Meta(Facebook) 앱 리뷰 정책상, 리뷰 중 공유 보상 기능이 정책 위반으로 리젝 리스크가 있음. 리뷰 통과를 위해 임시로 OFF 처리.
  • 다른 게임 현황 — 동일 스펙을 라이브에서 이미 사용 중인 게임이 있음. 우리 게임도 동일하게 포함 예정.
  • 관련 스펙 — spec-002 공유 지면 3종 설계 (hidden spot, 마일스톤, 이벤트 피드 공유 보상)
②
작업 내용
개발팀 전용
작업 내용
  • CONST 탭 → share_reward_in_use 값을 0 (OFF) 에서 1 (ON) 으로 변경
  • 변경 후 에이전트 시트 → 라이브 시트 동기화 (시트 수정 워크플로우 준수)
  • QA: 공유 보상 플로우 전체 검증 (hidden spot 공유 → 보상 지급 확인)
③
체크리스트
개발 + 아트 공통
체크리스트
  • App Store 리뷰 통과 확인
  • 에이전트 시트 share_reward_in_use → 1 변경
  • 라이브 시트 동기화 완료
  • QA: hidden spot 공유 보상 지급 확인
  • QA: 마일스톤 공유 보상 지급 확인
  • QA: 이벤트 피드 공유 보상 지급 확인
④
히스토리
개발 + 아트 공통
히스토리
  • 2026. 4. 6. 일감 등록 — 런칭 리뷰 대비 share_reward_in_use OFF 처리 결정. 리뷰 통과 후 ON 전환 예정으로 이슈 트래킹 시작.
