Explorer Rush

카드를 제거할 때마다 탐험 조각이 자동 카운트되어 마일스톤 보상을 달성하는 주중 이벤트. Royal Color Collection과 동일한 자동 카운트 로직, 탐험/도시 테마 적용.

왜 만드는가

동일한 자동 카운트 로직을 탐험/도시 테마로 재맥락화하여, 기존 이벤트에 익숙해진 유저가 새로운 맥락에서 동일한 참여 패턴을 반복하도록 유도한다.

  • 클리어 보상형 — 레벨 클리어 시에만 조각 획득. quit 시 해당 판 미적립
  • 메타 도시 연계 — 현재 진행 중인 도시 테마와 에셋 공유, 세계관 일관성
  • 주중 리텐션 방어 — 별도 미션 없이 플레이만으로 자연스러운 접속 동기 부여

플레이어 경험 흐름

1
이벤트 진입
로비 배너 또는 이벤트 허브에서 Explorer Rush 진입. 현재 탐험 조각 수와 마일스톤 진행도 확인.
2
레벨 플레이
레벨 클리어 시 탐험 조각 획득. quit 시 해당 판 미적립.
3
진행도 피드백
레벨 종료 후 로비 복귀 시 조각 수 증가 피드백 노출. 다음 마일스톤까지 잔여 수량 표시.
4
마일스톤 달성
목표 수량 도달 시 로비 전면 팝업 노출 → 즉시 보상 수령.
5
다음 목표 유도
팝업에서 다음 마일스톤 목표와 보상 미리보기 표시 → 계속 플레이 동기 부여.

와이어프레임

인게임 화면 — 우측 하단 탐험 조각 카운터 뱃지. 카드 제거 시 "+1" 이펙트 발생. 하단 소형 진행 바 선택 적용.
마일스톤 진행 팝업 — 3단계 노드, 현재 수집량, 다음 보상 미리보기. 최종 스텝은 잠금 상태로 표시.

방향성

전체 무드: 탐험 일지/손때 묻은 지도 느낌. 오렌지/황갈색 계열로 따뜻하고 모험심 있게. 배너는 지도+나침반 모티브, 메타 도시 컬러 언어 연속성 유지.

인게임/팝업: 카운터 이펙트는 가볍고 짧게 — 카드 제거 리듬 방해 금지. 팝업은 차분한 성취감으로, 다음 목표를 은은하게 노출. 등장 애니메이션은 easeOut 계열.

트리거 조건

  • 이벤트 활성 기간 중 레벨 클리어(clear) 이벤트 발생 시 자동 카운트 — quit 시 미적립
  • 카운트는 서버 사이드 누적. 클라이언트 단독 처리 불가
  • 마일스톤 도달 시: 로비 진입 시점에 팝업 큐에 추가

억제 조건

  • 이벤트 기간 외 카운트 적립 불가
  • 팝업 동시 노출 방지 — 다른 전면 팝업 처리 완료 후 순차 노출
  • 마일스톤 중복 지급 방지 — 서버 수령 플래그 확인 후 지급

큐 & 상태 처리

  • 여러 마일스톤이 동시에 달성된 경우 (오프라인 누적 후 동기화): 순차 팝업 노출
  • 이벤트 종료 시 미수령 마일스톤 → 우편함 자동 발송
  • 이벤트 기간 중 앱 강제 종료 / 재접속 시 서버 기준으로 카운트 복원

엣지 케이스

  • 최종 마일스톤 달성 후 추가 조각 수집: 카운터 최댓값 고정 표시 (초과분 숨김 처리)
  • 이벤트 시작 전 플레이 카운트는 이벤트 시작 타임스탬프 기준으로 필터링
  • 오프라인 플레이 후 동기화: 서버 수신 시 일괄 카운트 반영, 순차 마일스톤 팝업
  • 이벤트 재오픈(리런) 시 진행도 초기화 여부: 기획 확정 필요
