그림자 냥이 추격전 (Shadow Cat Chase)

판수 증대 데일리 스프린트. 그림자 냥이가 열쇠를 물고 달아났어요! 유저가 25분 안에 8판을 완주해 따라잡는 손실회피 훅. 그림자 냥이는 본체 미등장(🐾자국·실루엣 귀+발만), 루나가 길잡이 담당. 로비 복귀 후 우선 팝업(보상 정산·출석 등) 소화 → 발동 연출 자동 재생(사이클당 1회). 원형 = Candy Crush Solitaire "Catch the Troll".

핵심 수치 — 25분/8판 · 기간 월 00:00~목 23:59(매주 반복·event_schedule 160005 1행) · 유저 로비 복귀 기준 사이클·쿨다운 12h(cooldown_sec 43200) · 언락 Lv10 클리어 · 팝업 소화 후 자동 발동(사이클당 1회) · 배수(×N) 없음(티어 차이 = 체스트 보상 내용만).

정의

스프린트 목표 8판은 NRU가 하루에 걸쳐 치는 판수와 같은 양임. 이를 25분 창에 압축해 그날 판수를 2배 이상 끌어올리는 구조임. 실패해도 몰수 없음이라 다운사이드 없음. 발동 시퀀스(체스트 발견→열쇠 강탈→도주→마킹→행잉태그)는 원본 CCS "Catch the Troll"을 간소화 이식함.

1-1 발동 시퀀스 — 7단계

원본 CCS "Catch the Troll" 발동 흐름을 GIF·스크린샷 6장으로 프레임별 참고함. 각 단계는 원본 서술 → 루나 이식안 병기. 핵심 심리 = 보상을 먼저 '내 것'으로 보여주고(소유 효과) → 뺏기고 → 되찾으러 뛰게(손실회피). 기간 내·쿨다운 경과·로비 복귀 시 자동 발동, 시퀀스 종료 시점부터 25분 타이머 시작.

🐾 아트 필독 — 레퍼런스 시퀀스 간소화 이식

레퍼런스 시퀀스는 간소화하여 진행함. 완전 재현 아님. 핵심 연출 4종(①발견 ②열쇠 강탈 ③도주 ④밧줄 태그)으로 구성하되, 각 연출은 자국·스프라이트 중심의 경량 연출이라 컷별 부담은 크지 않음. 스플래시·파티클·도주 경로 등 세부 연출은 아트 재량으로 대폭 축소 가능.

그림자 냥이가 열쇠를 훔쳐 달아나는 캐릭터 풀 애니메이션은 제작하지 않음. 단순화하여 진행함. 캐릭터 본체 끝까지 미등장 — 고양이 발톱 자국·발바닥 자국으로 표현 — ①강탈=화면 밖에서 앞발이 슥 들어와 열쇠 채감+발톱 긁힘 이펙트 ②도주=발바닥 자국 트레일이 로비를 가로질러 점점이 찍히며 열쇠 아이콘 이동 ③마킹=플레이 버튼 발바닥 자국 1개 ④실패=자국이 화면 밖으로 사라지며 열쇠 페이드아웃.

원본 발동 시퀀스 전체 흐름 (CCS "Catch the Troll" · 11초 · 161프레임) — 체스트 발견 → 열쇠 강탈 → 로비 도주 → 플레이 버튼 마킹 → 프리레벨 행잉 태그

① 체스트 발견

루나 이식: 로비 풀스크린 "그림자 냥이가 열쇠를 물고 도망쳤어요! 25분 안에 8판을 깨고 따라잡아요" + 체스트 보상 미리 공개(Normal 6슬롯(골드·해머·와일드카드·되돌리기·파이어웍스·무료 입장 티켓) / Jackpot 6슬롯(+데코 조각 — 부록·v1 OFF). 수량은 event_shadow_chest 시트). 루나는 안내·응원 역할로 등장.

flow-02 · 열쇠 강탈 (Grab)

루나 이식: 화면 밖에서 고양이 앞발이 슥 들어와 열쇠를 채감 + 🐾발톱 긁힘 이펙트(캐릭터 본체 미등장·상태 GRAB). 연출 중 입력 잠금.

루나 이식: 루나 아이콘 + "그림자 냥이가 열쇠를 물고 도망쳤어요! 같이 잡아요!" + [확인]. 보상 패널 계속 노출 유지(손실회피 강화). [확인] = InfoPopup의 [Ok]와 동일 — 별도 [참가] 버튼 없음.
flow-04 · 도주 (Escape)

④ 도주 (Escape)

[Ok] 후 로비 복귀. 트롤이 열쇠를 들고 메타 맵을 가로질러 날아 달아남, 핑크 젤리 자국을 남김. 도주 경로의 종착 = 플레이(레벨) 버튼.

루나 이식: 🐾발바닥 자국 트레일이 로비를 가로질러 점점이 찍히며 열쇠 아이콘 이동(캐릭터 이동 애니 없음·상태 ESCAPE). 종착 = 플레이 버튼. 연출 중 입력 잠금.
flow-05 · 플레이 버튼 마킹

⑤ 플레이 버튼 마킹

트롤이 플레이 버튼(LEVEL)에 젤리를 묻히고 사라짐 → 이벤트 진행중 상시 표시가 플레이 버튼 자체에 생김. 입장 동선에 직접 마킹 = 다음 행동 유도.

루나 이식: 플레이 버튼에 🐾발바닥 자국 1개 상시 표시(상태 RUNNING). 스프린트 진행 중 로비 진입점 역할. 인게임 HUD·타이머 위젯 없음 — 타이머·n/8 인지는 프리레벨 행잉 태그에서만.
flow-06 · PreLevelPlayWidget

⑥ 프리레벨 밧줄 태그

프리레벨 팝업 우측 밧줄에 체스트 + 남은시간(26m 15s) + 진행바 "Get the key after 8 levels" 행잉 태그.

루나 이식: 프리레벨 팝업 우측 기존 진행 이벤트 밧줄 문법 재활용 — 체스트 + 남은시간 + "8판 완주 시 열쇠 획득" 진행바. 배수 배지 미표시(티어 차이 = 체스트 보상 내용만). 보상 = Normal 6슬롯(골드·해머·와일드카드·되돌리기·파이어웍스·무료 입장 티켓) / Jackpot 6슬롯(+데코 조각 — 부록·v1 OFF). 수량은 event_shadow_chest 시트. 태그 위 그림자 냥이 실루엣 상주 — 귀 끝+열쇠 든 발만 태그 밖으로 노출(정체 미공개), 스프린트 진행 중 상시·실패 시 열쇠와 함께 사라짐.
⑦ · 지급 (결과 화면 통합)

⑦ 체스트 보상 — 8판째 결과 화면 통합 (3컷 시퀀스)

별도 오픈 연출·팝업 없음. 8판째 클리어 판의 결과 화면에서 처리: ① 행잉 태그 게이지 8/8 만충·글로우 → ② 태그의 체스트가 팝 하고 열리며 🐾파티클이 보상 아이콘(골드·해머·와일드카드·되돌리기·파이어웍스·무료 입장 티켓 (수량 = event_shadow_chest 시트))으로 날아감 → ③ 태그 소멸·체스트 기여 항목(코인·해머)에 🐾마킹 완착. 태그가 보상으로 변환되며 사라지는 인과를 시각화. 이 결과 화면에서는 "광고 보고 ×2 받기"·홈 버튼을 노출하지 않음(이벤트 지급분 배수 혼란 방지) — [받기] 단일 버튼, 수령 후 자연 로비 복귀.

루나 이식: 결과 화면(PopupCompleteLevel) 확장만으로 구현 — 태그 소멸 Tween + 파티클 + 보상 아이콘 🐾뱃지 오버레이. 실패 시엔 이 시퀀스 없이 태그 비노출 전환.

인포 팝업 — 이벤트 안내 (ⓘ 버튼)

진입: 프리레벨 행잉 태그·결과 화면 행잉 상자의 ⓘ 버튼 탭 시 표시. 발동 연출(최초 1회 시청) 이후 규칙을 다시 확인하는 수단. 구성 = 서사(실루엣+열쇠) → 목표(체스트·"8판이면 열쇠를 되찾아요") → 체스트 보상 6슬롯 미리보기(골드·해머·와일드카드·되돌리기·파이어웍스·무료 입장 티켓 (수량 = event_shadow_chest 시트)) + 남은 시간 + [X] 닫기.

루나 이식: 신규 팝업 1종(PopupEventShadowChase 소관·PopupBase 문법). 보상 패널 수치는 event_shadow_chest 시트 연동 — 하드코딩 금지.
