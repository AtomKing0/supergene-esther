왜 판수인가

스프린트 목표 8판은 현재 NRU가 하루에 걸쳐 치는 판수와 같은 양임. 이를 25분 창에 압축하는 장치 = 성공 시 그날 판수가 사실상 2배 이상 뛰는 구조임. 실패해도 몰수 없음이라 다운사이드 없음. 이 스펙은 마스터 기획서(2층 구조)의 레이어2 스프린트 실행본이며, 특히 발동 시퀀스(체스트 발견→도난→도주→마킹→행잉태그)를 원본 프레임별로 확정함.

1-1 발동 시퀀스 — 7단계 (원본 프레임별 실측)

원본 CCS "Catch the Troll"의 발동 흐름을 GIF·스크린샷 6장으로 프레임별 실측함. 각 단계는 원본 서술 → 우리 이식안 병기. 핵심 심리 = 보상을 먼저 '내 것'으로 보여주고(소유 효과) → 뺏기고 → 되찾으러 뛰게(손실회피).

원본 발동 시퀀스 전체 흐름 (CCS "Catch the Troll" · 11초 · 161프레임) — 체스트 발견 → 열쇠 도난 → 로비 도주 → 플레이 버튼 마킹 → 프리레벨 행잉 태그
flow-01 · ChestFound

① 체스트 발견

이벤트 시작 시 로비 풀스크린: "Congratulations! You found a Legendary Chest" + Chest rewards 패널에 코인 7,850 + 부스터 6종을 전부 미리 공개 + "Tap to Collect".

심리: 보상을 먼저 '내 것'으로 보여줌 = 소유 효과.

루나 이식: 로비 풀스크린 "루나 체스트를 발견했어요!" + 체스트 보상(해머 8·골드 500·부스터) 미리 공개. 원본 6종 대신 우리 v1 체스트 구성 노출.
flow-02 · Grab

② 열쇠 도난 (Grab)

화면 밖에서 핑크 젤리 촉수가 들어와 체스트의 황금 열쇠를 낚아챔. 핑크 스플래시 연출. (보상 패널은 계속 노출)

루나 이식: 화면 밖에서 그림자 손/그림자 덩굴이 들어와 황금 열쇠를 낚아챔. 스플래시는 핑크 대신 루나 세계관 컬러(보라/그림자)로 리스킨. APK 상태 = Grab.
flow-03 · ChestFound.Story

③ 스토리 팝업

트롤 아이콘 + "Oh no! Bubblegum Troll stole the chest key. Quick, we have to catch him!" + [Ok]. 보상 패널은 계속 노출된 채 = 잃을 것을 보며 읽음.

루나 이식: 그림자 고양이 아이콘 + "앗! 그림자 고양이가 열쇠를 훔쳤어요. 서둘러 잡아야 해요!" + [확인]. 보상 패널 계속 노출 유지(손실회피 강화).
flow-04 · Escape

④ 로비 도주 (Escape)

[Ok] 후 로비 복귀. 트롤이 열쇠를 들고 메타 맵을 가로질러 날아 도망, 핑크 젤리 자국을 남김. 도주 경로의 종착 = 플레이(레벨) 버튼.

루나 이식: 그림자 고양이가 열쇠를 물고 로비 메타 맵을 가로질러 도주, 발자국/그림자 자국을 남김. 종착 = 플레이 버튼. APK 상태 = Escape.
flow-05 · Small 위젯

⑤ 플레이 버튼 마킹

트롤이 플레이 버튼(LEVEL)에 젤리를 묻히고 사라짐 → 이벤트 진행중 상시 표시가 플레이 버튼 자체에 생김. 입장 동선에 직접 마킹 = 다음 행동 유도.

루나 이식: 플레이 버튼에 그림자 고양이 발자국/그림자 마킹 상시 표시. 스프린트 진행 중 로비 진입점 역할. 원본 Small 위젯 상태에 대응.
flow-06 · PreLevelPlayWidget

⑥ 프리레벨 밧줄 태그

프리레벨 팝업 우측 밧줄에 체스트 + 남은시간(26m 15s) + 진행바 "Get the key after 8 levels" 행잉 태그.

주의: 이 GIF 회차는 "x1 rewards" → 원본 배수는 회차별 변동(무지개 게이지). 우리 v1은 고정 ×5(단순화·콜드스타트) — 차이 명기.

루나 이식: 프리레벨 팝업 우측 기존 진행 이벤트 밧줄 문법 재활용 — 체스트 + 남은시간 + "8판 완주 시 열쇠 획득" 진행바. 배수는 회차 변동 없이 고정 ×5 표시.
⑦ 보상 지급: 원본은 체스트 보상을 별도 팝업 없이 결과 화면에 묶어 지급. 우리 제안(확정 반영): 결과 화면 보상 리스트에서 이벤트 보상을 "🐱 루나의 추격" 뱃지로 특별 표시 → 일반 판 보상과 구분 · 이벤트 기여 체감. (상세 §4)
