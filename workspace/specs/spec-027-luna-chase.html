정의

스프린트 목표 8판은 NRU가 하루에 걸쳐 치는 판수와 같은 양임. 이를 25분 창에 압축해 그날 판수를 2배 이상 끌어올리는 구조임. 실패해도 몰수 없음이라 다운사이드 없음. 발동 시퀀스(체스트 발견→열쇠 강탈→도주→마킹→행잉태그)는 원본 CCS "Catch the Troll"을 간소화 이식함.

1-1 발동 시퀀스 — 7단계

원본 CCS "Catch the Troll" 발동 흐름을 GIF·스크린샷 6장으로 프레임별 참고함. 각 단계는 원본 서술 → 루나 이식안 병기. 핵심 심리 = 보상을 먼저 '내 것'으로 보여주고(소유 효과) → 뺏기고 → 되찾으러 뛰게(손실회피). 슬롯 열림 + 로비 진입 시 자동 발동, 시퀀스 종료 시점부터 25분 타이머 시작.

🐾 아트 필독 — 레퍼런스 시퀀스 간소화 이식

레퍼런스 시퀀스는 간소화하여 진행함. 완전 재현 아님. 핵심 연출 4종(①발견 ②열쇠 강탈 ③도주 ④밧줄 태그)으로 구성하되, 각 연출은 자국·스프라이트 중심의 경량 연출이라 컷별 부담은 크지 않음. 스플래시·파티클·도주 경로 등 세부 연출은 아트 재량으로 대폭 축소 가능.

그림자 냥이가 열쇠를 훔쳐 달아나는 캐릭터 풀 애니메이션은 제작하지 않음. 단순화하여 진행함. 캐릭터 본체 끝까지 미등장 — 고양이 발톱 자국·발바닥 자국으로 표현 — ①강탈=화면 밖에서 앞발이 슥 들어와 열쇠 채감+발톱 긁힘 이펙트 ②도주=발바닥 자국 트레일이 로비를 가로질러 점점이 찍히며 열쇠 아이콘 이동 ③마킹=플레이 버튼 발바닥 자국 1개 ④실패=자국이 화면 밖으로 사라지며 열쇠 페이드아웃.

원본 발동 시퀀스 전체 흐름 (CCS "Catch the Troll" · 11초 · 161프레임) — 체스트 발견 → 열쇠 강탈 → 로비 도주 → 플레이 버튼 마킹 → 프리레벨 행잉 태그
flow-01 · ChestFound

① 체스트 발견

이벤트 시작 시 로비 풀스크린: "Congratulations! You found a Legendary Chest" + Chest rewards 패널에 코인 7,850 + 부스터 6종 미리 공개 + "Tap to Collect".

루나 이식: 로비 풀스크린 "그림자 냥이가 열쇠를 물고 도망쳤어요! 25분 안에 8판을 깨고 따라잡아요" + 체스트 보상 미리 공개(Normal 6슬롯: 골드500·해머×3·와일드·undo×2·폭죽·티켓 / Jackpot 6슬롯: 골드1,000·해머×6·데코조각·와일드×2·undo×2·폭죽×2). 루나는 안내·응원 역할로 등장.
연출 입력 잠금: 풀스크린 터치 가드 — 최초 1회 필수 시청 후 [Ok] 노출. 재노출부터 탭 스킵 허용.
flow-02 · 열쇠 강탈 (Grab)

② 열쇠 강탈 (Grab)

화면 밖에서 핑크 젤리 촉수가 들어와 체스트의 황금 열쇠를 낚아챔. 핑크 스플래시 연출. (보상 패널은 계속 노출)

루나 이식: 화면 밖에서 고양이 앞발이 슥 들어와 열쇠를 채감 + 🐾발톱 긁힘 이펙트(캐릭터 본체 미등장·상태 GRAB). 연출 중 입력 잠금.
flow-03 · ChestFound.Story

③ 스토리 팝업

트롤 아이콘 + "Oh no! Bubblegum Troll stole the chest key. Quick, we have to catch him!" + [Ok]. 보상 패널은 계속 노출된 채 = 잃을 것을 보며 읽음.

루나 이식: 루나 아이콘 + "그림자 냥이가 열쇠를 물고 도망쳤어요! 같이 잡아요!" + [확인]. 보상 패널 계속 노출 유지(손실회피 강화). [확인] = InfoPopup의 [Ok]와 동일 — 별도 [참가] 버튼 없음.
flow-04 · 도주 (Escape)

④ 도주 (Escape)

[Ok] 후 로비 복귀. 트롤이 열쇠를 들고 메타 맵을 가로질러 날아 달아남, 핑크 젤리 자국을 남김. 도주 경로의 종착 = 플레이(레벨) 버튼.

루나 이식: 🐾발바닥 자국 트레일이 로비를 가로질러 점점이 찍히며 열쇠 아이콘 이동(캐릭터 이동 애니 없음·상태 ESCAPE). 종착 = 플레이 버튼e). 연출 중 입력 잠금.
flow-05 · 미니 위젯 (Small)

⑤ 플레이 버튼 마킹

트롤이 플레이 버튼(LEVEL)에 젤리를 묻히고 사라짐 → 이벤트 진행중 상시 표시가 플레이 버튼 자체에 생김. 입장 동선에 직접 마킹 = 다음 행동 유도.

루나 이식: 플레이 버튼에 🐾발바닥 자국 1개 상시 표시(상태 IDLE_WIDGET). 스프린트 진행 중 로비 진입점 역할.
flow-06 · PreLevelPlayWidget

⑥ 프리레벨 밧줄 태그

프리레벨 팝업 우측 밧줄에 체스트 + 남은시간(26m 15s) + 진행바 "Get the key after 8 levels" 행잉 태그.

루나 이식: 프리레벨 팝업 우측 기존 진행 이벤트 밧줄 문법 재활용 — 체스트 + 남은시간 + "8판 완주 시 열쇠 획득" 진행바. 배수 배지 미표시(티어 차이 = 체스트 보상 내용만). 보상 = Normal 6슬롯: 골드500·해머×3·와일드·undo×2·폭죽·티켓 / Jackpot 6슬롯: 골드1,000·해머×6·데코조각·와일드×2·undo×2·폭죽×2. 태그 위 그림자 냥이 실루엣 상주 — 귀 끝+열쇠 든 발만 태그 밖으로 노출(정체 미공개), 스프린트 진행 중 상시·실패 시 열쇠와 함께 사라짐.
