왜 만드는가

소셜 공유는 가장 저비용의 획득 채널이지만, 공유할 가치 있는 순간이 설계되어야 동작합니다. 현재 게임에는 플레이어가 자발적으로 공유하고 싶어질 만한 특별한 순간이 없습니다.

세 가지 공유 지면은 각각 발견의 기쁨(히든 스팟), 성취의 자랑(레벨 마일스톤), 보상의 즐거움(이벤트 수령)을 공유 계기로 삼아 골드 인센티브와 결합합니다.

공유 지면 3종 개요

구분 출현 조건 공유 인센티브 차별화 에셋
A. 시티 히든 스팟 로비 도시 배경에 일정 확률로 ? 스팟 출현. 탭하면 비밀 공간 모달 표시 hidden_spot_reward_gold_amount (500골드) 도시별 전용 이미지 필요 (21종, 도시당 1개)
B. 레벨 마일스톤 피드 특정 레벨 최초 클리어 시 마일스톤 축하 카드 표시 milestone_share_reward_gold_amount (1000골드) 레벨 번호 삽입용 마일스톤 배지 프레임 (1종)
C. 이벤트 보상 수령 피드 이벤트 마일스톤 보상 수령 완료 직후 공유 지면 표시 event_share_reward_gold_amount (1500골드) 이벤트 테마 공유 카드 배경 (이벤트별)

공통 플레이어 경험 흐름

1
특별한 순간 발생

히든 스팟 출현 / 레벨 마일스톤 달성 / 이벤트 보상 수령

2
공유 지면 표시

해당 순간을 담은 비주얼 카드 또는 모달이 표시됩니다.

3
공유 선택

플레이어가 공유 버튼을 탭하면 OS 공유 시트가 열립니다. 건너뛰기 가능합니다.

4
골드 보상 지급

공유 완료 시 골드 보상이 즉시 지급됩니다. 쿨다운 내 중복 지급 없음.

인센티브 원칙: 공유 보상은 게임 경제를 보조하는 수준이어야 합니다. 과도한 보상은 인플레이션을 유발합니다. 수치는 밸런스 시트에서 경제 팀이 관리합니다.

⚠ 확정 필요 — 문서 내 서술 상충 (2026-07-31 서버 핸드오프 감사)

  • hidden_spot_appearance_per_city 설명 "시티당 최대 출현 횟수 (기간 내)" vs 문서 어디에도 '기간' 정의 없음 — 카운터 리셋 주기(일/주/도시 체류 기간 등) 스키마가 갈림.
  • 엣지 케이스 "유효시간 만료 중 모달 오픈 시 공유 가능 유지" vs hidden_spot_validity_duration_min "만료 시 자동 소멸" — 만료 후 공유 허용 grace 범위(무제한 유지 vs 시간 제한)가 갈림.

기준 시각: 기준 시각 = UTC 0시 단일축(PST 라이브 관례 — 데일리 리셋·타 이벤트 동일). 토스 플랫폼(KST 서버) 확장 시 경계 9시간 차 확인 필요.

hidden_spot_config.milestone_share_reward_gold_amount = 1000 amount 레벨 마일스톤 공유 완료 시 지급 골드. key: 20005
hidden_spot_config.event_share_reward_gold_amount = 1500 amount 이벤트 보상 수령 공유 완료 시 지급 골드. key: 20006
hidden_spot_config.share_cooldown_sec = 14400 sec 공유 보상 쿨다운. 14400초 = 4시간. 3종 지면 통합 쿨다운. key: 20007
hidden_spot_config.share_exposure_max_per_session = 5 count 세션당 공유 지면 최대 노출 횟수 (3종 합산). key: 20008

공통 쿨다운 및 노출 제어

  • 3종 지면 모두 동일한 hidden_spot_config.share_cooldown_sec 쿨다운 풀 공유
  • 세션당 최대 hidden_spot_config.share_exposure_max_per_session회 (3종 합산). 초과 시 해당 세션 추가 노출 없음
  • 공유 완료 여부: OS 공유 completion handler 수신으로 판단 (단순 시트 열기 제외)
