왜 만드는가

소셜 공유는 가장 저비용의 획득 채널이지만, 공유할 가치 있는 순간이 설계되어야 동작합니다. 현재 게임에는 플레이어가 자발적으로 공유하고 싶어질 만한 특별한 순간이 없습니다.

세 가지 공유 지면은 각각 발견의 기쁨(히든 스팟), 성취의 자랑(레벨 마일스톤), 보상의 즐거움(이벤트 수령)을 공유 계기로 삼아 골드 인센티브와 결합합니다.

공유 지면 3종 개요

Surface A
시티 히든 스팟
로비 도시 배경에 일정 확률로 ? 스팟이 출현합니다. 탭하면 해당 도시의 비밀 공간 이미지가 나타나고, 공유하면 골드를 받습니다.
Surface B
레벨 마일스톤 피드
특정 레벨 도달 시 마일스톤 축하 카드가 표시됩니다. 레벨 달성 정보를 공유하면 골드를 받습니다.
Surface C
이벤트 보상 수령 피드
이벤트 보상을 수령하는 순간 공유 지면이 표시됩니다. 보상 수령 장면을 공유하면 골드를 받습니다.

공통 플레이어 경험 흐름

1
특별한 순간 발생

히든 스팟 출현 / 레벨 마일스톤 달성 / 이벤트 보상 수령

2
공유 지면 표시

해당 순간을 담은 비주얼 카드 또는 모달이 표시됩니다.

3
공유 선택

플레이어가 공유 버튼을 탭하면 OS 공유 시트가 열립니다. 건너뛰기 가능합니다.

4
골드 보상 지급

공유 완료 시 골드 보상이 즉시 지급됩니다. 쿨다운 내 중복 지급 없음.

인센티브 원칙: 공유 보상은 게임 경제를 보조하는 수준이어야 합니다. 과도한 보상은 인플레이션을 유발합니다. 수치는 밸런스 시트에서 경제 팀이 관리합니다.

개발팀 전용

밸런스 시트 변수 (신규 탭 생성 필요)

신규 탭: hidden_spot_config  ·  key_number 대역: 20001~20008  ·  담당: 02_경제_밸런스
hidden_spot_config.hidden_spot_appearance_rate = 1000 ratio_10000 히든 스팟 출현 확률. 1000 = 10%. key: 20001
hidden_spot_config.hidden_spot_appearance_per_city = 3 count 시티당 최대 출현 횟수 (기간 내). key: 20002
hidden_spot_config.hidden_spot_validity_duration_min = 30 count (분) 히든 스팟 유효 시간(분). 만료 시 자동 소멸. key: 20003
hidden_spot_config.hidden_spot_reward_gold_amount = 500 amount 히든 스팟 공유 완료 시 지급 골드. key: 20004
hidden_spot_config.milestone_share_reward_gold_amount = 1000 amount 레벨 마일스톤 공유 완료 시 지급 골드. key: 20005
hidden_spot_config.event_share_reward_gold_amount = 1500 amount 이벤트 보상 수령 공유 완료 시 지급 골드. key: 20006
hidden_spot_config.share_cooldown_hours = 14400 sec 공유 보상 쿨다운. 14400초 = 4시간. 3종 지면 통합 쿨다운. key: 20007
hidden_spot_config.share_exposure_max_per_session = 5 count 세션당 공유 지면 최대 노출 횟수 (3종 합산). key: 20008

시트 수정 절차: 에이전트 시트(1Z6VGk…)에 hidden_spot_config 탭 신규 생성 → 8행 입력 → 연두색 하이라이트 → PM 확인 → 라이브 시트(1oLbps…) 동기화 → 확인 → 하이라이트 제거. 담당: 02_경제_밸런스 에이전트.

Surface A: 히든 스팟 로직

항목상세
출현 트리거로비 진입 또는 일정 주기마다 hidden_spot_config.hidden_spot_appearance_rate 확률로 스팟 생성
출현 위치도시 배경 내 사전 정의된 앵커 포인트 중 랜덤 1곳. HUD/메타 UI 영역과 비겹침 보장 필요 (아트팀 앵커 정의)
최대 출현시티당 hidden_spot_config.hidden_spot_appearance_per_city회 제한. 서버 또는 로컬 카운트
유효 시간hidden_spot_config.hidden_spot_validity_duration_min분 경과 시 자동 소멸 (퇴장 애니메이션 포함)
공유 완료 판정OS 공유 completion callback 수신 시. 공유 시트 열기만으로는 보상 지급 안 됨
골드 지급hidden_spot_config.hidden_spot_reward_gold_amount, 쿨다운 hidden_spot_config.share_cooldown_hours초 이내 재지급 없음

Surface B: 레벨 마일스톤 로직

항목상세
마일스톤 레벨 정의별도 테이블 필요 (예: 50, 100, 150, 200, …). 초기 구현 후 시트 탭으로 이관 예정
트리거마일스톤 레벨 최초 클리어 시 1회. 동일 레벨 중복 표시 없음 (서버 기록 필요)
표시 타이밍레벨 결과 화면(Win) 이후 또는 로비 복귀 시
골드 지급hidden_spot_config.milestone_share_reward_gold_amount, 공통 쿨다운 적용

Surface C: 이벤트 보상 수령 피드 로직

항목상세
트리거이벤트 마일스톤 보상 수령 완료 직후
표시 조건보상 수령이 완전히 완료된 경우에만. 1회성 보상에만 적용 권장
골드 지급hidden_spot_config.event_share_reward_gold_amount, 공통 쿨다운 적용

공통 쿨다운 및 노출 제어

  • 3종 지면 모두 동일한 hidden_spot_config.share_cooldown_hours 쿨다운 풀 공유
  • 세션당 최대 hidden_spot_config.share_exposure_max_per_session회 (3종 합산). 초과 시 해당 세션 추가 노출 없음
  • 공유 완료 여부: OS 공유 completion handler 수신으로 판단 (단순 시트 열기 제외)
