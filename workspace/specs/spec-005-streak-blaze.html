기획 의도 & 콘텐츠 흐름

개발 + 아트 공통

왜 만드는가

Golden Stamp Tour가 "첫 시도 클리어(First Try)"로 질적 집중을 유도했다면, Streak Blaze는 "quit 없이 N판 연속 클리어"로 세션 지속성을 유도한다. 스트릭이 쌓일수록 보너스가 발동되어 "한 판 더 해야지" 동기가 자연스럽게 만들어진다. 스트릭이 끊길까봐 부스터를 사용하게 되는 BM 연계 효과도 기대된다.

  • 세션 연장 — 연속 클리어 카운터가 보이면 그 판을 마저 하고 싶어짐
  • quit 억제 — quit하면 스트릭이 초기화된다는 인식이 자연스러운 억제제
  • BM 자연 연계 — 어려운 레벨에서 스트릭을 지키기 위해 부스터를 자발적으로 소비
  • Golden Stamp Tour와 차별화 — 첫 시도 여부(질) vs 연속 클리어(양/지속성)

스트릭 보너스 구조

레벨 클리어마다 스탬프 +1. streak_blaze_bonus_interval판마다 보너스 스탬프 추가 지급. quit 시 스트릭 초기화.

아트 가이드

아트팀 전용

와이어프레임

레벨 클리어 결과 화면 — 스트릭 달성 시 BONUS 배너와 함께 보너스 스탬프 표시. 스트릭 카운터 강조.
quit 화면 — 스트릭 초기화 인지 + "다시 연속 클리어하면 보너스" 안내. 재도전 버튼 강조.

방향성

전체 무드: 불꽃, 질주, 집중. 연속으로 달리는 에너지가 시각적으로 느껴져야 함. 빨강-오렌지 그라데이션이 자연스러운 테마.

스트릭 카운터: 레벨 결과 화면에서 가장 눈에 잘 띄게. 숫자가 올라갈수록 불꽃이 더 강하게 타오르는 느낌이면 좋음. 단조롭지 않게.

스트릭 보너스 연출: "🔥 STREAK BONUS!" 순간은 화끈하고 짧게. 플레이 리듬을 끊지 않는 선에서 임팩트 있게.

스트릭 초기화: 너무 부정적이지 않게 — 실망보다는 "다시 시작하면 돼" 에너지. 불꽃이 꺼지는 느낌보다 "새 불꽃 시작" 느낌.

인게임 스트릭 힌트 (선택): 게임 화면 내 작은 스트릭 카운터 뱃지. 숫자가 올라갈수록 더 빛나거나 뜨거워지는 시각 변화.

스트릭 카운터 로직

  • 스트릭 카운터는 서버 사이드 유저별 유지 (클라이언트 단독 처리 불가)
  • 클리어 이벤트 수신 시: 카운터 +1 → streak_blaze_bonus_interval과 비교
  • 카운터 == bonus_interval이면: 보너스 스탬프 지급 + 카운터 0 초기화
  • quit 이벤트 수신 시: 카운터 즉시 0 초기화
  • 이벤트 기간 종료 시 카운터 초기화 (다음 이벤트 재오픈 시 0에서 시작)

트리거 조건

  • 이벤트 활성 기간 중 레벨 클리어(clear) 이벤트 발생 시 스탬프 지급 + 스트릭 카운터 증가
  • 스트릭 보너스: 카운터가 streak_blaze_bonus_interval에 도달 시 즉시 지급
  • 마일스톤 도달 시: 로비 진입 시점에 팝업 큐에 추가

억제 조건

  • 이벤트 기간 외 스탬프 적립 및 스트릭 카운트 불가
  • quit 시 스탬프 미지급, 스트릭 카운터 초기화
  • 팝업 동시 노출 방지 — 마일스톤 팝업은 다른 전면 팝업 완료 후 순차 노출
  • 마일스톤 중복 지급 방지 — 서버 수령 플래그 확인 후 지급

큐 & 상태 처리

  • 복수 마일스톤 동시 도달 시 (오프라인 누적 후 동기화): 순차 팝업 노출
  • 이벤트 종료 시 미수령 마일스톤 → 우편함 자동 발송
  • 앱 강제 종료 후 재접속: 서버 기준 스탬프 및 스트릭 카운터 복원

엣지 케이스

  • streak_blaze_bonus_interval = 1 설정 시: 매 클리어마다 보너스 발동 — 밸런스 주의
  • 오프라인 플레이 후 동기화: 서버가 클리어/quit 이벤트 순서를 타임스탬프로 처리, 스트릭 카운터 재계산
  • 이벤트 기간 마지막 클리어가 보너스 인터벌 도달 시: 기간 내 지급 확정
  • Golden Stamp Tour와 동일 기간 운영 시: 스탬프 보상이 중복 적립될 수 있으나 이벤트별 독립 집계 — 정상 동작
  • 인게임 스트릭 뱃지 표시 여부: 선택 적용. 미표시 시 레벨 결과 화면에서만 인지 가능
