문제 — 접속 직후 입장료에서 막힘

골드가 부족한 것은 총량 문제가 아님. 골드 수지는 획득/소비 1.219배 흑자이고 판당 보상이 입장료의 3.3~5.6배임. 문제는 다 쓰고 나서 다음 판을 못 들어가는 순간이며, 그 순간이 접속 직후에 집중됨.

회복 경로가 막혀 있어 골드 부족이 그대로 이탈 직전 상태로 남음. 골드에 막힌 유저의 80%가 광고를 시도하지만 완료는 38.5%이고, 실패하면 상점이 강제 노출되나 결제로 이어지지 않음. 최종적으로 플레이에 도달하는 것은 35.6%뿐임.

확정 설계 — 하루 1회 티켓 지급

티켓은 이미 "x1 상당 입장료 면제"로 구현돼 동작 중임. 새 로직을 만들지 않고 지급 한 줄만 얹음.

private getGoldCostForMultiple(multiple: number): number { const baseCost = DataManager.getEntryCost(); const hasTicket = DataManager.getTicketCount() > 0 || this.isTicketUnlimited(); if (hasTicket) { // 티켓은 골드 1회 입장료만 차감: x1->0, x2->baseCost*1, x4->baseCost*3 const goldMultiple = multiple - 1; return goldMultiple >= 1 ? baseCost * goldMultiple : 0; } return baseCost * multiple; }
항목확정근거
지급 수단currency_ticket 1장신규 아이템 · 신규 로직 불필요. 7일간 티켓 입장 3,740건 / 1,037명으로 이미 검증됨
지급 주기하루 1회세션 단위로 하면 앱 재시작으로 반복 취득이 가능함 — 어뷰징 차단
지급 시점로그인 시 자동수령 조작 없이 잔고에 반영. 유저가 인지하지 못해도 진입이 막히지 않는 것이 목적
배수 처리x1 상당액만 면제x1 선택 시 0골드, x2는 baseCost×1, x4는 baseCost×3. 배수 선택 자유가 유지됨
프리레벨 팝업유지스킵하면 배수 · 부스터 선택이 사라져 헤비 유저 보상이 1/4로 줄어듦(아래 참조)
프리레벨 팝업을 건너뛰지 않는 이유. 세션 첫 판의 x1 비중이 66%로 보이지만 1판만 하고 이탈한 세션(79.3% x1)이 만든 착시임. 세션 길이별로 보면 10판 이상 세션의 첫 판은 x4가 41.8%임 — 이들에게 x1을 강제하면 보상이 4배에서 1배로 줄어 오히려 손해가 됨. 티켓 방식은 배수를 그대로 고를 수 있어 이 문제가 없음.
