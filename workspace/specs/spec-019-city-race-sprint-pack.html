배경 — 왜 이 번들이 필요한가

City Race는 주말 3일간 진행되는 순위 경쟁 이벤트입니다. 최종 순위에 따라 보상이 지급되므로, 이벤트 초반에 얼마나 빠르게 레벨을 클리어해 순위를 올리느냐가 결정적입니다.

  • 현황: 이벤트 시작 직후 랭킹 스퍼트를 할 의지가 있지만 부스터·입장권이 부족한 유저가 다수
  • 기회: $2 미만의 저가형 번들로 초반 스퍼트 비용을 커버 → 구매 장벽 최소화 + 이벤트 참여 질 향상
  • 차별점: 기존 상시 상품(special_offer_1 $1.99)과 달리 시간제 부스터를 포함 → 이벤트 기간 한정으로 "지금 당장 써야 할 이유" 제공

1-1 플레이어 경험 흐름

City Race 이벤트 시작 — 로비 진입
주말 금요일 자정 전후 이벤트가 열린다. 로비에 City Race 배너 노출. 이벤트 화면 첫 진입 시 Sprint Pack 팝업이 우선순위로 표시된다.
Sprint Pack 팝업 노출
팝업에는 이벤트 잔여 시간 카운트다운 + 보상 4종 목록 + "$1.99 구매" CTA가 표시된다. 닫으면 24시간 후 재노출 (최대 1회 이벤트 중 구매 가능).
구매 완료 — 보상 즉시 지급
결제 성공 시 골드·티켓·부스터가 인벤토리에 즉시 추가된다. infinite_fireworks_5m은 수령 즉시 타이머 카운트다운이 시작되는 것이 아니라, 인벤토리에서 수동 발동한다.
랭킹 스퍼트 — 집중 플레이
티켓으로 입장료 없이 즉시 경기 참여, 파이어웍스로 클리어율 향상, 골드는 추가 베팅(×2/×4) 또는 연속 경기 참여에 활용. 시간제 파이어웍스는 좋은 시간대에 발동해 5분 집중 스퍼트.
랭킹 상승 확인
이벤트 내 리더보드에서 순위 확인. 번들 구매자는 초반 랭킹 순위 우위를 점한 상태에서 이벤트 진행.
이벤트 종료 — 최종 순위 보상 수령
3일 후 이벤트 종료, 순위별 보상 지급. 번들 구매자의 평균 순위가 비구매자 대비 높은지를 KPI로 측정.

아트 가이드

아트팀

전체 분위기 방향

  • City Race 자체의 레이싱·스피드 테마와 맞추되, 팝업 자체는 차분하고 신뢰감 있게
  • 배경은 어둡고 레이싱 느낌의 그래디언트 (짙은 남색 → 파랑 → 보라). 기존 이벤트 색상 팔레트 유지
  • 타이머 카운트다운은 붉은 숫자로 긴박감을 시각화하되, 스트레스 주지 않도록 작게 배치
  • 보상 아이템 아이콘은 기존 인게임 자산을 그대로 사용, 별도 제작 불필요

팝업 와이어프레임

팝업 와이어프레임 — 헤더(한정 레이블) / 카운트다운 / 아이템 4종 / CTA 버튼

연출 방향

  • 팝업 등장: 아래에서 슬라이드-업 + 페이드인 (빠르고 자신감 있게, 약 200ms)
  • 아이템 목록 진입: 순서대로 짧은 딜레이(약 40ms 간격) 후 페이드인 — 선물 언박싱 느낌
  • 시간제 아이템 강조: 주황색 테두리 펄스 애니메이션 (천천히 반복) — 나머지 아이템과 시각적으로 구분
  • CTA 버튼: 눌렸을 때 눈에 띄는 피드백 (살짝 축소 후 복귀). 색상은 기존 보라-그래디언트 계열 유지
  • 닫기(X) 버튼: 우상단 작게 배치. 닫아도 배너는 이벤트 화면에 잔류
