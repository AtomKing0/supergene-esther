앨범 마일스톤 보상 플로우 수정

배경 — 현재 문제

현재 앨범 마일스톤 보상은 유저가 로비에서 콜렉션 레드닷을 눌러 콜렉션 화면에 진입하는 순간 즉시 보상 연출이 재생된다. 그 결과:

  • 유저가 어느 앨범 / 어느 마일스톤에서 받은 보상인지 맥락을 인지하기 전에 연출이 터진다.
  • 콜렉션을 단순히 둘러보려고 들어온 유저에게도 보상 연출이 끼어들어 흐름을 끊는다.
  • 레드닷이 "콜렉션 진입"이라는 한 단계에서 소비되어, 보상의 출처(퍼즐)로 유저를 유도하지 못한다.

제안 — 레드닷을 한 단계 더 전파

보상 연출의 트리거를 콜렉션 진입 → 퍼즐 리스트("All Puzzles") 진입으로 한 단계 뒤로 미룬다. 레드닷이 로비 콜렉션 버튼 → 앨범 화면의 "All Puzzles" 버튼까지 이어지며, 유저가 직접 퍼즐 리스트로 들어가야 보상 연출이 재생된다.

참조 화면

참조 1 — 콜렉션 앨범 화면. 좌하단 "All Puzzles" 버튼에 레드닷이 노출되어야 한다.

참조 2 — All Puzzles 진입 후 퍼즐 리스트. 이 화면 진입 시점에 마일스톤 보상 연출 재생.

기대 효과 — 유저가 보상의 출처(어떤 도시 퍼즐인지)를 본 상태에서 연출을 보게 되어 콜렉션 콘텐츠 인지·재방문이 강화된다. 단순 열람 유저에게 보상 연출이 강제로 끼어들지 않는다.

신규 / 변경 에셋

  • "All Puzzles" 버튼 레드닷 — 콜렉션 앨범 화면(참조 1) 좌하단 "All Puzzles" 버튼 우상단에 레드닷 배지. 기존 로비 콜렉션 레드닷과 동일한 에셋·크기·애니메이션 재사용 (신규 디자인 불필요).
  • 레드닷 위치: 버튼 우상단 모서리에 살짝 걸치도록 (다른 레드닷 배치 규칙과 동일).

연출(VFX) 변경 없음

마일스톤 보상 연출 자체(파티클, 보상 카운트업, 사운드)는 기존 연출을 그대로 사용한다. 변경되는 것은 재생 트리거 시점뿐이다. 신규 연출 제작은 필요 없다.

아트 작업 요약 — 신규 레드닷 1종(기존 재사용 가능)만 "All Puzzles" 버튼에 배치. 연출/사운드 신규 제작 없음.

엣지 케이스

  • 대기 보상 다건 — 퍼즐 리스트 진입 시 큐에 쌓인 연출을 순차 재생(기존 다건 처리 로직 따름). 모두 소진 후 레드닷 소거.
  • 연출 중 이탈 — 연출 도중 화면을 벗어나면 보상은 이미 지급된 것으로 처리(미지급 방지). 다음 진입 시 중복 연출/중복 지급 금지. 지급 여부 판정은 §4 확정 기준(지급=서버 권위 1회·서버 수령 플래그 기준, 동기화 실패 시 플래그 미갱신·재시도)을 따름.
  • 앨범 화면을 거치지 않는 진입 경로 — 콜렉션을 거치지 않고 퍼즐 리스트로 직행하는 딥링크/숏컷이 있다면, 동일하게 퍼즐 리스트 onEnter에서 연출 재생되도록 트리거를 화면 단위로 둔다(버튼 클릭 핸들러가 아닌 화면 진입 기준).
  • 로비 레드닷만 보고 콜렉션을 닫은 경우 — 보상 미수령 유지. 레드닷 그대로 노출.

회귀 주의 — 기존 "콜렉션 진입 즉시 연출" 코드를 반드시 제거/비활성화해야 한다. 트리거를 옮기기만 하고 기존 트리거를 남기면 연출이 두 번 재생된다.

중복 지급 방지(필수) — 보상 지급은 서버 권위 기준 1회. 클라 연출 재생 ≠ 지급 확정. 연출 트리거가 콜렉션 진입에서 퍼즐 리스트 진입으로 바뀌어도 멱등(idempotent) 지급 보장.
