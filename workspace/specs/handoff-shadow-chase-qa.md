## 0. 사전 조건 · 테스트 세팅

| 항목 | 값 |
|---|---|
| 해금 | Lv10 클리어 (`unlock` 50031) |
| 기간 | 월 0:00 ~ 금 0:00 (= 월~목 4일) · `event_schedule` 160005 (`end_day=5`·`end_time=0:00`) |
| 시간창 | `duration_sec` = 1500초(25분) |
| 목표 판수 | `total_rounds` = 8 |
| 쿨다운 | `cooldown_sec` = 43200초(12h) |
| 연장 | `ad_extend_threshold_sec`=300 · `ad_extend_sec`=300 · `ad_extend_max_per_cycle`=1 |
| 킬스위치 | `event_shadow_sprint.in_use` / `event_schedule.in_use` |

**QA 편의 요청** — 시트 값이 전부 변수이므로 `duration_sec`를 짧게(예 180초), `total_rounds`를 작게(예 2), `cooldown_sec`를 짧게(예 60초) 세팅해 회전시켜 검증할 것. **테스트 후 원복 필수.**

**우선순위 표기** — 🔴 필수(막히면 릴리즈 불가) / 🟡 중요 / ⚪ 확인
