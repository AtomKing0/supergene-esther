왜 만드는가

현재 리워드 광고는 1회 시청 → 1회 보상으로 끝나는 구조입니다. 유저가 광고를 한 번 보고 나면 더 볼 이유가 없습니다. 보상이 항상 동일하기 때문입니다.

RV 누적 마일스톤은 이 구조를 바꿉니다. 광고를 볼수록 다음 마일스톤이 가까워지고, 마일스톤 보상은 점점 커집니다. "다음 마일스톤까지 N번 남았다"는 정보가 유저에게 한 번 더 볼 동기를 줍니다.

N일 주기 리셋으로 리셋 전 달성 심리로 주기 재방문을 유도합니다.

플레이어 경험 흐름

1
리워드 광고 시청

기존과 동일하게 유저가 RV를 봅니다. 기본 보상은 현행대로 지급됩니다.

2
누적 카운터 +1 & UI 업데이트

시청 완료 시 카운터가 올라가며 마일스톤 진행 상태가 시각적으로 갱신됩니다. "다음 마일스톤까지 N회 남음"이 보입니다.

3
마일스톤 달성 시 추가 보상

해당 단계의 마일스톤에 도달하면 추가 보상이 지급됩니다. 보상은 단계가 높을수록 커집니다.

4
다음 단계 유인

보상을 받고 나면 다음 마일스톤 정보가 보입니다. 자연스럽게 "한 번 더" 심리가 발동됩니다.

5
주기 리셋

N일이 지나면 카운터가 0으로 초기화되고 새 사이클이 시작됩니다. 리셋 전 남은 시간이 표시되어 마감 심리를 자극합니다.

핵심 설계 원칙: 마일스톤 간격이 너무 좁으면 당연하게 느껴지고, 너무 넓으면 포기합니다. 초반 단계는 쉽게, 후반 단계는 점진적으로 어렵게 설계해야 합니다. 수치는 밸런스 시트에서 경제 팀이 조정합니다.

비주얼 방향성

전체 톤은 골드/노란색 계열로 수익화 계열 콘텐츠임을 구분합니다. 진행 상태가 한눈에 보여야 하고, 다음 마일스톤 보상이 항상 보여야 합니다. "저기까지만 더 보면 저걸 받는다"는 심리가 핵심입니다.

  • 진행 바: 현재 위치와 마일스톤 지점이 동시에 보이는 구조. 달성된 단계는 초록, 현재 목표는 강조, 미래 단계는 흐리게.
  • 달성 연출: 짧고 경쾌하게. 게임 흐름을 크게 방해하지 않는 선에서 성취감을 전달합니다.
  • 리셋 타이머: 마감 심리를 자극하되, 압박감보다는 정보 제공 느낌으로.
  • 다음 보상 미리보기: 항상 보여야 합니다. 숨겨두면 효과가 반감됩니다.

⚠ 확정 필요 — 문서 내 서술 상충 (2026-07-31 서버 핸드오프 감사)

  • 최초 사이클 앵커 미정 — 리셋 처리 표 "마지막 리셋 기준 N일 경과"만 있고 첫 사이클의 시작점(가입 시점 vs 첫 RV 시청 시점 vs 글로벌 고정일)이 없음 — 유저별 개별 사이클 vs 전 유저 공통 사이클 스키마가 갈림.
  • step_5 설명 "달성 시 사이클 완료" vs 리셋 처리 표 "rv_milestone_period_days일 경과 후 리셋" + 엣지 케이스 "최종 step 이후 리셋까지 남은 시간만 표시" — 5단계 달성 즉시 리셋(새 사이클 시작) vs 기간 만료까지 대기 로직이 갈림.

용어 정의: 이 문서에서 "사이클" = rv_milestone_period_days(7일)로 정의되는 시간 창을 가리킴. 개별 마일스톤 도달은 "스텝 완료"로 부름. "사이클 완료"라는 표현은 위 콜아웃의 상충 항목이므로 확정 전까지 사용 유보.

기준 시각: 기준 시각 = UTC 0시 단일축(PST 라이브 관례 — 데일리 리셋·타 이벤트 동일). 토스 플랫폼(KST 서버) 확장 시 경계 9시간 차 확인 필요.

밸런스 시트 변수 (신규)

기존 탭: const  ·  추가 key_number: 10068
const.rv_milestone_period_days = 7 count (일) 누적 카운터 리셋 주기(일). 7 = 매주 리셋. key_number: 10068
신규 탭: rv_milestone_config  ·  key_number 대역: 30001~30005  ·  담당: 02_경제_밸런스

컬럼 구조: key_number | step | required_view_count | reward_item_key | reward_amount | in_use

rv_milestone_config.step_1 = 3회 key: 30001 1단계 마일스톤 기준 시청 횟수 + 보상 (소량 골드). 진입 장벽 낮게.
rv_milestone_config.step_2 = 7회 key: 30002 2단계 마일스톤. 1단계보다 보상 증가.
rv_milestone_config.step_3 = 15회 key: 30003 3단계 마일스톤. 골드 + 부스터 조합 등 질적 변화 시작.
rv_milestone_config.step_4 = 25회 key: 30004 4단계 마일스톤. 헤비 유저 대상 고보상.
rv_milestone_config.step_5 = 40회 key: 30005 5단계 (최종) 마일스톤. 최고 보상. 달성 시 사이클 완료.

시트 수정 절차: 에이전트 시트(1Z6VGk…)에 rv_milestone_config 탭 신규 생성 + const 탭 10068 추가 → 연두색 하이라이트 → PM 확인 → 라이브 시트 동기화. 담당: 02_경제_밸런스 에이전트.

트리거 및 카운팅

  • RV 완료 콜백 수신 시 서버에서 카운터 +1 처리 (클라이언트 단독 카운팅 금지 — 어뷰징 방지)
  • 카운팅 직후 마일스톤 조건 체크. 해당 step의 rv_milestone_config.required_view_count 도달 시 보상 지급
  • 이미 달성한 step은 재지급 없음 (서버에 달성 여부 기록)

엣지 케이스

상황처리 방식
RV 완료 후 네트워크 끊김카운터 업데이트 실패 시 로컬 큐에 저장 → 복귀 후 재처리
리셋과 RV 완료가 동시에 발생서버 타임스탬프 기준. 리셋 후 완료분은 새 사이클로 카운팅
최종 step(5단계) 이후 추가 시청카운터는 계속 올라가되 추가 보상 없음. 리셋까지 남은 시간만 표시
in_use=false인 step해당 step 건너뜀. 다음 in_use=true인 step으로 진행

어뷰징 방지: 카운터는 반드시 서버에서 관리. RV 완료 여부는 광고 SDK의 서버-사이드 검증(SSV) 활용 권장. 동일 광고 ID 중복 완료 처리 방지 로직 필요.
