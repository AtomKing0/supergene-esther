왜 만드는가

게임 개발 과정에서 특정 기능을 빠르게 검증하고, 문제점을 파악해야 합니다. 이를 위해 간단하고 직관적인 테스트 인터페이스를 제공하여 개발팀의 신속한 피드백을 지원합니다.

플레이어 경험 흐름

1
테스트 화면 진입

개발 메뉴 또는 특정 진입점에서 테스트 기능에 접근합니다.

2
테스트 항목 선택

검증할 기능 또는 시나리오를 선택하거나 입력합니다.

3
테스트 실행

버튼 클릭 등 간단한 조작으로 테스트를 시작합니다.

4
결과 표시

성공/실패 또는 상세 로그를 화면에 표시합니다.

5
반복 또는 종료

다른 테스트를 실행하거나 화면을 닫고 게임으로 복귀합니다.

와이어프레임 — 테스트 화면 구성

비주얼 방향성

간결하고 기능적인 디자인으로, 개발자의 집중력을 방해하지 않습니다. 테스트 결과는 명확하게 구분되어야 합니다.

  • 배색: 다크/라이트 테마 모두 대비가 명확한 색상 사용
  • 레이아웃: 입력 → 버튼 → 결과 순서로 위에서 아래로 흐르는 구조
  • 텍스트: 명확한 라벨과 작은 폰트로 정보 밀도 유지

애니메이션 방향성

최소한의 애니메이션으로 빠른 반응성을 중심으로 설계합니다. 로딩 중에는 스피너 또는 진행률 표시를 제공합니다.

필요 에셋

  • 로딩 아이콘: 스피너 또는 진행 애니메이션
  • 상태 아이콘: 성공(체크), 실패(엑스), 경고(느낌표)
  • 배경: 코드로 처리 가능

참고: 이 화면은 개발용 기능으로, 게임 내 일반 UI 스타일과 동일하게 유지하되 기능성을 최우선으로 합니다.

밸런스 시트 변수

해당 사항 없음 (테스트 기능은 밸런스 변수 미사용)

이 기능은 순수 UI/로직 테스트이며, 게임 밸런스 데이터를 포함하지 않습니다.

트리거 조건

  • 개발 메뉴 또는 특정 키 조합 입력 시 테스트 화면 진입
  • 테스트 항목 입력 후 [실행] 버튼 클릭 시 테스트 시작

기능 명세

기능설명예상 동작
항목 선택드롭다운 또는 텍스트 입력으로 테스트 케이스 지정선택된 항목 표시

에러 처리

  • 입력 없음: "항목을 선택하세요" 경고 표시
  • 테스트 실패: 실패 사유와 함께 빨간색 표시
  • 타임아웃: 30초 이상 응답 없을 시 중단 및 타임아웃 메시지
