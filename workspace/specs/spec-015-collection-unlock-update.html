콜렉션 UNLOCK 시트 VALUE 수정

출시 시 콜렉션은 LEVEL 100 잠금으로 나간다. 출시 직후 업데이트 때 UNLOCK 시트의 VALUE를 100 → 300으로 수정해야 한다. 해금 레벨 300 확정 (2026. 4. 21.).

현재 상태 (출시 빌드)

콜렉션 기능은 출시 스펙상 잠금 아이콘 + "UNLOCK AT LEVEL 100" 안내 문구로 노출된다. 실제 콜렉션 콘텐츠는 준비되어 있으나 UNLOCK 시트의 VALUE가 100으로 설정되어 있어 해금되지 않는 상태.

⚠️ 주의: 출시 직후 업데이트 때 이 작업을 빠뜨리면 콜렉션이 무기한 잠금 상태로 라이브 서비스된다. 반드시 첫 업데이트 배포 전 시트 수정 완료 확인 필수.
