왜 만드는가

플레이어가 인게임 중 데일리 태스크를 달성해도 인지하지 못하는 경우가 많습니다. 현재는 태스크 탭을 직접 열어야만 완료 여부를 확인할 수 있어, 달성 피드백이 없는 것과 다름없는 상태입니다.

리텐션 유도 장치인 데일리 태스크의 효과가 낮아지는 원인 중 하나로 추정되며, 즉각적인 시각 피드백으로 완수율을 높이는 것이 목표입니다.

플레이어 경험 흐름

1
게임 플레이 중

플레이어는 카드를 매칭하거나 특정 조건을 수행하며 데일리 태스크를 자연스럽게 진행합니다.

2
태스크 달성 이벤트 발생

서버 또는 로컬에서 태스크 완료 조건이 충족되면 알럿 표시 이벤트가 트리거됩니다.

3
플로팅 알럿 등장

화면 상단에서 슬라이드 다운으로 알럿이 나타납니다. 태스크명 + 완료 아이콘 + 보상을 보여줍니다. 터치해도 아무것도 일어나지 않는 전광판형 알럿입니다.

4
자동 소멸

일정 시간 후 페이드아웃으로 사라지고, 게임 흐름은 중단 없이 유지됩니다.

5
복수 달성 시 순차 처리

동시에 여러 태스크를 달성하면 큐에 쌓여 순차적으로 표시됩니다.

와이어프레임 2 — 큐 타이밍 흐름

비주얼 방향성

게임 화면 위에 살짝 얹히는 느낌이어야 합니다. 배경은 반투명으로 게임 배경이 비치게 하고, 테두리는 accent 컬러로 얇게 둘러 존재감을 줍니다. 전체적으로 게임 흐름을 방해하지 않는 조용하고 깔끔한 알럿입니다.

  • 위치: 화면 상단, HUD 아래. HUD와 겹치지 않는 것이 핵심입니다.
  • 크기: 화면 너비의 70~80% 수준으로 좌우 여백을 줍니다.
  • 내용 구성: 왼쪽에 녹색 체크 아이콘, 오른쪽에 태스크명 + 보상. 2줄 이내로 간결하게.

애니메이션 방향성

짧고 가볍게. 툭 나타났다가 자연스럽게 사라지는 느낌입니다. 정확한 시간값은 개발 스펙의 밸런스 시트 변수로 관리됩니다.

  • 등장: 화면 위에서 부드럽게 슬라이드 다운 (easeOut 계열)
  • 유지: 그대로 정지. 게임은 계속 진행됩니다.
  • 퇴장: 자연스러운 페이드아웃으로 소멸

필요 에셋

  • 완료 아이콘: 녹색 원형 체크 아이콘. 기존 게임 아이콘 스타일과 통일감 있게.
  • 골드 아이콘: HUD에서 쓰는 골드 아이콘 재사용 가능.
  • 알럿 배경: 별도 이미지 에셋 불필요. 코드로 처리합니다.

레퍼런스: Candy Crush, Royal Match 등 상단 토스트 알럿 패턴 참조. 우리 버전은 인터랙션 없는 순수 정보 표시형으로 단순화.

트리거 조건

  • 데일리 태스크 달성 이벤트 수신 시 즉시 큐에 삽입
  • 큐에 항목이 있고 현재 알럿이 없으면 즉시 표시 시작
  • 현재 알럿이 표시 중이면 새 달성 이벤트를 큐 뒤에 삽입

억제 조건 (알럿 표시 금지 상황)

상황처리 방식
게임 결과 화면 (Win/Lose)큐에 저장은 하되 결과 화면 퇴장 후 표시
로딩/전환 화면큐 유지, 인게임 복귀 후 표시
설정 오버레이 등 모달 표시 중모달 닫힌 후 표시 (선택적 구현)

큐 동작 상세

  • FIFO(First In, First Out) 큐 구조
  • 최대 크기: const.popup_queue_max_size — 초과 시 가장 오래된 항목부터 제거
  • 앱 백그라운드 전환 시 큐 초기화 (선택적 — PM 결정 필요)

인터랙션

터치 이벤트 무시: 알럿 영역은 터치/클릭 이벤트를 전달하지 않습니다 (pointer-events: none 또는 동등 처리). 탭 시 아무 동작 없음. 태스크 탭 이동 로직 구현 불필요.

엣지 케이스

  • 동시 다중 달성: 같은 프레임에 여러 태스크 달성 시 이벤트 순서 보장 필요 (서버 타임스탬프 기준 정렬 권장)
  • 오프라인 달성: 오프라인 중 달성 후 온라인 복귀 시 알럿 표시 여부 — PM 결정 필요 (기본: 표시 안 함)
  • 빠른 달성 연속: const.alert_display_duration_sec + 애니메이션 간격으로 자연스럽게 순서 처리됨
