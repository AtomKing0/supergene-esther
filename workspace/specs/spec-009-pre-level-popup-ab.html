개발 + 아트 공통
왜 테스트하는가
  • 현재 프리레벨 팝업은 부스터·배수 선택을 제공하지만, 매 판 나타나는 진입 장벽으로 작용할 수 있음
  • 팝업 제거 시 게임 진입 마찰 제거 → 세션당 플레이 횟수 증가 기대
  • 부스터 구매 기회 감소 리스크 존재 → 실측 검증 필요
항목 A안 (현행) B안 (테스트)
레벨 진입 프리레벨 팝업 표시 후 확인 버튼 탭 레벨 선택 즉시 게임 시작 (팝업 미노출)
부스터 구매 팝업 내 부스터 구매 / 배수 설정 Grand Fireworks를 인게임 즉석 부스트 아이템으로 전환, 인게임 내 판매 배치
배수 설정 팝업 내 배수 설정 가능 별도 진입점 제공 또는 제거 검토
연속 플레이 결과 화면 → 다음 레벨 수동 선택 결과 화면 "다음 게임" CTA 강조, 자동 유도
성공 지표 & 전제
  • 주요: B안의 세션당 플레이 판수가 A안 대비 통계적 유의 수준으로 증가
  • 허용 범위: 부스터 구매율 하락이 판수 증가 효과를 상쇄하지 않는 수준
  • 실패 기준: 클리어율 유의미한 하락 (부스터 미사용으로 인한 실력 저하 신호)
  • 전제: Grand Fireworks는 인게임 즉석 부스트로 전환 — 완전 제거 아님, 수익 기회 유지
②
아트 가이드
아트팀 전용
방향성
  • B안 팝업 제거 — 기존 프리레벨 팝업 숨김 처리만으로 구현. 팝업 사라짐 → 게임 씬 부드럽게 진입, 끊기는 느낌 없이
  • Grand Fireworks 인게임 배치 — 인게임 중 사용 가능한 즉석 부스트 UI로 재배치. 인게임 오버레이 또는 하단 버튼 형태 고려 (프리레벨 팝업 스타일과 구분)
  • 결과 화면 CTA 강조 — "다음 게임" 버튼을 현재보다 시각적으로 강조, 자연스럽게 눈에 들어오는 위치·크기
A안 vs B안 — 레벨 진입 흐름 비교
필요 에셋
  • Grand Fireworks 인게임 버튼 UI — 인게임 중 탭 가능한 즉석 부스트 아이콘/버튼. 기존 프리레벨 아이콘 재활용 가능 여부 개발 확인 필요
  • (선택) 결과 화면 "다음 게임" 버튼 강조 버전 — 우선순위 낮음

개발 스펙
개발팀 전용
밸런스 시트 변수
TAB: const
ab_pre_level_popup_variant 0 0=A안(팝업 표시), 1=B안(팝업 제거). 서버 플래그로 그룹 분기
ab_pre_level_test_duration_days — 테스트 기간(일). PM이 종료 시점에 플래그 수동 회수
ab_grand_fireworks_ingame_enabled 0 B안 활성 시 1로 세팅. Grand Fireworks를 인게임 즉석 부스트로 노출
트리거 & 분기 조건
  • A/B 그룹 배정: 유저 ID 기반 해시로 50:50 분기 (서버 결정, 클라이언트는 플래그 수신)
  • B안 진입: ab_pre_level_popup_variant == 1 — 레벨 진입 시 팝업 스킵, 게임 씬 직행
  • 억제 조건: 튜토리얼 미완료 유저는 A안 강제 적용 (팝업 교육 목적)
  • Grand Fireworks 전환: ab_grand_fireworks_ingame_enabled == 1 시 인게임 중 즉석 부스트 버튼으로 노출, 프리레벨 팝업 내 판매 제거
측정 이벤트
  • ab_game_start — variant(a/b), level_id 포함
  • ab_game_result — variant, result(clear/quit), booster_used
  • ab_booster_purchase — variant, booster_type, source(pregame/ingame)
  • 세션당 판수: ab_game_start 집계로 도출
엣지 케이스
  • Grand Fireworks 인게임 배치 위치 — 인게임 HUD 내 어느 위치에 놓을지 UX 설계 필요 (게임 플레이 방해 최소화)
  • B안 유저가 배수 부스터를 원할 경우 → 별도 메타 UI 진입점 제공 여부 PM 확인 필요
  • 테스트 종료 후 플래그 회수: A/B 중 채택안으로 ab_pre_level_popup_variant 고정
