009B가 009보다 먼저인 이유

SPEC-009(프리레벨 팝업 제거)는 부스터 판매 채널을 건드리기 때문에 경제 리스크가 높다. 009B는 로비 복귀 마찰만 제거하여 "로비 이동" 변수와 "팝업" 변수를 분리 검증한다. 009B 결과에 따라 009 진행 여부를 데이터로 판단한다.

핵심 변경점
  • B안에서 프리레벨 팝업은 그대로 유지 — 부스터 구매·배수 설정 경험 동일
  • 변경하는 것은 오직 결과 화면 이후 로비 복귀 여부만
  • B안: 결과 화면에서 "다음 게임" 탭 시 로비 없이 다음 레벨 프리레벨 팝업으로 직행
  • N판(ab_continuous_play_streak_count) 소진 또는 중단 조건 충족 시 로비로 복귀
항목 A안 (현행) B안 (테스트)
게임 종료 후 결과 화면 → 로비 복귀 → 레벨 탭 → 다음 레벨 선택 결과 화면 → "다음 게임" CTA → 다음 레벨 프리레벨 팝업 직행
프리레벨 팝업 로비에서 레벨 탭 시 표시 동일하게 표시 (변경 없음)
부스터 구매 팝업 내 구매 팝업 내 구매 (변경 없음)
배수 설정 팝업 내 설정 팝업 내 설정 (변경 없음)
연속 플레이 한도 해당 없음 N판 (ab_continuous_play_streak_count, 기본 3)
로비 복귀 시점 매 판 종료 후 N판 소진 / 골드 부족 / 튜토리얼 트리거 / 유저 로비 이동 시
성공 지표 & 전제
  • 주요: B안의 세션당 플레이 판수가 A안 대비 통계적 유의 수준으로 증가
  • 허용 범위: 클리어율 하락 5%p 미만 (부스터 사용 패턴 미변경이므로 큰 영향 없을 것으로 예상)
  • 실패 기준: 세션 길이가 늘지 않거나 클리어율이 유의미하게 하락
  • 009 진행 조건: 009B에서 판수 증가가 확인될 경우 팝업 제거(009) 로 단계적 진행

로비 트리거 튜토리얼은 단 1개

덱뒤집기(content_deck_draw)·스트릭미터 등은 인게임 트리거이므로 연속 플레이 중에도 정상 발동된다. 로비를 반드시 경유해야 하는 튜토리얼은 content_lobby_play(230003) 하나뿐 — Lv1 클리어 후 로비의 "게임 시작" 버튼 포커스 가이드.

처리 원칙
  • 억제 조건: TutorialStateStore.shownGuides에 "content_lobby_play"가 없으면 B안 억제 → 로비 복귀 강제
  • 실질적으로 Phase 0 유저(Lv1 미클리어 또는 Lv1 클리어 후 로비 미방문)만 억제 대상
  • Lv2 이상(Phase 1+)부터는 잔여 튜토리얼이 모두 인게임·프리레벨 트리거이므로 B안 정상 적용 가능
  • 프리레벨 팝업 안내(content_pre_level_popup)는 B안에서도 팝업이 유지되므로 정상 발동

로비 복귀 시 튜토리얼 재트리거

연속 플레이 중 스트릭 소진·골드 부족 등으로 로비에 복귀할 때, 로비 진입 트리거가 정상적으로 발동되는지 QA 필수. 로비를 건너뛴 판 수와 무관하게 트리거는 로비 복귀 시점에 정상 발동되어야 함.

③
입장료 처리
개발팀 전용
처리 원칙
  • 판당 입장료는 기존과 동일하게 각 레벨 진입 시점에 차감 — 선불 묶음 차감 없음
  • 입장료 차감 시점: 프리레벨 팝업에서 "게임 시작" 확인 시 (A안과 동일)
  • 연속 플레이 흐름 중 다음 레벨 입장료를 감당할 골드가 없으면 스트릭 중단 → 로비 복귀
  • 로비 복귀 시 토스트 메시지로 이유 안내: "골드가 부족해 로비로 돌아왔어요"
선불 묶음 차감을 하지 않는 이유

N판치 입장료를 미리 차감하면 ① 중도 포기 시 환불 로직 필요 ② 게임 크래시 시 재화 손실 분쟁 ③ 구현 복잡도 증가. 판당 차감을 유지하면서 골드 부족 감지만 추가하는 것이 가장 단순하고 안전하다.

골드 부족 처리 상세 흐름
1
결과 화면 진입 시점에 다음 레벨의 입장료를 미리 조회 (next_level_entry_cost)
2
유저 현재 골드 < 다음 레벨 입장료이면 "다음 게임" CTA 비활성화 또는 미표시
3
대신 "골드 부족 — 로비로 이동" 보조 텍스트 표시 후 자동 로비 복귀 유도
!
강제 이동 금지 — 유저가 결과 화면을 확인할 시간 확보. 5초 타이머 후 자동 로비 복귀 또는 버튼 탭으로 즉시 이동 (둘 다 허용)
level_entry_tier 수정 필요 (Lv5 전 로비 숨김 전제)

NRU 시작 골드 2,000G 기준, 현재 Lv3·4에 각 1,000G 입장료가 부과되어 Lv3에서 골드가 바닥남. 연속 플레이 중 입장료 부족으로 스트릭이 즉시 종료되는 문제를 방지하려면 아래 수정이 필요.

배팅(베팅/배수) 설정 처리
  • 배팅 설정은 프리레벨 팝업 내에 그대로 존재 — B안에서도 동일하게 접근 가능
  • 연속 플레이 중 배팅 설정은 판마다 프리레벨 팝업에서 조정 가능 (변경 없음)
  • 이전 판의 배팅값을 다음 판에 기본값으로 유지할지 여부: PM 확인 필요 (현재 미정)

엣지 케이스
  • 마지막 레벨 도달 시 — 다음 레벨 없으면 스트릭 종료 → 로비 복귀 (레벨 없음 안내)
  • 실패(fail) 후 연속 플레이 — 실패한 레벨을 다시 시도할지, 다음 레벨로 넘길지 PM 확인 필요. 기본: 실패해도 다음 레벨로 진행 (스트릭 카운터 차감)
  • 앱 백그라운드 → 복귀 시 — 스트릭 카운터 유지 여부: 세션 만료(session_timeout) 기준으로 만료 시 리셋 권장
  • 테스트 종료 후 플래그 회수 — ab_continuous_play_variant를 채택안(0 또는 1)으로 고정, ab_continuous_play_streak_count는 서비스 파라미터로 전환
