## 0. 사전 조건 · 테스트 세팅

| 항목 | 값 |
|---|---|
| 대상 시트 | `dynamic_level` (라이브 반영 완료 · 2026-07-31) |
| 추가 컬럼 | `level_min` · `level_max` (`result_tier_id` 뒤, `in_use` 앞) |
| 신규 행 | 30010~30016 (7행) · `in_use=TRUE` |
| 병행 변경 | `hard_cooldown` 발동 조건 → 승패 무관 |
| 로깅 | `2100`·`2300`에 `user_level` 추가 · `2100`에 `tier_reason` 추가(권장) |
| 킬스위치 | 추가 7행의 `in_use` (밴드 단위 개별 롤백 가능) |

**QA 편의 요청** — 레벨 구간 경계가 25 / 100 / 350 / 800이라 계정을 만들어 도달시키기 어려움. **유저 레벨을 임의로 세팅할 수 있는 치트/디버그 수단이 필요함.** 없으면 `level_min`·`level_max`를 임시로 낮춰(예: 800+ 밴드를 `5 / 99999`로) 검증하고 **테스트 후 원복 필수**.

**믹스 검증 요청** — 티어 비중은 확률이 아니라 카운터 주기라 **연속 30~50판을 돌려 배분 순서를 기록**하는 방식이 가장 확실함. 판마다 배정된 티어를 순서대로 적어 §3의 예상 패턴과 대조할 것.

**우선순위 표기** — 🔴 필수(막히면 릴리즈 불가) / 🟡 중요 / ⚪ 확인

## 1. 무변경 확인 — 저레벨은 현행과 동일해야 함

가장 중요한 검증임. **레벨 24 이하는 이번 변경으로 아무것도 바뀌면 안 됨.**

| # | 케이스 | 기대 결과 | 우선 |
|---|---|---|---|
| 1-1 | 레벨 1~8 계정으로 플레이 | **Tutorial 티어 맵 순차 제공** — 현행과 동일 | 🔴 |
| 1-2 | 레벨 9~10 계정으로 플레이 | **Normal 고정** — 현행과 동일 | 🔴 |
| 1-3 | 레벨 11~24 계정으로 30판 연속 | Hard 비중 **12% 내외** · Super Hard **6% 내외**. 변경 전과 체감·수치 모두 동일 | 🔴 |
| 1-4 | 레벨 24 계정 연속 플레이 | Normal 6판 연속 후 Hard 등장 패턴 유지 | 🔴 |
| 1-5 | 레벨 24 → 25 레벨업 직후 | 25부터 새 구간(hard_g=5) 적용. **레벨업 시점에 판이 깨지거나 티어가 튀지 않아야 함** | 🔴 |

## 4. Hard 이상 연속 배정 금지 ⚠ 핵심 회귀 항목

`hard_cooldown` 발동 조건 변경이 제대로 들어갔는지 보는 항목임.

| # | 케이스 | 기대 결과 | 우선 |
|---|---|---|---|
| 4-1 | Hard를 **클리어**한 직후 판 | 반드시 **Normal** | 🔴 |
| 4-2 | Hard를 **실패**한 직후 판 | 반드시 **Normal** — 변경 전에는 Super Hard가 나올 수 있었음 | 🔴 |
| 4-3 | Super Hard를 **클리어**한 직후 판 | 반드시 **Normal** | 🔴 |
| 4-4 | Super Hard를 **실패**한 직후 판 | 반드시 **Normal** | 🔴 |
| 4-5 | Hard를 중도 포기(quit)한 직후 판 | 반드시 **Normal** | 🔴 |
| 4-6 | 800+ 구간 50판 연속 기록 | Hard 이상이 연달아 나오는 구간이 **0건** | 🔴 |

> 변경 전 800+ 구간에서 이 케이스가 1.36% 발생했음. 전부 **Hard를 진 직후 Super Hard**가 나오는 조합이었음.

## 6. 시트 데이터 이상값 처리

| # | 케이스 | 기대 결과 | 우선 |
|---|---|---|---|
| 6-1 | `level_min` 또는 `level_max`를 빈 셀로 | 해당 행 **무시** + 경고 로그. 게임 진행은 막히지 않음 | 🔴 |
| 6-2 | `level_min`에 0 입력 | 해당 행 무시 + 경고 로그 | 🟡 |
| 6-3 | `level_min > level_max` (예: 500 / 100) | 해당 행 무시 + 경고 로그 | 🟡 |
| 6-4 | 같은 폭의 구간을 중복 입력 | `key_number` 작은 행 적용 + 경고 로그 | 🟡 |
| 6-5 | 구간 사이에 공백 (예: 100~349 다음이 400~) | 350~399는 `1/99999` 행(현행값)으로 폴백. **게임 진행에 문제 없어야 함** | 🔴 |
| 6-6 | 추가 7행을 전부 `in_use=FALSE` | **현행 동작으로 완전 복귀** — 롤백 경로 검증 | 🔴 |
| 6-7 | 800+ 밴드 행만 `in_use=FALSE` | 800+ 유저만 현행값으로, 나머지 밴드는 유지 (**부분 롤백**) | 🔴 |
