레벨 구간별 Help Rate 배율 시스템
DDA — level_entry_tier × difficulty_tier 연동

초반 레벨에 도움패 확률을 높게, 후반 레벨에 낮게 — level_entry_tier 시트에 배율 컬럼을 추가해 구간별로 조정한다.

배경 — 현재 구조의 한계

현재 difficulty_tier 시트에는 deck_help_rate, field_help_rate 값이 난이도 구간(Easy/Normal/Hard)별로 고정되어 있다. 레벨 번호와 무관하게 동일 구간이면 동일 확률이 적용된다.

그러나 초반 레벨(Lv.1~30 권)의 신규 유저와 후반 레벨(Lv.200+)의 숙련 유저는 동일 help_rate를 체감하는 방식이 매우 다르다. 초반에는 도움이 자주 나와야 진입 장벽이 낮아지고, 후반에는 도움 빈도를 줄여 긴장감·과금 동기를 유지할 수 있다.

목표

  • 초반 구간(220001~220004): help_rate를 기본값 대비 120~150%로 높여 NRU 이탈 방지
  • 중반 구간(220005): 기본값(100%) 유지 — 기준선
  • 후반 구간(220008~220012): help_rate를 50~70%로 낮춰 도전 지속성 및 부스터 소비 유도

추후 개선 항목 — 현재 추천안(Option B)을 채택하되 실서비스 승률 데이터 수집 후 정밀 튜닝 예정. 초기 출시에는 기본 help_rate만 적용.

설계 선택 — Option B (level_entry_tier 배율 컬럼)

검토한 옵션 3가지 중 Option B를 채택한다.

옵션방식장점단점
A — difficulty_tier 행 분리 레벨 구간별로 difficulty_tier 행 복제 후 수치 직접 수정 명시적 행 폭발, 다른 수치(gold ratio 등)까지 뒤섞임
B — level_entry_tier 배율 컬럼 level_entry_tier에 배율 컬럼 추가, 런타임 곱셈 기존 패턴(rv_gold_ratio)과 동일, 12행 관리 런타임 계산 추가 (미미)
C — 별도 시트 help_rate_override 시트 신설 완전 분리 조인 복잡도 증가, 오버 엔지니어링

Option B는 이미 rv_gold_ratio 컬럼이 동일 패턴으로 구현되어 있어 개발 비용이 가장 낮다.

시트 변경 — level_entry_tier

기존 컬럼 뒤에 2개 컬럼을 추가한다. rv_gold_ratio와 동일한 단위·범위 규칙을 따른다.

신규 컬럼 정의
deck_help_rate_ratio 10000 정수 (1/10000) 덱 도움패 출현율 배율. 10000 = 100% (기본값 유지)
field_help_rate_ratio 10000 정수 (1/10000) 필드 도움패 출현율 배율. 10000 = 100% (기본값 유지)

계산식

effective_deck_help_rate  = difficulty_tier.deck_help_rate  × (level_entry_tier.deck_help_rate_ratio  / 10000)
effective_field_help_rate = difficulty_tier.field_help_rate × (level_entry_tier.field_help_rate_ratio / 10000)

기존 패턴 참조: rv_gold_ratio와 동일한 방식. effective_rv_gold = difficulty_tier.rv_gold × (level_entry_tier.rv_gold_ratio / 10000)

구현 조건

  • ratio가 10000인 경우 기존 로직과 동일하게 동작 (배율 1.0 = 곱셈 생략 가능)
  • 결과값이 0 미만이 되지 않도록 max(0, effective) 처리
  • 결과값 상한: difficulty_tier 최대값 × 2.0 (= ratio 20000)으로 캡 권장
  • 컬럼 없는 구버전 클라이언트 호환: ratio 미존재 시 10000으로 fallback

적용 범위

  • deck_help_rate_ratio: 덱에서 다음 도움 카드가 나올 확률 보정
  • field_help_rate_ratio: 필드 배치 시 도움 카드 위치 확률 보정
  • 적용 시점: 레벨 진입 시 level_entry_tier 조회 → 해당 구간의 ratio 확정 → 난이도 결정 시 곱셈 적용

시트 수정 시 주의: 컬럼 추가는 기존 컬럼 순서 뒤에 append. 중간 삽입 시 클라이언트 인덱스 오프셋 변경 위험. 추가 후 반드시 전체 행 숫자 포맷 확인.
