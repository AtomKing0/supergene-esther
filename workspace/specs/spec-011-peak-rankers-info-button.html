Peak Rankers
자세히 보기 버튼 추가

기존 Peak Rankers (clear_ranking, event_id 160004) UI에 "자세히 보기 (!)" 버튼을 추가. 탭 시 순위별 보상 리스트와 참여 조건 안내 문구를 표시합니다.

왜 추가하는가

현재 Peak Rankers 화면에는 순위 리스트(1~5위)만 보이고 각 순위에 어떤 보상이 주어지는지 확인할 방법이 없습니다. 유저는 무엇을 위해 경쟁하는지 알 수 없는 상태에서 이벤트에 참여하게 됩니다.

또한 현재 클리어 수가 없는 유저(이벤트 중 한 판도 클리어하지 않은 유저)가 순위권에 보이는 경우, 해당 유저가 실제로 보상을 받는지 여부가 불명확합니다. "1판이라도 클리어해야 순위 등록이 유효하다"는 조건을 명시적으로 안내해야 유저의 혼선을 방지할 수 있습니다.

플레이어 경험 흐름 (추가분)

1
Peak Rankers 화면 진입

기존 흐름 그대로. 타이틀 옆 또는 우상단에 "!" 버튼이 추가로 표시됩니다.

2
"!" 버튼 탭

버튼을 탭하면 하단 시트 또는 중앙 팝업이 올라옵니다. 배경(Peak Rankers 화면)은 딤처리 유지.

3
보상 정보 + 참여 조건 확인

팝업에서 ① 순위별 보상 리스트(1위~그 외)와 ② 참여 조건 안내 문구를 확인합니다.

4
닫기 → Peak Rankers 복귀

팝업 내 닫기 버튼 또는 배경 탭으로 팝업 종료. Peak Rankers 화면으로 돌아옵니다.

참여 조건 안내 문구 (확정)

"1판이라도 클리어해야 순위가 등록되어 보상을 받을 수 있습니다."

이 문구는 팝업 하단 고정 표시입니다. 보상 리스트 아래에 명확히 구분된 영역으로 배치하며, 단순 정보 전달이므로 경고 스타일보다는 중립적인 안내 스타일로 처리합니다.

비주얼 방향성

"!" 버튼: 작고 명확해야 합니다. 원형 배지 스타일로, 타이틀 우측 또는 우상단 X 버튼 좌측에 배치합니다. 색상은 기존 UI 배경 대비 눈에 띄되, X 닫기 버튼보다는 시각적 우선순위가 낮아야 합니다. 게임 UI의 기존 정보 버튼 스타일이 있다면 통일해서 사용합니다.

  • 팝업 스타일: 하단 슬라이드업 시트 또는 중앙 팝업 둘 다 가능. 기존 게임 팝업 컴포넌트와 동일한 형태를 사용하는 것을 권장합니다.
  • 보상 리스트: 1위는 골드/황금 강조 배경, 2~3위는 해당 메달 컬러 텍스트로 구분, 4위 이하는 동일한 일반 스타일.
  • 참여 조건 안내 영역: 보상 리스트 아래 구분선으로 분리. 경고(빨강)보다는 정보(파랑/중성) 색조. 작은 ℹ 아이콘과 함께 배치하면 명확합니다.
  • 닫기: 팝업 상단 X + 배경 탭 두 가지 모두 지원.

필요 에셋

  • "!" 버튼: 기존 게임 내 정보 버튼 아이콘 재사용 가능 여부 확인. 없으면 원형 배지에 "!" 텍스트로 처리.
  • 팝업 배경: 기존 팝업 컴포넌트 재사용. 별도 신규 에셋 불필요.
  • 아이템 아이콘: 보상 리스트에 각 아이템 소형 아이콘 표시 가능 여부 개발팀 확인 (없어도 텍스트만으로 기능 충족).

밸런스 시트 변수 (신규 추가 없음)

이 기능은 기존 event_ranking 탭 데이터(key_number 170001~170005)를 읽어 표시하는 것으로, 새로운 밸런스 시트 변수 추가는 불필요합니다. 보상 내용 변경은 event_ranking 탭 수정으로 반영되며 팝업에 자동 적용됩니다.

참조 탭: event_ranking  ·  event_id = 160004 (clear_ranking)
event_ranking.rank_start / rank_end 순위 범위 (1~1, 2~2, 3~3, 4~6, 7~10). 팝업은 이 범위를 그대로 표시.
event_ranking.reward_item_key_1~3 보상 아이템 키. 팝업에서 아이템명 또는 아이콘으로 변환하여 표시.
event_ranking.reward_amount_1~3 보상 수량. 팝업에서 ×N 형식으로 표시.

트리거 조건

  • Peak Rankers 화면 활성 상태에서 btn_ranking_info 탭 이벤트 수신 시
  • → event_ranking 탭에서 event_id = 160004인 행 전체 조회
  • → popup_ranking_info 오픈 + 보상 데이터 렌더링

참여 조건 판정 로직

팝업에서 안내 문구만 표시하며, 실제 판정은 이벤트 종료 시 서버에서 처리합니다. 클라이언트는 "1판이라도 클리어해야 순위가 등록되어 보상을 받을 수 있습니다" 문구를 고정 텍스트(string_code)로 하드코딩하지 않고, 현지화 테이블에서 참조하도록 구현합니다.

string_code 키 신규 추가 필요: 참여 조건 안내 문구를 현지화 가능하도록 ranking_entry_condition_notice (가칭) string_code 신규 등록 필요. 11_translation 에이전트에 번역 요청 또는 기존 유사 문구 재사용 여부 확인.

엣지 케이스

  • 보상 구간이 변경된 경우 (예: 11~20위 추가): event_ranking 탭에 행이 추가되면 팝업 리스트에 자동으로 추가됨. 서버 데이터 기반 렌더링이므로 클라이언트 코드 수정 불필요.
  • 팝업 열린 상태에서 이벤트 종료: 서버 이벤트 수신 시 팝업 강제 닫기 처리 또는 무시 (PM 결정 필요, 기본: 이미 열린 팝업은 자연 닫기까지 유지).
  • 매우 긴 아이템명: 보상 리스트 텍스트 말줄임 처리 또는 2줄 허용 여부 아트팀 결정 필요.
