1 UI 컴포넌트

모든 튜토리얼 화면은 아래 4종 핵심 + 2종 보조 컴포넌트로 구성된다. guide_type에 따라 조합이 달라진다.

focus_bubble (20건) — 강제
Dim+Highlight 배경 + 캐릭터+Bubble + Arrow(선택)
is_forced=TRUE — 반드시 지정 영역(아이콘/카드/버튼) 터치해야 진행
예: 상점 아이콘 터치, 기믹 카드 매칭, 해금 팝업 확인
floating (7건) — 비강제
딤 없이 캐릭터+Bubble(반투명) + Arrow(선택)
is_forced=FALSE — 화면 아무 곳 탭으로 스킵 가능
예: 와일드카드/언두/엑스트라덱 안내, 기믹 터치 팁
💬 Bubble (말풍선)
캐릭터+말풍선. 제목, 설명, 탭하여 닫기(선택) 기능 포함. focus_bubble·floating 모두 사용.
radius: 12px 그림자 꼬리: 대상 방향 DEFAULT / CELEBRATION / WARNING mascotIcon: 48x48px mascotPosition: LEFT_TOP / RIGHT_TOP / NONE
위치BOTTOM_CENTER TOP_CENTER NEAR_TARGET CENTER
닫기autoDismiss(ms) 또는 탭
마스코트LEFT_TOP 기본. WARNING 스타일은 NONE (마스코트 미표시) [REF-개선]
✨ Highlight (하이라이트)
전체 화면 딤 + 대상 요소에 마스크 컷아웃 적용. focus_bubble 전용 — floating에서는 사용하지 않음.
rect / circle / auto padding: 8px 외부 터치 차단
☝ Arrow (화살표)
손가락 아이콘 + 대상을 가리키는 화살표. 애니메이션 적용.
48x48px #FFD700 PULSE (0.8s) BOUNCE (0.6s) STATIC
⚠ Feedback (피드백)
오류/주의 애니메이션. 요소에 직접 적용.
SHAKE: +/-5px x3 0.3s BLINK: alpha x3 0.5s PULSE_RED: 테두리 깜빡임
■ DimOverlay (딤 오버레이)
가변 투명도 블랙 오버레이. focus_bubble 전용 — floating에서는 딤 없음. [REF-개선: 라이트 터치]
#000000 0.3 (일반) 0.4 (로비) 없음 (Phase 0 S1-1) 0.5 / 0.6 / 0.7
🎁 FreeTag (무료 태그)
버튼 위에 무료 부스터 횟수를 표시하는 초록색 뱃지.
FREE x3 Undo (Lv8) Extra Deck Fireworks (Lv24)
