## 1. 온보딩 플로우 (NRU 첫 진입 ~ 자유 플레이)

### 1.1 진입 시퀀스 [확인]

| 순서 | 화면 | 비고 |
|------|------|------|
| 1 | 앱 실행 | 캔디크러시 브랜딩 스플래시 |
| 2 | ToS (이용약관) 동의 | 법적 필수 절차 |
| 3 | 알림 권한 요청 팝업 | iOS/Android 표준 |
| 4 | **Level 1 즉시 시작** | 로비 화면 없이 바로 게임 진입 |

**핵심 설계 원칙**: ToS와 알림 팝업 이후 **어떠한 추가 인터럽트 없이** 바로 Level 1이 시작된다. 로비 UI, 캐릭터 인트로, 스토리 씬 등이 **없다**. 플레이어가 올바른 경로를 따르면 초반 레벨에서 게임플레이를 중단시키지 않는다.

### 1.2 튜토리얼 단계별 진행 [확인]

게임은 플레이어가 TriPeaks 솔리테어를 한 번도 해본 적 없다는 전제로 설계되어 있다.

| 레벨 | 학습 내용 | 가이드 방식 |
|------|-----------|-------------|
| **Lv 1~3** | 카드 매칭 기본 룰: 현재 카드보다 +1 또는 -1 랭크의 카드를 탭하여 제거 | 버블 설명 + 하이라이트 타겟 |
| **Lv 4** | 오프라인 수입(Idle Earning) 소개: 4시간마다 코인 지급 | 시스템 팝업 |
| **Lv 5** | 위클리 챌린지(Weekly Challenge) 언락 | 피처 소개 팝업 |
| **Lv 6** | 데일리 기프트(Daily Gift) 시스템 시작: 7일 출석 보상 | 피처 소개 팝업 |
| **Lv 9** | 카드 덱 스킨(Card Deck) 진행 언락 + **첫 보너스 레벨** 등장 | 보너스 레벨 = 실패 불가능 |
| **Lv 11** | **Hold Slot** 메카닉 언락 | 버블 튜토리얼 |
| **Lv 22** | **첫 장애물(Obstacle/Blocker)** 등장 | 버블 설명 |
| **Lv 25** | 피기뱅크(Piggy Bank) 언락 | 시스템 팝업 |
| **Lv 28** | 앨범(Album) 진행 시작 | 피처 소개 |

### 1.3 자유 플레이 전환 시점 [추정]

명시적인 "튜토리얼 종료" 시점은 없다. **Lv 1~11까지가 핵심 메카닉 학습 구간**(카드 매칭 + Hold Slot)이며, Lv 22에서 장애물이 도입되면서 본격적인 난이도 곡선이 시작된다. 사실상 **Lv 1~21이 "확장된 튜토리얼 존"**으로 기능하며, 장애물 없이 순수 카드 매칭만으로 구성된다.

## 2. 인게임 튜토리얼 -- 카드 매칭/클리어 기본 룰 학습

### 2.1 핵심 룰 [확인]

- **TriPeaks 솔리테어 변형**: 보드 위 카드 중 현재 활성 카드(Discard Pile 최상단)보다 랭크가 +1 또는 -1인 카드를 탭하여 제거
- **슈트/색상 무관**: 랭크만 일치하면 어떤 카드든 제거 가능
- **K-A 순환**: K ↔ A ↔ 2는 연속 숫자로 취급 (랩어라운드)
- **스톡파일(Stockpile)**: 매칭 가능한 카드가 없으면 좌측 덱에서 새 카드를 드로우하여 활성 카드 갱신
- **승리 조건**: 보드 위 모든 카드 제거
- **패배 조건**: 스톡파일 소진 + 매칭 가능 카드 없음

### 2.2 Hold Slot 메카닉 (Lv 11~) [확인]

- 활성 카드(Waste Pile 최상단)를 Hold Slot으로 이동 가능
- Hold Slot이 비어있을 때만 저장 가능
- 저장하면 아래 카드가 새 활성 카드가 됨
- Hold Slot의 카드는 언제든 보드 카드와 매칭 가능
- **전략적 효과**: 최적 시나리오에서 매칭 확률이 2배로 증가 (활성 카드 + Hold Slot 카드 동시 매칭 가능)
- 이 메카닉이 게임을 기존 TriPeaks 대비 **반응형 → 전략형**으로 전환시키는 핵심 차별점

### 2.3 스트릭 미터 (Streak Meter) [확인]

- 스톡파일에서 드로우하지 않고 연속으로 보드 카드를 클리어하면 스트릭 발동
- 화면 상단에 스트릭 미터 표시: 수집 카드 수 / 목표 카드 수 / 보상 미리보기
- 스트릭 완료 시 코인, 추가 카드, 와일드 카드 등 보상 지급
- **색상 보너스**: 같은 색 카드 연속 수집 또는 빨강-검정 교대 수집 시 보상 2배

## 3. UI 가이드 방식 [확인]

### 3.1 주요 가이드 패턴

| 방식 | 설명 | 사용 시점 |
|------|------|-----------|
| **버블 설명 (Bubble Tutorial)** | 말풍선 형태의 텍스트 박스로 메카닉 설명 | 새 메카닉 최초 등장 시 |
| **하이라이트 타겟 (Highlighted Target)** | 탭해야 할 카드/UI 요소를 밝게 강조, 나머지 영역 딤(dimming) 처리 | 튜토리얼 중 특정 행동 유도 시 |
| **즉각 피드백 애니메이션** | 잘못된 행동이나 대기 시 자동으로 올바른 경로를 안내하는 애니메이션 재생 | 플레이어가 잘못된 카드를 선택하거나 일정 시간 대기 시 |
| **비간섭 원칙** | 플레이어가 올바른 경로를 따르면 게임을 중단하지 않음 | 초반 레벨 전체 |

### 3.2 설계 철학 [확인]

- **"Show, don't tell" + 반응형 가이드**: 플레이어가 올바르게 플레이하면 튜토리얼이 투명하게 작동하고, 틀리거나 멈추면 즉시 가이드가 개입
- **클래식 어프로치**: King사의 표현으로 "classic approach with bubble tutorials" -- 캔디크러시 본편의 검증된 온보딩 패턴(마스코트, 딤 배경, 스킵 버튼, 인터랙티비티)을 솔리테어에 적용
- Match-3 게임(Royal Match 등)과 달리 장애물을 Lv 22까지 의도적으로 지연시켜 **기본 메카닉 숙달 시간 확보**

### 4.2 장애물(Blocker) 종류 [확인]

장애물은 **Lv 22부터** 도입. 확인된 블로커 목록:

| 블로커 | 메카닉 | 제거 조건 |
|--------|--------|-----------|
| **Chocolate Blocker** | 카드를 감싸서 숨김. 슈트 또는 랭크 표시 | 같은 슈트의 카드로 매칭하여 초콜릿 제거 → 카드 노출 |
| **Liquorice Blocker** | 카드에 점착. 1겹/2겹/3겹 존재 | 해당 랭크 +1/-1 카드로 각 겹을 순차 제거 |

## 5. 보상 구조 -- 튜토리얼 중 제공 보상

### 5.1 레벨 클리어 보상 [확인]

| 보상 유형 | 설명 |
|-----------|------|
| **코인 (Coins)** | 매 레벨 클리어 시 지급. 각 카드 클리어 시에도 소량 코인 적립 |
| **에너지 (Energy)** | 레벨 클리어 시 1 Energy 지급 → 포스트카드 꾸미기 진행에 사용 |
| **스트릭 보상** | 연속 매칭 시 코인, 추가 카드, 와일드 카드 보상 |

### 5.2 보너스 레벨 (Lv 9~) [확인]

- **실패 불가능**: 스톡파일 소진 시 레벨 자동 종료 (실패 판정 없음)
- **코인 카드 수집 전용**: 보드에서 Coin Card를 최대한 많이 수집하는 것이 목표
- **부스터/블로커 없음**: 순수 카드 매칭만으로 진행
- **특별 연출**: 빨간색 카지노 테마 배경 + 전용 BGM
- **주기**: 매주 추가되는 50레벨 세트의 마지막 25번째가 보너스 레벨 [확인]
- **설계 의도**: 어려운 레벨 이후 "휴식(relaxation)" 제공

## 6. 재화 소개 타이밍

### 6.1 코인 (Coins) -- 주요 재화 [확인]

- **첫 노출**: Level 1 클리어 시 자연스럽게 획득
- **용도**: 레벨 입장비(Entry Fee), 부스터 구매, 추가 카드 구매
- **구조**: 레벨 시작 시 코인 소비 → 클리어 시 코인 회수 + 추가 보상. **레벨 클리어 보상만으로는 진행에 불충분** -- 메타 레이어(이벤트, 데일리 등) 보상이 필수 [확인]
- **오프라인 수입**: Lv 4에서 소개 (4시간 주기)

### 6.2 에너지 (Energy) [확인]

- **첫 노출**: 포스트카드(Postcard) 시스템과 함께 소개 [추정: Lv 1~3 사이]
- **용도**: 포스트카드 꾸미기(Candify) 태스크 수행 전용
- **획득**: 레벨 1회 클리어 = 1 Energy
- **설계 의도**: 코인과 별도의 진행 재화로 메타 루프(꾸미기) 진행 속도 조절

### 6.3 부스터 [확인]

- **획득**: 이벤트/챌린지 보상, 코인으로 구매, 스트릭 보상
- **첫 노출 시점**: Hold Slot 이후(Lv 11+), 장애물 등장(Lv 22+) 즈음에 본격 필요성 증가 [추정]

## 7. 난이도 곡선

### 7.1 초반 난이도 설계 [확인]

**Lv 1~21: 장애물 없는 순수 카드 매칭 존**

- Match-3 장르(Royal Match 등)가 Lv 1부터 장애물을 도입하는 것과 달리, CCS는 **Lv 22까지 장애물 도입을 의도적으로 지연**
- 이 구간에서 플레이어는 카드 매칭, 스톡파일 관리, Hold Slot 활용 등 **핵심 메카닉을 충분히 숙달**
- 초반 25개 레벨은 출시 후 수주 내 **페이싱 개선을 위해 리워크(revamp)** 되었음 [확인]

### 7.2 난이도 지표 -- 디컨스트럭션 데이터 [확인]

| 지표 | 일반 레벨 | 하드 레벨 | 설명 |
|------|-----------|-----------|------|
| **Consecutiveness** (보드 카드 연속 매칭 가능도) | 0.63 | 0.54 | 1.0 = 모든 보드 카드가 연속 매칭 가능, 0.0 = 불가 |
| **스톡파일 카드 매칭 확률** | 0.47~0.56 | 더 낮음 [추정] | 1.0 = 항상 매칭, 0.0 = 매칭 불가 |
| **평균 부스터 사용 횟수** | 1.6회 | 2.6회 | 하드 레벨은 부스터 의존도 ~63% 증가 |

### 7.3 레벨 유형별 난이도 [확인]

| 레벨 유형 | 시각 표시 | 특징 |
|-----------|-----------|------|
| **Normal** | 일반 배경 | 기본 난이도 |
| **Hard** | 보라색 해골 패턴 보드 | 낮은 consecutiveness, 부스터 사용 유도 |
| **Super Hard** | 강화된 시각 표시 [추정] | Hard보다 높은 난이도, 진입 전 부스터 오퍼 제공 |
| **Bonus** | 빨간색 카지노 테마 | 실패 불가, Coin Card 수집 전용 |

## 8. 메타 진행 시스템 -- 포스트카드 (Postcard)

### 8.1 구조 [확인]

- 전 세계 명소(하와이, 파리, 일본 등)를 테마로 한 포스트카드를 꾸미기(Candify)
- 레벨 클리어 시 획득하는 Energy로 태스크 수행 → 장식 오브젝트 배치
- 첫 포스트카드는 빠른 진행으로 **단기 몰입** 유도, 이후 포스트카드부터 **장기 몰입** 목표

## 9. PST(우리 게임)와의 비교 시사점

### 9.1 튜토리얼 설계 비교

| 항목 | Candy Crush Solitaire | PST (우리 게임) |
|------|----------------------|-----------------|
| 장르 | TriPeaks Solitaire | TriPeaks Solitaire |
| 첫 레벨 진입 | ToS 후 즉시 Lv 1 | 비교 필요 |
| 장애물 도입 시점 | Lv 22 (매우 늦음) | 비교 필요 |
| Hold Slot | Lv 11에서 도입 | 해당 없음 (다른 메카닉) |
| 가이드 방식 | 버블 + 하이라이트 + 즉각 피드백 | 비교 필요 |
| 보너스 레벨 | Lv 9부터 (실패 불가) | 비교 필요 |
| 재화 시스템 | 코인(입장비) + 에너지(포스트카드) | 골드 + 부스터 |
| 메타 루프 수 | 8개 (단계적 언락) | 비교 필요 |

### 9.2 CCS 설계의 주목할 점

1. **장애물 도입 극단적 지연 (Lv 22)**: Match-3 대비 매우 느리게 복잡도를 올린다. TriPeaks 자체가 카드 게이머에게도 생소할 수 있다는 판단.
2. **Hold Slot = 킬러 피처**: 기존 TriPeaks 대비 전략성 2배 증가. 별도 튜토리얼 레벨(Lv 11)에서 소개.
3. **코인 = 입장비 모델**: 레벨 시작 시 코인 소비, 클리어 시 회수. 메타 보상 없이는 코인 부족 설계.
4. **보너스 레벨 = 휴식 장치**: 실패 불가능 레벨로 난이도 곡선에 "밸리(valley)" 삽입.
5. **Free Entrance Booster**: 실패 후 5분 무료 재도전 -- 이탈 방지 vs 수익화 사이 균형점.
6. **Bubblegum Troll**: Hold Slot을 일시 점거하는 장애물 -- 핵심 메카닉을 역이용한 장애물 설계.
