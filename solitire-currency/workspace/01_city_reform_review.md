### 골드 공급 건전성 영향

현재 건전성 점수 **45/100** (위험 -- 과잉 공급). 개편 후 예상 변화:

| 요소 | 영향 | 크기 |
|------|------|------|
| 데코 중간 단계 SINK 제거 | 부정적 (SINK 축소) | 일 소득의 ~13.9% 해당 SINK 소실 |
| 마지막 단계 SINK 유지 (197,600g) | 완화 요소 | 전체의 32.7% 보존 |
| 해머 증가로 SINK 기간 연장 (144일 -> 164일) | 완화 요소 | 마지막 단계 SINK가 더 오래 작동 |
| D30 골드 누적 증가 | 부정적 | +16.2% (457k -> 532k) |

**판정: 주의 필요 (경미)**

405,800g 제거는 절대액 기준 크지만, 16개 도시 ~164일에 걸쳐 분산되므로 일별 영향은 ~2,970g/일 (일 소득의 16.6%)이다. 기존 경제 시뮬레이션(v3)에서 확인된 실질 SINK 채널은 **게임플레이 입장료+부스터** (보통 유저 기준 8,976g/일)이며, 데코 SINK는 부차적 채널이었다. 건전성 점수는 45 -> 약 **42/100** 수준으로 소폭 하락 예상되나, 이미 "위험" 등급 내 변동이므로 등급 변경은 없다.

다만 D30 기준 +16.2% 골드 누적은 IAP 유인을 추가로 약화시키므로, 향후 다른 SINK 채널(앨범 콜렉션, 이벤트 등) 활성화와 병행해야 한다.

### 체감 변화 분석

**현재 구조의 문제**: 골드를 전 단계에서 소비하므로 "내 돈을 많이 빼앗겼는데 보상이 적다" 체감. 특히 G5~G6에서 18% 회수율은 "손해보는 느낌" 강화.

**개편 후 구조의 장점**:
1. **중간 단계 골드 0** -> "해머만으로 척척 진행" -> 긍정 경험
2. **마지막 단계에서만 골드** -> "마지막 투자" 의사결정 = 유저 자율성 확보
3. **마지막 단계 투자 대비 72~75% 회수** -> "투자하면 상당 부분 돌아옴" 인식
4. **전 도시 72~75% 균일** -> 역진성 해소. 01_forced_city_ux_review.md에서 지적된 "NY 73% -> Rio 37% 반감" 문제가 완전히 해결됨

**주의점**: "회수율 72~75%"는 마지막 단계 골드만 기준이므로, 유저가 마지막 단계를 건너뛰면 회수율은 사실상 무한대(골드 0 투입, 보상만 수령)가 된다. 이는 SINK 채널 약화를 의미하지만, 강제 차단 제거와 맞물려 유저 만족도 측면에서는 명확히 개선이다.

**판정: 적합**

72~75% 균일 회수율은 유저 감정에 적절하며, 01 PM 이전 검수(01_forced_city_ux_review.md)에서 P1으로 제안한 "60% 균일화"보다 더 관대한 수치이나, 마지막 단계만 골드 소비라는 구조 변경과 맞물려 자연스러운 결과이다.

## 4. UX 전환 리스크

### 강제 -> 자발 전환 시 참여율 분석

| 요소 | 현재 (강제) | 개편 (자발) | 리스크 |
|------|-----------|-----------|--------|
| 꾸미기 참여율 | 100% (강제) | 추정 60~80% | 하락 불가피 |
| 코어 게임 이탈 | 높음 (차단 시 이탈) | 낮음 | **개선** |
| 해머 소실 FOMO | 없음 | 있음 (미소비 시 추가 해머 미지급) | FOMO 유인 |
| 골드 부담감 | 높음 (강제 + 골드) | 낮음 (자발 + 중간 무료) | **개선** |

### 해머 소실(FOMO) 유인력 평가

| 항목 | 분석 |
|------|------|
| FOMO 발동 조건 | 해머 가득 참 -> 게임 클리어 시 해머 미지급 |
| 일일 소실 규모 | 15.3해머/일 = 약 1일치 진행 |
| 유저 인지 | 말풍선 넛지 + 클리어 화면 "FULL" 표시 |
| 행동 유도력 | **보통~높음** (무료 재화 소실은 강한 행동 유인) |

**참여율 하락 시나리오 검토**:

- **낙관**: 80% 참여. FOMO + 무료 진행(골드 0) 조합이 대부분 유저를 유도
- **중립**: 65% 참여. 일부 유저는 꾸미기에 무관심 -> 해머 소실 수용
- **비관**: 50% 참여. 꾸미기 자체에 관심 없는 유저층 존재

**경제 관점**: 참여율이 50%로 하락해도 경제 영향은 제한적이다. 마지막 단계 SINK(197,600g)의 50% = 98,800g만 실현되지만, 이는 전체 경제 흐름에서 미미한 수준(D30 잔액의 0.02%).

**판정: 수용 가능**

참여율 하락은 불가피하나, 핵심 목표(코어 게임 차단 제거 -> 리텐션 개선)와 트레이드오프 관계이며, 해머 소실 FOMO가 적정 수준의 유인을 제공한다. 참여율 하락으로 인한 SINK 감소는 데코 골드가 본래 부차적 SINK였으므로 경제적 영향이 미미하다.
