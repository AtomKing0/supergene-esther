## 2. NRU(신규 유저) 플로우

### 2.1 진입 규칙 (슬라이드 7)

**핵심 원칙**: 진입 엔트리 및 컨텍스트에 관계 없이 모두 **지정된 튜토리얼 스테이지로 이동**

- P2P 컨텍스트 진입: 첫 판 P2P 메세지 전송 O, 토너먼트 생성 시도 X
- 토너먼트 컨텍스트 진입: 첫 판 솔로 전환, 토너먼트 생성/공유 시도 X
- 두번째 판부터 컨텍스트 전환, 토너먼트 생성 또는 공유 시도

### 2.2 NRU 게임 플로우 (슬라이드 8)

```
튜토리얼 진입 → 플레이 화면 → 결과 화면 → 로비 화면
```

NRU 첫번째 세션 제한사항:
- 봇구독 팝업 **노출 안함**
- 숏컷 추가 팝업 **노출 안함**
- 설정 버튼 → 나가기
- 게임 클리어 → 로비 이동
- 결과 화면 → 컨텍스트 전환 시도

### 2.3 NRU 컨텍스트 전환 (슬라이드 79)

전환 패턴: `friend → solo` (즉시 Solo 전환)

설계 의도:
- 소셜 실패 경험 최소화
- 첫 플레이에서 대기/반복 시도 제거
- 즉시 플레이 가능성 최우선

### 2.4 NRU 초기 지급

## 4. 난이도 티어 시스템과 튜토리얼

### 4.1 difficulty_tier: Tutorial 티어

| key | tier_id | display_name | score_min | score_max | reward_hammer | pity_trigger | streak_sustain | help_card_rate |
|---|---|---|---|---|---|---|---|---|
| 20001 | 1 | **Tutorial** | 0 | 0 | 1 | 3 | 5 | 8000 (80%) |
| 20002 | 2 | Normal | 0 | 780 | 1 | 5 | 4 | 5000 (50%) |
| 20003 | 3 | Hard | 781 | 860 | 2 | 8 | 3 | 2000 (20%) |
| 20004 | 4 | Super Hard | 861 | 910 | 3 | 99 | 2 | 0 (0%) |

**Tutorial 티어 특징**:
- `help_card_rate = 8000` (80%): 덱에서 뽑는 카드가 매칭 가능한 카드일 확률 80%
- `pity_trigger_count = 3`: 3회 헛스윙 시 매칭 카드 제시 (Normal은 5회)
- `streak_sustain_count = 5`: 스트릭 유지를 위한 카드 제시 필수 횟수 5회
- `reward_hammer = 1`: 클리어 시 해머 1개 고정 지급

### 4.2 dynamic_level: 튜토리얼 스테이지 배정

| key | priority | condition_type | param_1 | param_2 | result_tier_id | 설명 |
|---|---|---|---|---|---|---|
| 30001 | 1 | `user_level_range` | 1 | 8 | 1 (Tutorial) | **Lv 1~8은 튜토리얼 맵 순차 제공** |
| 30002 | 2 | `user_level_specific` | 9 | 10 | 2 (Normal) | Lv 9~10은 Normal 맵 제공 |

- **Lv 1~8**: Tutorial 티어 맵을 순차적으로 제공 (동적 난이도 로직 제외)
- **Lv 9~10**: Normal 맵을 고정 제공 (Tutorial → Normal 전환 구간)
- **Lv 11+**: 동적 난이도(DDA) 시스템에 의해 Normal/Hard/Super Hard 자동 배정

### 5.3 맵 특징 분석

- **모든 튜토리얼 맵에 specialType = 0 (특수카드 없음)**: 기믹 카드가 포함되지 않은 순수 기본 카드만 사용
- **모든 맵의 difficultys = [True, False, False]**: 단일 난이도(Easy 변형만 사용)
- **카드 수 범위**: 필드카드 3~29장 (평균 약 11장), 매우 작은 맵이 대다수
- **초반 맵(Lv 1~8)이 dynamic_level에서 Tutorial 티어로 순차 제공되는 맵**
- 레벨 번호가 불연속적 (0001→0002→0004→0005...) -- 레퍼런스 게임(GSN Tripeaks)의 원본 레벨 번호 기반
- Lv 1 맵은 필드카드 13장 + 드로우카드 1장으로 **매우 쉽고 직관적인 구성**

### 6.4 메타 게임

#### 도시 꾸미기 (슬라이드 24, 107~108)

- 게임 클리어로 획득한 **해머**를 사용하여 도시(씬) 건물 업그레이드
- 건물 업그레이드 3단계: 기본(해머만) → 기본+(해머+골드) → 기본++(해머+광고)
- 구역 완성 시 다음 구역 해금
- 해머 부족 시 → **해머 획득 튜토리얼 팝업** 노출 (슬라이드 26)
  - 해머 얻는 방법 2가지를 썸네일+설명으로 안내
  - "게임 시작" 버튼으로 바로 레벨 진입 유도

#### 컬렉션 (슬라이드 73~74, Lv 8 해금)

- 게임 승리 시 베팅 배수에 따라 퍼즐 피스 지급: x1=1장, x2=3장, x4=5장
- 앨범 마일스톤: 카드 1장 = 1포인트, 누적 포인트로 보상
- 앨범 퍼즐 완성: 도시별 퍼즐 올 클리어 시 추가 보상
- 현재 `is_album_collection_open = 0`, `is_deck_collection_open = 0` (비활성)

### 6.5 재화 (슬라이드 15)

| 재화 | 타입 | 획득처 | 사용처 |
|---|---|---|---|
| **골드 (Gold)** | 기본 재화 | 레벨 승리(베팅 배수), 데일리/룰렛, 상점/광고 | 입장료, 부스터 구매, 이어하기, 꾸미기 |
| **해머 (Hammer)** | 꾸미기 재화 | 레벨 승리 고정(티어별 1~3개), 난이도 보너스 | 씬 건물 건설, 태스크 완료 |
| **스트릭 스타** | 경쟁 재화 | 인게임 스트릭 미터 달성 시 | 리더보드/토너먼트 순위 산정 (비소모) |
| **퍼즐 피스** | 수집 자산 | 레벨 승리 시 베팅 배수별 드랍 | 컬렉션 앨범 완성 |
| **무료 입장 티켓** | 소모품 | 데일리/친구 선물/룰렛/상점 | x1 베팅 시 골드 소모 없음 |

### 6.6 베팅 시스템 (슬라이드 13, 66)

| 배수 | 해금 | 효과 |
|---|---|---|
| x1 | Lv 3 | 기본 참가비, 기본 보상 (퍼즐 피스 1장) |
| x2 | Lv 10 | 참가비 2배, 보상 2배 (퍼즐 피스 3장) |
| x4 | Lv 20 | 참가비 4배, 보상 4배 (퍼즐 피스 5장) |

참가비 계산: `final_price = floor(min(current_price, max_price))`
- `base_price = entry_cost * betting * (entry_cost_ratio / 10000)`
- 누진가격(undo, extra_deck)은 사용할수록 가격 상승

### 6.7 인게임 골드 획득 구조 (const 시트)

| 시스템 | 상수 | 초기값 | 레벨 인상 | 상한 |
|---|---|---|---|---|
| **콤보 보상** | `ingame_combo_reward_base` | 2g | 10레벨마다 +1g | 50g/매칭 |
| | `ingame_combo_reward_increase` | 1g/콤보 | 10레벨마다 +1g | |
| **덱 보너스** | `remaining_deck_reward_base` | 15g | 5레벨마다 +5g | 5,000g |
| | `remaining_deck_reward_increase` | 15g/장 | 5레벨마다 +5g | |
| **인게임 골드 상한** | `gold_max_limit` | 20,000g | - | 판당 수령 상한 |

### 6.8 스트릭 미터 시스템 (슬라이드 71~72, Lv 5 해금)

- 덱을 사용하지 않고 연속 카드 제거 시 게이지 충전
- 덱 카드 오픈 시 스트릭 초기화
- 3단계 순환 보상: 보상1 → 보상2 → 보상3 반복
- 스트릭 스타: 콤보 1회당 1개 (인게임 최대 100개, `streak_star_max_limit`)
- 보상 종류: 골드, 와일드카드, 플러스카드(+1)

### 7.2 해머 획득 튜토리얼 (슬라이드 26)

별도로 존재하는 **컨텍스트 기반 튜토리얼**:
- 트리거: 꾸미기 화면에서 해머 부족 시 자동 노출
- 내용: 해머 획득 방법 2가지 안내 + 바로 레벨 시작 유도

## 9. 요약

PST의 튜토리얼은 **3개 층위의 점진적 해금 구조**로 설계되어 있다:

1. **Lv 1~8 (Tutorial 티어)**: 기본 카드 매칭 규칙을 36개 튜토리얼 전용 맵으로 학습. 80% help_card_rate로 높은 성공률 보장. 특수카드/기믹 없음.

2. **Lv 3~8 (시스템 해금)**: pre-레벨 팝업, 베팅, 부스터(언두/파이어웍스/골든티켓), 스트릭, 컬렉션을 순차적으로 해금하며 show_tutorial=True로 각 해금 시 튜토리얼 표시.

3. **Lv 10~35 (점진적 콘텐츠)**: 고급 부스터, 기믹 4종, 이벤트 3종, 고배율 베팅을 장기간에 걸쳐 해금.

현재 **기획서 튜토리얼 섹션(슬라이드 80~83)은 미완성** 상태이며, 실제 구현은 마일스톤 상 **3/23 착수 예정**이다. unlock 시트와 dynamic_level 시트에 해금 규칙은 정의되어 있으나, 각 해금 시 표시할 **상세 UI/UX 플로우와 핸드 가이드 연출**은 아직 기획이 필요하다.
