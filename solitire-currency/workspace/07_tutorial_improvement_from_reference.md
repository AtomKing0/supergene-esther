## 2. 핵심 차이점 분석 (CCS vs PST 현행)

### 2.1 전체 설계 철학 비교

| 항목 | CCS (레퍼런스) | PST (현행) | 평가 |
|------|---------------|-----------|------|
| **튜토리얼 톤** | 가벼움 — "한 번 알려주고 놔둔다" | 무거움 — 단계별 강제 진행 | CCS 우위 |
| **딤 오버레이** | 없음~매우 옅음 (Bubble만 표시) | alpha 0.5~0.7 풀 딤 | CCS 우위 |
| **캐릭터** | 마스코트(캔디 킹) 아바타 + 성격 | 추상적 Bubble 컴포넌트 | CCS 우위 |
| **힌트 방식** | 컨텍스트 기반 (상황 발생 시만) | 타임아웃 기반 (5초 무조작) | CCS 우위 |
| **보상 연출** | 인게임 보상 수령 연출 + 컨페티 (화려) | Bubble(CELEBRATION) 텍스트 | CCS 우위 |
| **참가비 노출** | Lv 4에서 자연스럽게 | 명세에 Pre-Level 가이드 있음 | 동등 |
| **기능 해금** | 레벨별 점진 (Lv 16 상점 보너스 잠김) | Phase별 점진 해금 | 동등 |
| **메타 진행** | 엽서 태스크 (에너지 소비) | 도시 꾸미기 (해머 소비) | 구조 상이 |

### 2.2 Phase별 상세 비교

| Phase | CCS 접근 | PST 현행 | 개선 필요도 |
|-------|---------|---------|-----------|
| **Phase 0 (Lv 1)** | 딤 없이 즉시 플레이, 마스코트 1회 환영 Bubble | alpha 0.7 딤 + 5단계 가이드 (S1-1~S1-5) | **높음** |
| **로비 학습** | "Tap on Task" 마스코트 1회 안내 | 5단계 강제 가이드 (Step 1~5) | **높음** |
| **기믹 첫 등장** | Lv 4에서 자연스럽게 노출, 별도 설명 없음 | SCR-05 Bubble + Highlight 가이드 | 중간 |
| **스트릭** | Lv 5에서 미터 UI 자연 등장 | SCR-06 Bubble 설명 | 중간 |
| **부스터** | Pre-Level에서 잠금 슬롯 노출 → 자연 학습 | SCR-07/08/11 단계별 FREE×3 가이드 | 낮음 |
| **클리어 축하** | 인게임 보상 수령 연출 + 마스코트 + 컨페티 (3~5초 연출) | Bubble(CELEBRATION) 텍스트 | **높음** |
| **상점** | Lv 4 이후 자연 노출, 카테고리 분류 | SCR-10 아이콘 터치 유도 | 낮음 |

## 3. 개선 제안 (우선순위별)

### 🔴 높음 — 즉시 반영 권장

#### 3.1 Phase 0 딤 오버레이 경량화

**현행 문제**: SCR-01의 alpha 0.7 풀 딤은 NRU에게 "설명서를 읽는" 느낌을 줌. CCS는 딤 없이 카드 딜링부터 보여주고, 마스코트가 자연스럽게 안내.

**개선안**:

| 항목 | 현행 | 개선 |
|------|------|------|
| S1-1 (환영) | alpha 0.7 딤 + Bubble(CENTER) | **딤 제거** → 카드 딜링 애니메이션 후 마스코트 Bubble 등장 |
| S1-2 (필드 설명) | alpha 0.7 딤 + 필드 하이라이트 | **alpha 0.3 딤** + 매칭 가능 카드만 스파클 |
| S1-3 (드로우 설명) | alpha 0.5 딤 + 드로우덱 하이라이트 | 유지 (첫 막힘 시에만 표시 — 컨텍스트 트리거) |
| S1-4 (매칭 시도) | 입력 대기 (딤 없음) | 유지 |
| S1-5 (클리어 보상) | Bubble(CELEBRATION) | **인게임 보상 수령 연출 연출**로 변경 (아래 3.3 참조) |

**변경되는 UX 흐름**:
```
[현행]
앱 시작 → 딤(0.7) → "환영합니다" 탭 → 딤(0.7) → "이것이 카드입니다" 탭
→ 딤(0.5) → "드로우 덱" 탭 → 자유 플레이

[개선]
앱 시작 → 카드 딜링 애니메이션(1.5s) → 마스코트 Bubble 자동 등장(2s)
"환영합니다! 아래 카드보다 1 높거나 낮은 카드를 탭하세요."
→ 자동 소멸 → 자유 플레이
→ (첫 막힘 시) "드로우 덱을 탭해서 새 카드를 뽑으세요" 컨텍스트 힌트
```

**영향 범위**: `06_tutorial_ui_ux_spec.md` SCR-01 전체, `05_tutorial_system_spec.md` §4

#### 3.2 마스코트 캐릭터 시스템 도입

**현행 문제**: Bubble 컴포넌트가 추상적이어서 튜토리얼에 "인격"이 없음. CCS는 마스코트(캔디 킹)가 일관되게 안내하여 친근감과 기억 효과 생성.

**개선안**:

```
[기존 Bubble]                        [개선 Bubble (마스코트형)]
┌─────────────────────┐              ┌─────────────────────────┐
│ 설명 텍스트           │              │ ┌──┐ 설명 텍스트          │
│                      │              │ │🐾│                      │
│            [탭하세요] │              │ └──┘          [탭하세요]  │
└────────┬────────────┘              └──────────┬──────────────┘
         ▼                                       ▼
```

| 속성 | 값 |
|------|-----|
| 마스코트 아이콘 | 원형 48×48px, Bubble 좌상단 배치 |
| 캐릭터 | 게임 세계관 마스코트 (디자인팀 결정) |
| 적용 범위 | 튜토리얼 Bubble 전체 (style: `DEFAULT`, `CELEBRATION`) |
| 예외 | `WARNING` 스타일은 마스코트 미표시 (Feedback 전용) |

**Bubble 컴포넌트 공통 사양 수정**:
- `1.1 Bubble` 섹션에 `mascotIcon` 속성 추가 (선택적, 기본값: 게임 마스코트)
- `mascotPosition`: `LEFT_TOP` (기본) / `RIGHT_TOP` / `NONE`

#### 3.3 클리어 축하 연출 강화 (인게임 보상 수령 연출)

**현행 문제**: SCR-13a 클리어 축하가 Bubble(CELEBRATION) 텍스트로만 구성. CCS는 코인이 화면을 가득 채우며 날아가는 화려한 연출로 보상 쾌감 극대화.

**개선안 — 인게임 보상 수령 연출 연출 추가**:

```
┌─────────────────────────────────────┐
│  🪙🪙🪙🪙  ← 코인 파티클 상단→하단    │
│    🪙  🪙🪙                          │
│  🪙    🪙  🪙  ✨✨                   │
│      🪙  🪙  ✨                      │
│  ✨    🪙    ✨  ✨                   │
│                                      │
│         +1,108 🪙                    │
│                                      │
│  ┌──────────────────────────────┐    │
│  │         Collect              │    │
│  └──────────────────────────────┘    │
│                                      │
│              Tap to Skip             │
└─────────────────────────────────────┘
```

| 항목 | 값 |
|------|-----|
| 코인 파티클 | 30~50개, 상단 → 코인 카운터 방향으로 비행 |
| 비행 시간 | 2.0초 (ease-out), 도착 시 카운터 증가 애니메이션 |
| 컨페티 | 멀티컬러 5~8색, 1.5초간 낙하 |
| 마스코트 | Bubble 상단에 축하 포즈 |
| 보상 표시 | 화면 중앙 "+{amount} 🪙" 대형 텍스트 (24pt, Bold, 골드색) |
| Collect 버튼 | 초록 라운드 버튼 (기존 Go 버튼과 동일 스타일) |
| Skip | "Tap to Skip" 하단 텍스트 (alpha 0.5, 1초 후 표시) |
| 사운드 | 코인 떨어지는 효과음 + 팡파르 |

**적용 레벨**: 전 레벨 클리어 시 (Phase 0 포함)
**SCR-13a 대체**: 기존 Bubble(CELEBRATION) → 인게임 보상 수령 연출 + Collect 버튼

### 🟡 중간 — 다음 스프린트 반영 권장

#### 3.4 컨텍스트 기반 힌트 시스템

**현행 문제**: SCR-12 타임아웃 힌트가 5초 무조작 기반. CCS는 "사용 가능한 수가 없을 때" 즉시 드로우 덱 안내.

**개선안**:

| 트리거 | 현행 | 개선 |
|--------|------|------|
| 5초 무조작 | 타임아웃 힌트 (매칭 카드 Blink) | 유지 |
| **매칭 불가 감지** (신규) | 없음 | "사용 가능한 수가 없습니다. 드로우 덱을 탭하세요" Bubble + 드로우 덱 Arrow |
| **드로우 후 매칭 가능** (신규) | 없음 | "이 카드를 매칭할 수 있습니다!" + 해당 카드 스파클 (Phase 0~2에서만) |

**구현 방식**:
- `GuideSystem`에 `checkAvailableMoves()` 호출 추가
- 필드 + 드로우 탑 카드 기준 매칭 가능 카드 0개 → 컨텍스트 힌트 발동
- Phase 3 이후 자동 비활성화 (tutorial_phase ≥ PHASE_3)

**영향 범위**: `05_tutorial_system_spec.md` §10 인게임 가이드 시스템, `06_tutorial_ui_ux_spec.md` SCR-12 확장

#### 3.5 Pre-Level 부스터 슬롯 표시

**현행 문제**: SCR-04 Pre-Level 가이드에서 참가비만 설명. CCS는 Pre-Level에서 부스터 3슬롯을 잠금 상태로 노출하여 존재를 자연스럽게 인식시킴.

**개선안**:

```
[CCS 스타일 Pre-Level]
┌──────────────────────────────────┐
│           Level 4                │  ← 파란 리본 배너
├──────────────────────────────────┤
│                                  │
│  Select Boosters:                │
│  ┌──────┐ ┌──────┐ ┌──────┐    │
│  │ 🔒   │ │ 🔒   │ │ 🔒   │    │  ← Lv 8 이전: 3슬롯 잠김
│  │      │ │      │ │      │    │     Lv 8+: 1슬롯 해금 (undo)
│  └──────┘ └──────┘ └──────┘    │     Lv 24+: 3슬롯 모두 해금
│                                  │
│  ┌──────────────────────────┐    │
│  │    PLAY  🪙 1,000        │    │  ← 초록 버튼
│  └──────────────────────────┘    │
│                                  │
│              ✕                   │
└──────────────────────────────────┘
```

**SCR-04 수정**:
- 참가비 버튼 위에 부스터 3슬롯 영역 추가
- 해금 전: 자물쇠 아이콘 + "Lv {n}에서 해금" 툴팁
- 해금 후: 부스터 아이콘 + 보유 수량 + 선택 토글

#### 3.6 로비 가이드 경량화 (SCR-02)

**현행 문제**: SCR-02 로비 최초 진입이 5단계(Step 1~5) 강제 가이드. CCS는 마스코트 Bubble 1회("Tap on the Task")로 해결.

**개선안**:

| 항목 | 현행 | 개선 |
|------|------|------|
| Step 1 (로비 소개) | 딤 + Bubble(CENTER) | **삭제** — 로비는 시각적으로 자명 |
| Step 2 (도시 진입) | 딤 + 전환 연출 | **마스코트 Bubble 1회**: "도시를 꾸며보세요!" + 도시 영역 스파클 |
| Step 3 (업그레이드) | 딤 + 하이라이트 + Arrow | **유지** (첫 업그레이드는 강제 수행 필요) |
| Step 4 (완료 연출) | 딤 + 파티클 | **마스코트 Bubble**: "잘했어요! 레벨을 플레이해서 해머를 모으세요" |
| Step 5 (플레이 유도) | 딤 + 플레이 버튼 Arrow | **삭제** — 플레이 버튼은 자명 |

**결과**: 5단계 → **3단계**로 축소 (Bubble 1 → 강제 업그레이드 → Bubble 1)

### 🟢 낮음 — 선택적 반영

#### 3.7 스트릭 미터 시각화 개선

**CCS 관찰**: 우측에 세로형 스트릭 미터 (도트가 채워지는 형태)가 상시 노출. 스트릭 진행이 시각적으로 즉각 인지됨.

**현행**: SCR-06 Bubble로 스트릭 개념 설명. 미터 UI 자체의 시각적 존재감은 인게임 UI 영역.

**권장**: 인게임 UI 팀에 스트릭 미터 레퍼런스 이미지 전달 (본 문서 범위 외, 인게임 UI 명세에서 처리)

#### 3.8 상점 자연 노출 타이밍

**CCS 관찰**: Lv 4 클리어 후 인게임 보상 수령 연출 → 상점이 자연스럽게 노출됨. Featured/Bundles/Coin Packs 3단계 구조.

**현행**: SCR-10에서 상점 아이콘 터치 유도 (Lv 5 해금 시).

**권장**: 현행 유지. 상점 UI 구조는 별도 상점 명세에서 관리. 다만 SCR-10의 터치 유도를 강제 딤 대신 마스코트 Bubble + 아이콘 스파클로 변경 검토.

#### 3.9 데일리 로그인 팝업 타이밍

**CCS 관찰**: 게임 플레이 세션 중간(Lv 5 이후)에 "Daily login streak!" 등장. 게임 흐름을 방해하지 않는 타이밍.

**현행**: 05 spec에 daily_gift 시스템 정의 있음. 로비 진입 시 표시.

**권장**: 현행 유지 (로비 진입 시). CCS의 세션 중 노출은 오히려 흐름 방해 가능성 있음.
