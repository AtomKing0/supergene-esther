# 강제 도시 완성 전환 UX 검토 및 개선안

## 1. 현행 구조 요약

### 메커니즘
1. 유저가 코어 게임(카드 솔리테어) 클리어 → **해머 획득** (Normal 1개, Hard 2개, SH 3개)
2. 해머로 도시 데코레이션 업그레이드 (5개 데코 × 다단계)
3. 각 업그레이드에 **해머 + 골드** 소비 (1단계만 무료, 2단계~는 골드 필요)

5. 모든 데코 업그레이드 완료 → 도시 완성 보상 수령 → 다음 도시 언락 → 코어 게임 복귀

## 3. 문제 진단

### 문제 A: 강제 플레이 차단의 정당성 부재

**현재 설계 의도**: 도시 꾸미기를 통한 메타 진행감 + 골드 SINK

**실제 유저 경험**:
- "재미있게 게임하는 중인데 갑자기 막힘" → **부정적 감정 트리거**
- "꾸미기에 골드를 쓰라고 강제됨" → **자율성 침해**
- "도시 완성했는데 투자한 만큼 돌려받지도 못함" → **보상 불만족**
- 특히 G1(2.4일 간격)에서 반복 → NRU 초반 경험 훼손

**레퍼런스 비교**: PST 원본의 도시 꾸미기는 해머만 소비 (골드 미소비). 우리 게임이 골드 SINK를 추가한 것이 이중부담 원인.

### 문제 B: 보상 구조의 역진성

진행할수록 보상 회수율이 **떨어지는** 구조:
- 초반(쉬운 도시) → 보상 풍성 → 동기부여 ✅
- 후반(어려운 도시) → 보상 빈약 → 불만 누적 ❌

일반적 게임 설계에서는 **반대**여야 함: 후반 콘텐츠일수록 보상이 풍성해야 지속 동기 제공.

### 문제 C: 인플레이션과의 모순

| 관점 | 현재 상태 | 문제 |
|------|----------|------|
| SINK로서 | 잔액의 3~7% → 효과 미미 | 불쾌감만 유발 |
| 유저 인식 | "골드 넘치는데 왜 이런 것까지" | 가치 역전 |
| 경제 해법 | 인플레이션 해결은 Source 제어가 핵심 | 작은 SINK로 해결 불가 |

## 4. 개선안

### 개선안 1: 강제 차단 제거 — "해머 소실" 소프트 넛지 (P0, PM 확정)

**변경**: 강제 플레이 차단을 **완전 제거**. 대신 해머가 가득 차면 추가 해머를 지급하지 않는 방식으로 자발적 꾸미기를 유도.

**현재 → 변경:**
```
현재: 해머 가득 참 → 코어 게임 차단 → 강제 꾸미기
변경: 해머 가득 참 → 게임 계속 가능, 해머만 안 줌 → 유저 자발적 꾸미기
```

**UI 안내 요소:**
| 요소 | 내용 |
|------|------|
| 레드닷 + 느낌표 | 해머 아이콘에 경고 뱃지 표시 |
| 안내 문구 | "이 도시에 필요한 해머가 가득 찼어요! 더 이상 모을 수 없어요" |
| 클리어 결과 | 해머 보상란에 "FULL" 표시 (획득 불가 시각화) |
| 로비 진입 시 | 최초 1회 안내 팝업 (도시 꾸미기 바로가기 CTA 포함) |

**해머 소실 정책: 옵션 A (획득 안 됨) 채택**
- 해머가 가득 찬 상태에서 게임 클리어 시 해머 미지급 (소실)
- 다음 도시 이월 없음 — FOMO 효과로 자발적 행동 유도
- "가방이 가득 찼어요" = 단순하고 직관적인 규칙

**소실 시 유저 손실 규모 (Rio 기준, 미루는 기간별):**

| 미루는 기간 | 소실 해머 | 게임판 환산 | FOMO 강도 |
|--------:|-------:|-------:|:-------:|
| 0.5일 | 7.7개 | ~7판 | 약함 |
| 1일 | 15.3개 | ~13판 | 보통 |
| 2일 | 30.6개 | ~27판 | 강함 |
| 3일+ | 45.9개+ | ~40판+ | 매우 강함 |

**강제 차단 vs 해머 소실 비교:**

| 항목 | 현재 (강제 차단) | 개선 (해머 소실) |
|------|:------------:|:------------:|
| 코어 게임 | 차단됨 | **항상 플레이 가능** |
| 유저 자율성 | 없음 | **완전 자율** |
| 꾸미기 동기 | 강제 (부정적) | **FOMO (자발적)** |
| 데드락 가능성 | 이론상 존재 | **0%** |
| 해머 가치 인식 | 자동 소비 | **"아까운 것" → 가치↑** |
| NRU 초반 경험 | 2.4일마다 차단 | **끊김 없음** |
| 이탈 리스크 | 높음 | **낮음** |
| 구현 비용 | 기존 구조 | 차단 로직 제거 + UI 추가 |

**비채택 옵션:**
- 옵션 B (다음 도시 이월): FOMO 없음 → 유저가 영원히 꾸미기 안 할 수 있음
- 옵션 C (임시 보관 상한): 복잡도 대비 효과 불확실

### 개선안 2: 데코 골드 비용 단계적 제거 — Stage 2 해머Only (P0)

**변경**: 데코 업그레이드 **Stage 2까지** 골드 비용 제거 → 해머만으로 완성 가능하게.

현재 구조:
```
Stage 1: 해머 ✅ + 골드 0 (무료)
Stage 2: 해머 ✅ + 골드 X (유료) ← 이 비용이 불쾌감 원인
Stage 3+: 해머 ✅ + 골드 X (유료)
```

**조정안**: 도시 완성에 필요한 최소 업그레이드(Stage 2)까지 골드 무료화
```
Stage 1: 해머 + 골드 0 (무료) — 불변
Stage 2: 해머 + 골드 0 (무료) ← 변경
Stage 3+: 해머 + 골드 X (선택적 프리미엄 업그레이드)
```

**핵심 전환**: "도시 완성"과 "도시 꾸미기"를 분리
- **완성 조건** = Stage 2까지 (해머만) → 꾸미기 시 골드 부담 0
- **프리미엄 꾸미기** = Stage 3+ (해머 + 골드) → 유저 선택적 추가 투자

**효과**:
- 꾸미기 시 골드 강탈감 완전 제거
- Stage 3+ 골드 소비는 유저 자율 의사결정 → SINK 효과 + 긍정 감정
- 프리미엄 외형이 더 화려하면 → 자발적 SINK 유도 가능
- 전체 골드 SINK 중 도시 비중 미미(3~7%)이므로 경제 영향 최소

**개선안 1 + 2 시너지**:
- 해머 가득 참 → 게임은 계속 가능 (개선안 1)
- 유저가 자발적으로 꾸미기 진입 → 골드 0으로 완성 가능 (개선안 2)
- "아깝다" + "공짜로 할 수 있다" = **최적의 행동 유도 조합**

### 개선안 4: 도시 완성 보상 연출 강화 (부가)

현재 보상이 "기쁘지 않은" 원인은 수치뿐 아니라 **연출** 문제도 있음.

| 항목 | 현재 | 개선 |
|------|------|------|
| 보상 표시 | 즉시 지급 | **보상 언박싱 연출** (열기 애니메이션) |
| 골드 표시 | 숫자만 | **이전 도시 대비 증가량** 강조 |
| Infinite 아이템 | 텍스트 | **타이머 시각화** + "바로 사용" CTA |
| 다음 도시 예고 | 없음 | **다음 도시 실루엣 + "곧 만나요"** 티저 |
| SNS 공유 | 없음 | **도시 완성 카드** (공유 시 추가 보상) |

**판단 근거**:
