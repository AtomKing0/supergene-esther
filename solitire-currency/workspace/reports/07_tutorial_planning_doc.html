1 설계 개요

즉시 플레이
NRU는 로비를 건너뛰고 바로 인게임 진입. 첫 판(Lv 1) 풀 가이드로 기본 메카닉 숙달.
비간섭 가이드
올바른 행동 시 가이드 미노출. 5초 무행동 시에만 힌트 깜빡임. 플레이어 자율성 보장.
단계적 복잡도
Lv 1~8 Tutorial 티어 (help_card_rate 80%). Lv 9부터 Normal/DDA 전환. 2레벨 이내 간격 해금.
2-시트 아키텍처
unlock (해금 조건) / tutorial_guide (가이드 설정 + 맵 배정 통합)
레퍼런스: Candy Crush Solitaire (King, 2025). Tutorial 티어: help_card_rate 80%, pity_trigger 3회. trigger_type 5종: level_clear / first_appear / condition / tutorial_level / touch guide_type 2종: focus_bubble(딤+하이라이트+강제) / floating(딤 없이+비강제)

5 Phase 0~1: 즉시 진입 + 로비 (Lv 1~2)

230001 content_ingame_intro (floating, tutorial_level=1) — Lv 1 인게임 시작 시 카드 매칭 기본 안내. 플로팅 말풍선, 화면 탭 스킵 가능.
230002 content_deck_draw (floating, tutorial_level=2) — Lv 2 인게임 시작 시 덱 뒤집기 안내. 플로팅 말풍선, 화면 탭 스킵 가능.
Lv 1~3 제한: 정해진 카드만 터치 가능 (가이드가 지정한 카드 외 입력 차단). 다른 카드 터치 시 카드 흔들기(0.3초) + 올바른 카드 깜빡임 힌트 연출 재생.

Lv 1 인게임 가이드 스텝

S1-1 — 게임 화면 구성 소개

필드 카드 → 드로우 덱 → 오픈 카드 (0.8초 간격). 화면 아무 곳 탭으로 진행. 스킵 불가.

매칭 가능 카드 하이라이트 + 탭 유도 화살표
최소 3회 매칭 성공 필요. 5초 무행동 시 힌트 깜빡임. 오류 시 카드 흔들기 + 올바른 카드 깜빡임 3회.
S1-3 — 클리어 연출
골드 1,000G + α + 해머 획득
NRU 전용 강화 클리어 이펙트. 결과 화면 확인 → Phase 1 (로비) 진입.

12 가이드 컴포넌트 (5종)

Focus Bubble (포커스 버블)
딤+하이라이트 배경 + 대상 강조 + 캐릭터+말풍선. 강제(is_forced=TRUE) — 반드시 터치 완료해야 진행. 20건.
새 메카닉/시스템 설명 + 행동 유도
Floating (플로팅)
딤 없이 캐릭터+말풍선. 비강제(is_forced=FALSE) — 화면 탭으로 스킵 가능. 7건 (230001, 230002, 230013, 230015, 230016, 230027, 230028).
보조 안내, 터치 팁
Highlight (하이라이트)
딤 배경 + 대상 UI 강조. alpha 0.4~0.7.
특정 행동 유도 (탭 대상)
Arrow (화살표)
탭 유도 애니메이션 화살표. PULSE / BOUNCE 타입.
매칭 가능 카드, 드로우덱
Feedback (피드백)
잘못된 행동 시 흔들기(0.3초) + 올바른 카드 깜빡임 3회.
오류 시 즉각 안내
