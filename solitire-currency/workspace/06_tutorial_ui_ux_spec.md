## 1. UI 컴포넌트 공통 사양

모든 튜토리얼 화면은 아래 4종 컴포넌트 + 2종 보조 요소의 조합으로 구성된다.

### 1.1 Bubble (포커스 말풍선)

> **[REF-개선] 마스코트 캐릭터 시스템 추가** — CCS 레퍼런스 분석 결과, 캐릭터 아바타가 포함된 Bubble이 NRU 친근감·기억 효과를 크게 높임.

```
┌──────────────────────────────────┐
│ ┌──┐ [아이콘] 타이틀 (14pt, Bold) │  ← titleKey (선택)
│ │🐾│                              │  ← mascotIcon (신규)
│ └──┘ 설명 텍스트 (12pt, Regular)  │  ← descKey (필수)
│                                   │
│                       [탭하세요]  │  ← autoDismiss=0일 때 표시
└────────────┬─────────────────────┘
             ▼ (꼬리: target 방향)
```

| 속성 | 값 |
|------|-----|
| 배경 | 흰색 라운드 사각형 (radius 12px, shadow) |
| 꼬리 | target 방향 삼각형 |
| 위치 | `BOTTOM_CENTER` / `TOP_CENTER` / `NEAR_TARGET` / `CENTER` |
| 스타일 | `DEFAULT` / `CELEBRATION` / `WARNING` |
| 닫기 | autoDismiss(ms) 또는 탭 |
| **mascotIcon** | 원형 48×48px, Bubble 좌상단. 게임 마스코트 캐릭터 (디자인팀 결정) |
| **mascotPosition** | `LEFT_TOP` (기본) / `RIGHT_TOP` / `NONE` |
| **mascot 예외** | `WARNING` 스타일은 mascotPosition=`NONE` (Feedback 전용) |

### 1.2 Highlight (하이라이트)

| 속성 | 값 |
|------|-----|
| 구현 | 전체 딤(alpha **0.3~0.4**, [REF-경량화]) + mask로 대상만 투명. Phase 0 S1-1은 딤 없음 |
| 형태 | `rect` / `circle` / `auto` |
| 여백 | 기본 8px |
| 터치 | 대상 외 영역 터치 차단 |

### 1.3 Arrow (화살표)

| 속성 | 값 |
|------|-----|
| 에셋 | 손가락 아이콘 + 화살표 (48×48px) |
| 색상 | #FFD700 (골드) |
| 애니메이션 | `PULSE`(위아래 0.8초) / `BOUNCE`(탭 시뮬) / `STATIC` |

### 1.4 Feedback (피드백)

| 타입 | 동작 |
|------|------|
| `SHAKE` | 좌우 ±5px, 3회, 0.3초 |
| `BLINK` | alpha 0→1→0, 3회, 0.5초 간격 |
| `PULSE_RED` | 빨간 테두리 깜빡임 |

### 1.5 DimOverlay (딤 오버레이)

> **[REF-개선] 딤 경량화** — CCS는 Phase 0에서 딤 없이 마스코트 Bubble만 사용. 무거운 딤은 NRU에게 "읽기 모드" 느낌을 주어 이탈 유발.

| 속성 | 값 |
|------|-----|
| 색상 | 검정 (#000000) |
| alpha | ~~0.5 (일반) / 0.6 (로비 가이드) / 0.7 (Phase 0 화면 소개)~~ |
| alpha (개선) | **0.3 (일반)** / **0.4 (로비 가이드)** / **없음 (Phase 0 환영 — S1-1)** |
| Phase 0 특칙 | S1-1 환영 Bubble은 딤 없이 게임 화면 위에 직접 표시. S1-2~S1-3는 alpha 0.3 적용 |

### 1.6 FreeTag (무료 태그)

| 속성 | 값 |
|------|-----|
| 텍스트 | `FREE ×3` |
| 위치 | 대상 부스터 버튼 상단 |
| 적용 대상 | 언두(Lv 8), 엑스트라 덱(상황), 파이어웍스(Lv 24) |

## 3. SCR-01: 인게임 — Phase 0 가이드 (Lv 1)

**화면**: InGameScene
**진입 조건**: NRU 첫 실행 → 로비 스킵 → 즉시 인게임
**맵**: Tutorial_0351 (필드 6장, 드로우 3장)

### 스텝 시퀀스

```
S1-1 화면소개 → S1-2 카드매칭 유도 ──→ (3회 성공) → S1-4 자유 플레이 → S1-5 클리어
                    ↑          │
                    └── S1-3 ──┘ (매칭불가 시 드로우 유도)
```

#### S1-1: 환영 + 게임 소개 (딤 없음)

> **[REF-개선]** CCS 스타일: 카드 딜링 애니메이션 후 마스코트 Bubble이 자연스럽게 등장. 딤 없이 게임 화면이 살아있는 상태로 안내.

| 항목 | 설명 |
|------|------|
| **딤** | **없음** (게임 화면 그대로 노출) |
| **연출** | 카드 딜링 애니메이션 1.5초 → 마스코트 Bubble 자동 등장 |
| **Bubble** | `T_TUT_MATCH_TITLE` + `T_TUT_MATCH_DESC`, BOTTOM_CENTER, mascotIcon 표시 |
| **autoDismiss** | 3,000ms (자동 소멸) 또는 탭 |
| **매칭 가능 카드** | 스파클 이펙트로 시각 유도 (딤 대신) |
| **스킵** | 불가 |

```
┌─────────────────────────────────────┐
│  [코인: 0]              [메뉴]      │
│                                     │
│     ┌───┐  ┌───┐  ┌───┐           │
│     │ 5 │  │ ■ │  │ 7 │ ✨         │
│     └───┘  └───┘  └───┘           │
│        ┌───┐  ┌───┐               │  ← 카드 딜링 완료 상태
│        │ ■ │  │ 3 │ ✨            │     (✨ = 스파클)
│        └───┘  └───┘               │
│                                     │
│  ┌──────┐         ┌──────┐         │
│  │드로우 │         │ [4]  │         │
│  │ 덱   │         │오픈  │         │
│  └──────┘         └──────┘         │
│                                     │
│  ┌──────────────────────────────┐   │
│  │ 🐾 환영합니다!                │   │
│  │    아래 카드보다 1 높거나 낮은│   │
│  │    카드를 탭하세요.           │   │
│  └──────────────────────────────┘   │
└─────────────────────────────────────┘
  (3초 후 자동 소멸 → 자유 플레이)
```

#### S1-2: 카드 매칭 유도 (±1)

| 항목 | 설명 |
|------|------|
| **딤** | 전체 (alpha **0.3**), 매칭 가능 카드만 스파클+밝게 |
| **Arrow** | 오픈 카드 → 매칭 가능 카드 (PULSE) |
| **타임아웃** | 5초 무행동 → 매칭 가능 카드 1개 Blink ×3 |
| **오류 처리** | 틀린 카드 탭 → SHAKE(0.3초) + 정답 Blink ×3 |
| **완료 조건** | 3회 매칭 성공 |

> **[REF-개선]** 딤 alpha 0.5→0.3으로 경량화. 매칭 가능 카드에 스파클 이펙트 추가 (CCS 방식).

```
┌─────────────────────────────────────┐
│          ██ 딤 (0.3) ██             │
│                                     │
│     ┌───┐  [dim] [dim]  ┌───┐      │
│     │ 5 │               │ 7 │ ✨    │
│     └───┘               └───┘      │
│           [dim]  ┌───┐              │
│                  │ 3 │ ✨           │
│                  └───┘              │
│                    ▲                │
│                    │ Arrow (PULSE)  │
│  ┌──────┐     ┌───┴──┐             │
│  │드로우 │     │ [4]  │ ← 오픈 카드 │
│  └──────┘     └──────┘             │
└─────────────────────────────────────┘
  ✨ = 스파클 이펙트 + 하이라이트(매칭 가능: 3, 5)
```

#### S1-5: 클리어 연출 (인게임 보상 수령 연출)

> **[REF-개선]** CCS는 코인이 화면을 채우며 날아가는 화려한 연출로 보상 쾌감을 극대화. Bubble(CELEBRATION) 텍스트를 인게임 보상 수령 연출 + Collect 버튼으로 대체.

| 항목 | 설명 |
|------|------|
| **연출** | **인게임 보상 수령 연출**: 30~50개 코인 파티클, 상단→코인 카운터 방향 비행(2.0s, ease-out) |
| **컨페티** | 멀티컬러 5~8색, 1.5초간 낙하 |
| **마스코트** | 화면 상단 축하 포즈 (200×200px) |
| **보상 표시** | 화면 중앙 "+{amount} 🪙" (24pt, Bold, 골드색) + "⚒ ×1" |
| **Collect 버튼** | 초록 라운드 버튼 (기존 Go 버튼 스타일), 탭 → 로비 전환 |
| **Skip** | "Tap to Skip" 하단 (alpha 0.5, 1초 후 표시) |
| **사운드** | 코인 낙하 효과음 + 팡파르 |
| 보상 | 골드 1,000g + 해머 1개 (가설 — const 10065 라이브 확인 필요) |
| 다음 | Collect 탭 → 로비 진입 (Phase 1) |

```
┌─────────────────────────────────────┐
│        🐾 (축하 포즈)                │
│                                     │
│  🪙🪙🪙🪙  ← 코인 파티클 비행       │
│    🪙  🪙🪙     ✨✨                 │
│  🪙    🪙  🪙  ✨                   │
│      🪙  🪙  ✨  ✨                 │
```
