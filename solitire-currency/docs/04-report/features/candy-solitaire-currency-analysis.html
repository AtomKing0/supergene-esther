Energy 흐름도

[레벨 클리어] │ ▼ rewardEnergy / energyEarned [Energy ⚡ 획득] │ ▼ AnimateEnergySpend [꾸미기 화면 (MetaScene)] │ ┌──┴───────────────────────────────────┐ │ RegularTask (일반 꾸미기 요소) │ │ taskEnergyCost = N (요소마다 상이) │ └──────────────────────────────────────┘ ┌──┴───────────────────────────────────┐ │ FinalTask (구역 최종 꾸미기 요소) │ │ finalTaskCost = M (더 높은 비용) │ └──────────────────────────────────────┘ │ ▼ TaskCompletedEvent [꾸미기 요소 1개 완성] │ ▼ AreaCompletedEvent [구역 완료 → 다음 구역 잠금 해제]

AreaProgression 구조

MetaScene (꾸미기 전체 화면) └─ Area 1 ├─ RegularTask × N (각 Task마다 다른 energyCost) └─ FinalTask × 1 (더 높은 finalTaskCost) └─ AreaCompletedEvent → Area 2 잠금 해제 └─ Area 2 ...

Betup (배팅 상승) 시스템

Betup은 레벨 진입 시 더 많은 Coins를 걸어 고위험-고보상을 선택하는 시스템입니다.
연승 달성 (OnFire 조건) │ ▼ BetupActivatedEvent [Betup 팝업: 배팅 금액 선택] │ ├─ [기본 입장료] → 일반 Coin 보상 └─ [높은 입장료] → 배율 적용 Coin 보상 │ ▼ 레벨 클리어 시 BetupCompletedEvent → 높아진 보상 지급 실패 시 BetupDestroyedEvent

OnFire (연승 불꽃) 시스템
