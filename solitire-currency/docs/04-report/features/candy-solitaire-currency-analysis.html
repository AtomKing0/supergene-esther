⚡ Energy — 꾸미기 진행 재화

✅ Energy는 레벨 입장 비용(생명력)이 아니다. 레벨 클리어 후 획득하여 꾸미기 Task 완료에 소모하는 메타게임 전용 재화.

Energy 흐름도

[레벨 클리어] │ ▼ rewardEnergy / energyEarned [Energy ⚡ 획득] │ ▼ AnimateEnergySpend [꾸미기 화면 (MetaScene)] │ ┌──┴─────────────────────────────────────┐ │ RegularTask taskEnergyCost = N │ │ FinalTask finalTaskCost = M (더 높음) │ └────────────────────────────────────────┘ │ ▼ TaskCompletedEvent → 꾸미기 요소 완성 ▼ AreaCompletedEvent → 다음 Area 잠금 해제

Area 계층 구조

MetaScene └─ Area 1 ├─ RegularTask × N (각 Task마다 다른 energyCost) └─ FinalTask × 1 (더 높은 finalTaskCost) └─ AreaCompleted → Area 2 해제 └─ Area 2 ...

⭐ StreakStar — 스트릭 연동 Stars 획득

레벨 내 카드를 연속으로 플레이하면 StreakMeter가 차오르고, 스트릭 달성 시 Stars(StreakStar)를 획득한다. 이 Stars는 토너먼트·에피소드 레이스에서 점수로 사용된다.

StreakStar 획득 흐름

[레벨 플레이 중] │ ▼ 카드 연속 플레이 (스트릭 체인) StreakMeter 상승 │ ├─ StreakOpportunityStart → 스트릭 기회 활성화 (HUD 표시) ├─ StreakOpportunityLoop → 스트릭 유지 중 루프 연출 └─ StreakMeter 충족 시 │ ▼ StreakReward 트리거 [Coins × StreakMultiplierValue] ← Coin 보상 배율 적용 [StreakStar(Stars) 가산] ← 별도 Stars 계정에 누적 │ ▼ StarBurstEffect.prefab 재생 [레벨 클리어 완료] │ ▼ Stars 잔액 → 토너먼트 / 에피소드 점수 반영

// 최종 Coin 보상 계산식 (필드명에서 재구성) 최종_Coin_보상 = BaseReward ← CoinRewardTLB 조회값 × StreakMultiplierValue ← 스트릭 배율 (연승에 따라 상승) + ( 남은_일반카드수 × LevelWonRewardPerRegularStockPileCardFactor ) + ( 남은_와일드카드수 × LevelWonRewardPerWildCardInStockPileFactor ) + ( 남은_부스터카드수 × LevelWonRewardPerBoosterCardInStockPileFactor ) + EpisodeFinishedCoinReward ← 에피소드 마지막 레벨일 때만 + BonusLevelCoins ← 보너스 레벨일 때만 // Betup 선택 시 추가 배율 최종_Coin_보상 ×= BetupMultiplier ← { x1, x2, x4, x8 } 카탈로그 확정
💡 설계 인센티브: 레벨 종료 시 남은 덱(StockPile) 카드 수를 Coin으로 환산. 즉 빠른 클리어 = 더 많은 남은 카드 = 더 많은 Coins. 숙련 플레이어의 코인 수익이 자연스럽게 높아지는 구조.

OnFire 달성 → Betup 제안 팝업 등장 │ ├─ [건너뛰기 x1] → 기본 입장료, 기본 보상 ├─ [x2 선택] → 입장료 ×2, 보상 ×2 → BetupActivatedEvent ├─ [x4 선택] → 입장료 ×4, 보상 ×4 → BetupActivatedEvent └─ [x8 선택] → 입장료 ×8, 보상 ×8 → BetupActivatedEvent │ ▼ (레벨 플레이) [클리어] → BetupCompletedEvent → 배율 적용 보상 지급 [실패] → BetupDestroyedEvent → 배팅 소멸 (초과 입장료 손실)
