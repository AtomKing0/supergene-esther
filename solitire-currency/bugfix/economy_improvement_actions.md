
# Economy Improvement Action Summary

본 문서는 제안된 개선안의 처리 방향과 후속 작업을 정리한 것이다.  
각 개선안은 실행 여부와 후속 분석 작업을 기준으로 관리한다.

---

# 1. 개선안 1

개선안 1은 **메타 골드 콘텐츠 업데이트 계획과 관련된 항목**이다.

정책

- 메타 골드는 **지속적으로 업데이트될 예정**이다.
- 분석의 핵심은 다음 두 가지다.

분석 항목

1. **도시 하나당 유저의 평균 플레이 타임**
2. **플레이 타임 기준 적절한 콘텐츠 업데이트 주기**

따라서 본 보고서에는 다음 내용만 포함되면 된다.

- 도시 1개 소비 예상 플레이타임
- 플레이타임 기준 콘텐츠 소진 속도
- 적절한 메타 업데이트 주기 제안

---

# 2. 개선안 2

개선안 2는 **출시 이후 단기 업데이트로 처리되는 항목**이다.

정책

- 해당 개선안은 **출시 후 2주 이내 업데이트 예정**이다.
- 따라서 런칭 빌드에는 일부 반영되지 않을 수 있다.

분석 목적

- 초기 런칭 안정성 확보
- 실제 플레이 데이터 확보
- 업데이트 시점 최적화

---

# 3. 개선안 3

개선안 3은 **경제 시뮬레이션 검증 작업**이다.

실행 계획

`06_simulation_agent` 를 재실행한다.

목표

1. idle 값 수정
2. 실제 플레이 기반 수치 재계산
3. 모든 플레이 유형별 경제 수치 확보

확인 항목

- 라이트 유저
- 일반 유저
- 헤비 유저
- 이벤트 집중 유저

이 작업을 통해 다음을 수행한다.

- 본 보고서의 **추정값 검증**
- 실제 경제 흐름 재확인

---

# 4. 경제 건강도 개선

현재 목표는 **경제 건강도 A 등급 달성**이다.

추가로 검토할 수 있는 항목

- 골드 소모 구조 강화 가능 지점
- 이벤트 재화 소모 루프 확장
- 메타 소비 속도 조정
- 부스터 소비 가속 구조
- 장기 플레이 인플레이션 방지 장치

분석 결과에 따라 **추가 개선 포인트를 제안해야 한다.**
