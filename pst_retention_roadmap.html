PST 리텐션 로드맵 — 세션·데일리·장기 3층 설계

Solitaire City Journey (Tripeaks Solitaire) · FB Instant Games · 2026-07-21 · north-star = NA/서구권 D1·D7·D14 · 콜드스타트(8/12까지 수익화 OFF) · 연동: 튜토·데코 · 결과후 플로우 · 도시 꾸미기 개편

한눈에

  • 우리 게임은 이미 시스템이 많음(컬렉션 2·이벤트 2·토너·리더보드 2·데일리 3·도시 메타·친구선물·스트릭). 문제는 기능 부족이 아니라 신규가 메타 루프에 못 올라탐 — 신규 89%가 도시1 데코 0개, D1도 낮음.
  • 이 게임의 심장 루프 = 레벨 플레이 → 해머 획득 → 도시 꾸미기 → 다시 플레이. 진짜 게이트는 골드가 아니라 해머(첫 데코 3해머·신규 중앙값 0). 리텐션 로드맵은 이 해머·데코 플라이휠을 돌리는 걸 최우선으로 한다.
  • 3층으로 카덴스를 분리(판당 / 일·주 / 상시)해 보상 피로 없이 쌓는다: ① 진행 체스트(해머 지급) → ② 무료 시즌 패스(데일리 앵커·시스템 감독) → ③ 친구 경쟁·노티 윈백(장기).
  • 팀/클럽은 공수 커서 제외 — 장기(D14) 빈칸은 다주차 시즌 패스 + 기존 친구 인프라로 대체.
  • 온보딩 선행(트랙1 튜토·트랙2 첫 데코)이 입구를 열고, 이 로드맵이 그 위에 지속 루프를 얹는다.

5. 레버별 상세 스펙

P1 · 먼저 진행 체스트 — 해머를 지급하는 세션 훅 (저공수)

재정합 주의 — 로비 해머 게이지(개편안 11)는 이미 "플레이→채우기" 존재. P1은 그와 중복이 아니라, 기획요청 "해머 획득처 강화"를 구현하는 보상 체스트: 승리 누적으로 해머(+골드·부스터)를 지급해 데코 게이트(3해머)를 빠르게 넘게 한다.

AS-IS

신규 해머 중앙값 0 → 첫 데코(3해머) 못 넘음 → 89% 데코 0개 → 메타 루프 진입 실패

TO-BE

승리마다 체스트 게이지↑ → 만땅 시 해머 다발 지급 → 첫 데코 즉시 가능 → 플라이휠 점화
🎁 동작
공수 저(게이지 UI 1개) 보상 해머 중심 + 골드·부스터 노출 로비 + 결과화면
  • 판 승리마다 게이지↑, 만땅 시 체스트 개봉 → 해머 N개(+골드·부스터). First Try는 2배(기존 winning_milestone 로직 재활용).
  • 초반 체스트는 해머 비중↑(첫 데코 3해머를 1~2체스트로 넘게), 이후 골드·부스터 혼합(가변 보상).
  • 결과후 플로우(다음판 직행)에 게이지 인라인 노출 → "한 판 더" 근접 목표.
왜 먼저? 신규 시스템 신설 없이 게이지+보상만 얹으면 됨(저공수). 해머 병목을 직접 뚫어 89% 데코 정체를 완화 → D1/D3 즉효.
이코노미 체스트 티어별 해머 지급량 밸런스(첫 데코 3해머·도시별 해머비용은 개편안 11 표 기준). 인플레 안 나게 상한.
클라 게이지 상태(승리 카운트)·결과화면 인라인 노출·개봉 연출. 아트 체스트·해머 튀는 피드백.

P2 · 메인 무료 시즌 패스 — 데일리 앵커 + 시스템 감독

관점 전환 — 패스를 또 하나의 시스템이 아니라, 기존 시스템으로 유저를 몰아넣는 메타 레이어(감독)로. 시퀀싱 문제(신규가 길 못 찾음)와 데일리 복귀를 동시에 잡음.

AS-IS

데일리 3종(기프트·태스크·룰렛) 전부 당일 리셋 → 다주차 목표·복귀 앵커 없음. 신규가 뭘 먼저 할지 모름.

TO-BE

2주 시즌 트랙 → 데일리/위클리 퀘가 데코·해머·토너·이벤트로 유도 → 티어 보상 누적 → "완주" 목표로 매일 복귀.
🎟 구성
기간 2주 시즌 트랙 무료만(8/12까지) 티어 ~30단 테마 도시 연동
  • 데일리 퀘 3 + 위클리 퀘 → 패스XP → 30티어 무료 보상. 보상에 해머·데코해머·부스터·골드(해머로 데코 루프 연료 공급).
  • ★퀘스트 = 기존 시스템 라우팅 — "데코 1개 배치 / 도시 진척 / 토너 1회 / 앨범 조각 3개 / 색카드 이벤트 참여". 신규가 시스템을 골고루 만지게.
  • 시즌 테마를 특정 도시·컬렉션과 묶어 서사 일관성(루나 서사 보조 레버와 연결).
  • 8/12 후 = 유료 Gold 트랙 얹어 수익화 전환(무료 트랙 구조 그대로 재사용).
팀 대체 효과 — 팀/클럽이 맡았을 장기(D14) 리텐션 빈칸을 다주차 아크가 상당 부분 대체. 무료 트랙만이라 콜드스타트 수익화 OFF 원칙 준수.
클라 패스 UI·퀘스트 진행·티어 수령. 퀘스트 트리거는 기존 이벤트 로그 재활용. 이코노미 30티어 보상 밸런스(해머·골드 인플레 통제)·퀘 난이도.

P3 · 장기 팀 대신 저공수 장기 리텐션 (기존 인프라 재활용)

팀/클럽(고공수) 제외 → D14+ 빈칸을 이미 가진 친구 인프라 + Meta 노티 채널(질 2위)로 메꿈.
