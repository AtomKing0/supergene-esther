PST 리텐션 로드맵 — 세션·데일리·장기 3층 설계

Solitaire City Journey · FB Instant Games · 2026-07-21 · north-star = NA/서구권 D1·D7·D14 · 콜드스타트(8/12까지 수익화 OFF) · 연동: 튜토·데코 · 결과후 플로우 · 도시 꾸미기 개편

한눈에

  • FB Instant Games는 설치 없이 즉시 플레이 → 첫 화면부터 컨텐츠가 많아 보여야 유저가 머문다. 우리 게임이 시스템이 풍부한 건 의도된 강점(과다가 아님).
  • 심장 루프 = 레벨 플레이 → 해머 획득 → 도시 꾸미기 → 다시 플레이. 진짜 게이트는 골드가 아니라 해머(첫 데코 3해머·신규 중앙값 0).
  • ∴ 과제 = 그 풍부한 컨텐츠를 실제로 돌게 만드는 것: ① 진행 체스트(해머 공급) → ② 무료 시즌 패스(데일리 앵커) → ③ 친구·노티(장기). 카덴스=판당/일·주/상시.
  • 팀/클럽은 공수 커서 제외 — 장기 빈칸은 시즌 패스 + 기존 친구 인프라로 대체.

1. 플랫폼 특성 · 진짜 병목

★ 플랫폼 — FB Instant Games는 설치 없이 즉시 플레이되는 특성상, 유저가 딱 봤을 때 컨텐츠가 많아 보여야 이탈하지 않고 머문다. 따라서 시스템을 숨기거나 늦게 여는 게 아니라 풍부하게 보여주는 게 맞다. 리텐션 과제는 "시스템을 줄이기"가 아니라 그 많은 컨텐츠가 실제로 돌게 하는 것.

3. 레버별 상세 스펙

P1 · 먼저 진행 체스트 — 해머를 지급하는 세션 훅

AS-IS

신규 해머 중앙값 0 → 첫 데코(3해머) 못 넘음 → 89% 데코 0 → 메타 루프 진입 실패

TO-BE

승리마다 게이지↑ → 만땅 시 해머 다발 지급 → 첫 데코 즉시 → 플라이휠 점화
🎁 동작
공수 저보상 해머 중심 + 골드·부스터노출 로비 + 결과화면
  • 판 승리마다 게이지↑, 만땅 시 체스트 → 해머 N개(+골드·부스터). First Try 2배(기존 winning_milestone 재활용).
  • 초반 체스트는 해머 비중↑(첫 데코 3해머를 1~2체스트로 넘게), 이후 혼합(가변 보상).
  • 결과후 플로우(다음판 직행)에 게이지 인라인 노출.
이코노미 체스트 티어별 해머 지급량 밸런스(도시별 해머비용=개편안 11 표). 클라 게이지·결과화면 노출·개봉. 아트 체스트·해머 피드백.

P2 · 메인 무료 시즌 패스 — 데일리 앵커

AS-IS

데일리 3종(기프트·태스크·룰렛) 전부 당일 리셋 → 다주차 목표·복귀 앵커 없음

TO-BE

2주 트랙 → 데일리/위클리 퀘가 데코·해머·토너·이벤트로 유도 → 티어 보상 누적 → 완주 목표로 매일 복귀
🎟 구성
기간 2주트랙 무료만(8/12까지)티어 ~30단테마 도시 연동
  • 데일리 퀘 3 + 위클리 퀘 → 패스XP → 30티어 무료 보상(해머·데코해머·부스터·골드).
  • 퀘스트 = 기존 시스템 라우팅 — 데코 배치·도시 진척·토너·앨범·이벤트로 골고루.
  • 8/12 후 유료 Gold 트랙 얹어 수익화 전환(무료 구조 재사용).
클라 패스 UI·퀘 진행·티어 수령(트리거=기존 이벤트 로그 재활용). 이코노미 30티어 보상·퀘 난이도 밸런스.

P3 · 장기 친구 비동기 경쟁 + 노티 윈백 (팀 대체)

  • 친구 비동기 경쟁 — 친구 리더보드·선물 이미 있음 → "친구가 앞질렀어"·주간 리셋 보상·선물 되갚기 스트릭. 백엔드 신규 없음.
  • 노티 윈백(Meta 노티=질 2위 채널) — "체스트 만땅"·"해머 다 찼어(꾸미러 와)"·"시즌 2일 남음"·D3+ 이탈자 복귀 보너스. 문구·트리거만 설계.
4. 레퍼런스 검증 — 우리 ①② 방향
우리가 기획하는 시즌 패스·진행 체스트가 2025 신작 Candy Crush Solitaire(King)에 동일 구조로 구현돼 있음. 실제 화면(시스템 해체분석 캡처).
