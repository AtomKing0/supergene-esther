Solitaire City Journey (Tripeaks Solitaire) · FB Instant Games · 2026-07-21 · north-star = NA/서구권 D1·D7·D14 · 콜드스타트(8/12까지 수익화 OFF)

요약

  • 우리 게임은 이미 시스템이 많음(컬렉션 2·이벤트 2·토너·리더보드 2·데일리 3·도시 메타·친구선물·스트릭). 문제는 기능 부족이 아니라 신규가 길을 못 찾음(신규 89%가 도시1 데코 0/5).
  • ∴ "더 넣기"보다 깊이·시퀀싱이 먼저. 아래 3층은 카덴스가 안 겹치게(판당/일·주/상시) 설계.
  • 채우기 상자(세션 훅) → 무료 시즌 패스(데일리 앵커 + 기존 시스템 감독) → 친구 경쟁·노티 윈백(장기).
  • 팀/클럽은 공수 커서 제외 — 그 장기 리텐션 빈칸을 다주차 시즌 패스 + 기존 친구 인프라로 대체.

1. 현황 — 이미 가진 것 (feature-rich)

이미지 맵(Figma) 기준. 솔리테어 장르의 경쟁형 소셜·컬렉션·데일리·메타빌딩은 이미 대부분 구비.
  • 컬렉션 2종 — 카드백 덱(collection_deck)·도시 앨범 퍼즐(collection_album)
  • 이벤트 2종 — 마일스톤(색카드·골든스탬프)·랭크(레이스)
  • 경쟁 소셜 — 토너먼트·리더보드(글로벌·친구)·친구 선물
  • 데일리 3종 — 기프트(7일)·태스크·룰렛
  • 도시 메타 — 데코 배치·도시 건설(meta_build_city)·스트릭(스타)
  • 인게임 — 트라이픽스 보드·프리레벨 부스터

4. 레버별 상세 스펙

P1 · 먼저 채우기 보물상자 (세션 훅 · 저공수)

🎁 승리로 채우는 상자
공수 저(게이지 UI 1개) 보상 기존 재활용 노출 로비 상시 + 인게임 미니
  • 판 승리마다 게이지↑, 만땅 시 상자 개봉(골드·데코해머·부스터).
  • First Try 2배 가산 — 기존 Golden Stamp(winning_milestone) 로직 재활용.
  • 상자 브론즈→실버→골드 순환(가변 보상 = 도파민 루프).
  • 항상 화면에 근접 목표가 보이게 → "한 판 더" 유발.
왜 먼저? 신규 시스템 신설 없이 게이지+상자만 얹으면 됨(저공수). 세션 판수·세션타임 즉효 → D1/D3에 가장 빠른 리텐션 승리.

P2 · 메인 무료 시즌 패스 (데일리 앵커 + 시스템 감독)

관점 전환 — 패스를 또 하나의 시스템이 아니라, 기존 시스템으로 유저를 몰아넣는 메타 레이어(감독)로 설계. 시퀀싱 문제(신규가 길 못 찾음)와 데일리 복귀를 동시에 잡음.
🎟 2주 시즌 · 무료 트랙
기간 2주 시즌 트랙 무료만(8/12까지) 티어 ~30단 테마 도시 연동
  • 데일리 퀘 3 + 위클리 퀘 → 패스XP → 30티어 무료 보상(골드·데코해머·부스터·데코).
  • ★퀘스트를 기존 시스템 라우팅용으로 설계 — "도시 데코 1개 배치 / 토너 1회 참여 / 앨범 조각 3개 / 색카드 이벤트 참여"로 골고루 유도.
  • 시즌 테마를 특정 도시·컬렉션과 묶어 서사 일관성.
  • 8/12 후 = 유료 Gold 트랙 얹어 수익화 전환(무료 트랙 구조 그대로 재사용).
팀 대체 효과 — 팀/클럽이 맡았을 장기(D14) 리텐션 빈칸을 다주차 아크가 상당 부분 대체. 게다가 무료 트랙만으로 콜드스타트 수익화 OFF 원칙 준수.

P3 · 장기 팀 대신 저공수 장기 리텐션 (기존 인프라 재활용)

팀/클럽(고공수) 제외 → D14+ 빈칸을 이미 가진 친구 인프라 + Meta 노티 채널로 메꿈.
👥 친구 비동기 경쟁 심화
  • 친구 리더보드·선물 이미 있음 → "친구가 널 앞질렀어" · 주간 리셋 보상 · 선물 되갚기 스트릭 추가. 백엔드 신규 없음.
🔔 노티 기반 윈백 (Meta 노티 = 질 2위 채널)
  • "상자 만땅" · "스트릭 끊기기 직전" · "시즌 2일 남음" · D3+ 이탈자 복귀 보너스.
  • 가장 저공수 재참여 레버 — 발송은 Meta 통제라 문구·트리거만 설계.
