🎯 판정: GO-WITH-CHANGES
장르는 강한 GO — 머지-2 H1'26 $1.24B(+95% YoY), 매출이 유저보다 빠르게 성장(ARPU 주도). 방식(Gossip Harbor)·메타(Flambé식 구역 재건) 모두 검증됨. 단 컨셉 그대로는 미검증 베팅 2개(포화 테마 + 밝은 톤)가 겹쳐, 아래 5개 변경을 조건으로 GO.

반드시 반영할 5개 변경

1. 차별점 = 테마가 아니라 "코지 미스터리" 서사. 정원/꽃 머지는 이미 포화·매출 상한(Florescence "꽃 스튜디오 상속받아 유산 되살림" = Rosewood와 판박이, Merge Gardens 하락, 전부 월 수백만$ 상한). 테마론 못 이김 → 할머니 비밀 중심 코지 미스터리(40-65 여성에 검증된 출판 장르)를 진짜 차별점으로. 밝은 톤은 유지.
2. 테마: 순수 꽃 → "메이커(공방·약방)" 강조. 도예·양초·비누·허브약방 "만드는" 각도가 꽃보다 훨씬 덜 포화(미검증이나 화이트스페이스).
3. 할머니 존재감 강화(공동 주역급). Merge Mansion의 Ursula(Kathy Bates 광고 얼굴) 모델 — 젊은 로지+이든 로맨스 + 강한 할머니로 40-65 정서 헤지.
4. 플랫폼: 네이티브 우선 + FB Instant는 UA/디스커버리 채널. 대형 머지 전부 네이티브 전용, FB Instant는 리텐션 구조 불리(홈아이콘·푸시 없음). NEZP(Zero Permissions)로 빌드 필수 — 레거시 Web Games 2026-09-30 종료.
5. 주인공/스코프 정합. 로지 = 순진한 소녀 아닌 20대후반~30대초 사연 있는 젊은 어른(GH Quinn식), 이든 로맨스 = 미스터리에 엮인 슬로우번. 상시 구역 ~20-30 + 시즌 리스킨(47 아님). 에너지/버블 DDA는 유지하되 힐링 톤에 맞게 UX 순화.

2. ⚠️ 테마 리스크 (최대 약점)

정원/꽃 머지는 여러 번 시도됐고 전부 매출 상한(Florescence·Merge Gardens·Flower Haven — 월 수백만$, GH 100M/월 근처도 못 감). 웰니스/공방(도예·양초·비누·차·약방)은 대규모 검증 사례 아예 없음 = 비포화 화이트스페이스. → 테마는 차별점 못 됨, 서사 실행력이 차별점. 순수 꽃보다 메이커/약방 각도가 덜 포화.

3. ⚠️ 톤 리스크 (밝음 vs UA 공식)

GH의 $677M UA 공식 = "모든 광고가 위기로 시작"(불륜·비밀·배신). "무거운 드라마 없음"은 이 검증된 훅을 제거 → CPI↑·리텐션↓. 완화: 코지 미스터리 spine(할머니에게 무슨 일이/마을은 왜 버려졌나/이든이 숨긴 것)을 광고 훅에 쓸 만큼 날카롭게, 톤은 따뜻하게. 미완화 시 Florescence 티어에 갇힘.

4. 주인공/오디언스 (부분 검증)

젊은 여주+로맨스 = 1위 GH가 쓰는 바로 그 패턴(Quinn↔Harrison). 나이든 플레이어도 몰입(로맨스소설·소프오페라 = 40-65 여성). 단 GH 평균 32세(타겟보다 젊음) → 정확한 전환 증거는 없음. Merge Mansion 헤지: 젊은 Maddie + 할머니 Ursula가 마케팅 앵커. GH 실제 주역은 성숙한 어른(이혼·아이)이고 로맨스는 슬로우번 → 로지도 사연 있는 젊은 어른, 이든은 슬로우번.

5. 플랫폼 (네이티브 우선으로 전환)

대형 머지 프랜차이즈 전부 네이티브 전용. FB Instant는 홈아이콘·푸시 없어 솔로 서사 머지엔 불리. 스펙: 초기로드 <1MB · 전체 50MB · 70/30 · IAP 별도 승인. 레거시 Web Games 2026-09-30 종료 → NEZP SDK v8.0로 빌드. FB Instant 테마: 카페만 포화, garden/wellness/craft는 화이트스페이스. → 네이티브 주 + FB Instant는 저비용 UA 채널.

6. 코어 이식 목록 (GH/Seaside 역기획 — 변경 금지)

  • 에너지 최대 100·120초당 1 · 머지는 무소모(생성기 탭만) · 생성기 2단 재고 · 럭키 pity [total,lucky] · 버블 Lv4/60초/DDA · 오더 난이도 캡 300 · 레벨 30+15/레벨 선형
  • 스토리 2계층: 감정태그 챕터 대사(로맨스=서브플롯) + 범용 친밀도 선물시스템(전 NPC 재사용)
  • 라이브옵스 레인 + 수익화 레이어링(1+1·Buy All·에스컬레이팅 번들·2티어 패스) + 봇 경쟁(협동적으로 완화) · 월 ~20이벤트로 시작→확장
