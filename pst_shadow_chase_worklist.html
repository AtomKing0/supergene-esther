A-1~A-7. 화면별 문자열 확정

  • ① 발동 연출(풀스크린) 문구 확정기획
    타이틀 · 서브카피 · [OK] 버튼(T_OK 재사용) — 현재 스펙에 타이틀/서브 키가 없음 → 신규 2키 필요
  • ③ 스토리 팝업 문구 확정기획
    "그림자 냥이가 열쇠를 물고 도망쳤어요! 같이 잡아요!" + [확인] — T_SHADOW_CHASE_INFO_TEXT 재사용 여부 판단
  • ⑥ 프리레벨 행잉 태그 문구 확정기획
    남은시간(T_COUNTDOWN_5) · n/8 게이지 · T_SHADOW_CHASE_TAG_GOAL("8판 완주 시 열쇠 획득")
  • ⑦ 체스트 팝업 문구 확정 — 3컷 전부기획
    컷① 타이틀·서브 · [Open] 버튼(기존 단독 키 없음 → 신규) · 컷③ 서브("열렸어요") · 보상 헤더 · [받기](T_CLAIM)
  • ⑧ 타이머 말풍선 문구 확정기획
    T_SHADOW_CHASE_AD_EXTEND = "+5분" · 연장 성공/실패 피드백 문구 필요 여부 판단
  • ⓘ 인포 팝업 문구 확정기획
    T_SHADOW_CHASE_INFO_TITLE · _INFO_TEXT · 보상 미리보기 헤더 · 남은시간 · [X]
  • 공통·에러 문구 확정기획
    T_SHADOW_CHASE_OFFLINE · 수령 실패 재시도 안내(기존 에러 키 재사용 가능한지 확인)
  • 최종 키 목록 확정 — 신규 N개 / 재사용 M개기획
    A-1~A-7 종합. 기획서 §3-4 ③ string_code 표를 이 목록으로 갱신
미사용 키 정리 — T_SHADOW_CHASE_FAIL_FLEE(실패 알림 미채택) · T_SHADOW_CHASE_CHEST_NO_MULTIPLY(지급 분리로 불필요)는 등록하지 않음. 등록해두고 안 쓰면 다음 사람이 또 헷갈림.

B 번역 — 10개 언어

라이브 string_code 컬럼 순서 = Key · en · ar · es · pt · id · ru · fr · th · jp · kr — en이 첫 컬럼이고 kr이 마지막임. 10개 언어를 모두 채워야 등록 완료임.
  • kr 원문 확정기획
    A 단계 산출물. 한자 사용 금지 · 기존 게임 말투와 통일
  • en 작성기획
    첫 컬럼이자 사실상 기준 언어. FB Event Info 문구와 표현 통일
  • 나머지 8개 언어 번역기획
    ar · es · pt · id · ru · fr · th · jp
  • 특수문자·플레이스홀더 검증기획
    {0} 자리표시자 개수·순서 일치 · 개행(\n) 처리 · 아랍어 RTL 확인

C 라이브 밸런스시트 등록

안전장치 — 전 행 in_use=FALSE로 선등록함. 개발 완료 후 TRUE 전환이 곧 킬스위치임. 키 충돌·대역 소유는 검증 완료(기획서 §3-4 참조).
  • event_schedule +1행 — 160005기획
    shadow_chase · start_day=1 · end_day=5 · 0:00 / 0:00 · repeat=TRUE · interval_week=1 · base_date · in_use=FALSE
    라이브 관례 = 종료일 자정 기준 → 목요일 끝까지는 end_day 4가 아니라 5
  • unlock +1행 — 50031기획
    content_event_shadow_chase · level_clear · 10 · pre_unlock_visibility=FALSE
  • string_code 신규 키 등록기획
    B 단계 완료분을 10개 언어 전부 채워 등록
  • event_shadow_sprint 신규 탭 생성 — 240001기획
    8변수: duration_sec=900 · total_rounds=8 · cooldown_sec=43200 · grace_after_window=TRUE · ad_extend_threshold_sec=300 · ad_extend_sec=300 · ad_extend_max_per_cycle=1 · in_use=FALSE
    라이브 포맷 준수: 1행=한글 라벨 · 2행=영문 컬럼명
  • event_shadow_chest 신규 탭 생성 — 250001~250006기획
    Normal 6슬롯 — 골드 500 · 해머 3 · 와일드카드 1 · 되돌리기 2 · 파이어웍스 1 · 티켓 1
    reward_key 6종 전부 라이브 item_list 실존 확인 완료 · Jackpot 250007~250012는 v1 미등록
  • 등록 후 키 충돌 재확인기획
    등록 시점 기준으로 160005 · 50031 · 240001 · 250001~006 중복 없는지 최종 확인

D 로그정의서 기입 — [PST] 로그정의서

대역 = 5xxx-1 이벤트 관련 섹션(블랙5400 · 레드5410 · 위닝5420 · 클리어랭킹5430) 다음 빈 블록 5440번대. 시트 컬럼 = 적용 · 확정 · Event · 기록시점 · Data 요약 · Sample Data · isapplied · 호출 지점

  • 5442_EVENT_SHADOW_CHASE_ROUND_CLEAR기획
