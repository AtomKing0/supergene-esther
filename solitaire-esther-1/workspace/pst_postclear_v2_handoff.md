# PST 결과 후 플로우 단축 (post-clear v2) — 개발 핸드오프

> 기획·화면 = `pst_postclear_flow_spec.html` · 데이터 = `pst_ftue_funnel_analysis.html` ②부 · 작성 2026-06-23

## 0. 한 줄 요약
클리어→다음판 사이 뎁스 제거(현 탭 4회+ → **[받기] 1번**)로 인당 판수↑. 전부 밸런스시트 const로 on/off — **마스터 1개 + 정합 게이트 + 종속 3그룹**.

## 1. 배경 (왜)
- 인당 판수: 동일 런칭주차·promotion 기준 **PST 5.7 vs Cozy 16.3 (≈⅓)**. 판수가 리텐션·RV로 직결.
- 제1요인 = 결과 후 뎁스: 받기 → 로비 수령 → 플레이 → 프리레벨 팝업(배수·부스터·입장료) → 다음판.
- 판당 RV는 이미 최고(0.136)·**RV 68.7%가 결과화면 x2받기** → 레버는 RV가 아니라 판수.

## 2. 구조 — 마스터 1개 + 정합 게이트 + 3그룹
- **마스터 `is_quick_next_loop_open` (0/1)**: "결과 후 로비 없이 바로 다음판" 전체. 0=킬스위치(전부 v1).
- **정합 게이트**: `v2적용 = is_quick_next_loop_open AND 그룹정합()`. **그룹①⟺②는 반드시 동일**(①팝업스킵만 켜고 ②보상결과화면 끄면 모순) → 불일치 시 **전체 v1 폴백 + 경고 로그**(반쪽 적용 X). 그룹③ 독립.
- 운영: 마스터만 ON(3그룹 기본 v2·자동 정합). A/B: 마스터 번들 또는 그룹③(데코) 단독.

## 4. 3그룹 상세

### 그룹① 프리레벨 팝업 — 띄움(v1) vs 스킵(v2)
- `is_prelevel_popup_open` 1→0
- 입장료(`entry_cost_*_v2`=0)·배수 1배·부스터 인게임 — **전부 팝업 안에 있던 것이라 같이 켜고 같이 꺼야 함**(하나만 끄면 모순·깨짐)

### 그룹② 보상 수령 — 로비(v1) vs 결과화면(v2)
- `is_reward_on_result_open` 0→1 (①과 항상 동일)
- **[받기] 1번에 결과+이벤트 마일스톤 동시 수령 → 다음판 즉시 이동**
- 이벤트 진척 미터(우측 28/40·40/45)는 이미 결과화면 노출 → **수령 로직만 [받기]에 연결**(신규 UI 불필요)
- [홈] 버튼 골드 아래 신설

### 그룹③ 꾸미기 — 수동(v1) vs 자동(v2)
- `is_deco_auto_open` 0→1
- 망치(=플레이수) 임계(`deco_auto_hammer_threshold_v2`) 도달 시 자동 진입·자동 꾸미기, **골드 미사용**(`deco_auto_use_gold_v2`=0)
- 자동 꾸미기 = 망치 임계 시 자동 진입 → **로비(도시 화면)로 보내 꾸민 도시 노출** (다음판 자동복귀 아님 · 로비 [다음판]/[홈]로 재개). **빈도 상한**으로 과다 노출 방지(불가 시 결과화면 인라인 진척으로 대체)

## 7. 골드 경제 (입장료 폐지 영향) — ★검증·정합 완료 2026-06-25
> 검증 = `pst_postclear_economy_verification.html` · 인플레 실측 `pst_gold_economy_inflation.md` · 채널 before/after = `pst_reward_beforeafter.html` · 근거 9400 GOLD_TX(6/15~21, n=312)

- **AS-IS**: 소스 +55M(판보상 41.5·컬렉션 6·RV 5.7·방치 0.9·데일리 0.9) / 싱크 −39.25M(입장료 −33.4·부스터 −5.6·데코 −0.25) → 순잉여 +15.75M/주. 입장료=싱크 **85%**.
- **입장료 폐지 자체 = 골드 중립(왕복 확인됨)**: 보상=`entry_cost+reward_margin` 왕복 구조 **확인** → entry=0이면 보상도 자동으로 마진만 남아 판보상이 입장료만큼 자동 축소 → 순잉여 ~+16M 유지·**보상테이블 재작업 없음**.
- **단 인플레는 이미 진행 중**(입장료와 무관): 페어드 추적 잔류 **74% 20일 순증**·max 10.5M. 진짜 순증 수도꼭지 = **컬렉션·이벤트·앨범·메타도시**(판보상은 입장료와 왕복이라 무관). 판수↑(post-clear v2 목적)가 증폭.
- **해법 = 구조화 채널 골드 감액 + 아이템 타입 치환** (§5-B):
  - **골드**: meta_city(효과기반 해머×25)·이벤트·앨범·데일리 등 골드 슬롯 감액. **A·B 빌드 공통·기획이 시트에서 처리(클라 무관)**. 단일 가드레일 = F2P 하루 공짜아이템 **24→3~5개**.
  - **아이템**: 사라지는 프리부스터(**폭죽 제외·인게임 이전이라 유지**)·티켓·인피니트(골티/티켓) → 인게임 부스터 고정표 치환(§5-B, **B전용·클라**).
  - **안 건드림**: 판보상·RV·방치·인게임 수익.
- 메타 데코는 망치(=Royal Match의 Stars 대응) 분리 → 코인경제 무관·정합.
- 라이프(하트) 게이팅 = 인플레 심화·잔류 꼬리 잔존 시 검토하는 **별도 옵션(전제 아님)**. 1차는 채널 골드 감액으로 통제.
- 인플레 시 큰 수도꼭지(컬렉션 +6M·x2받기 RV +5.7M)부터 축소. 방치(cap 8000/4hr)·RV 골드(2000/회) **양 유지**(복귀유인·광고수익)·증액 금지.
